# 液态玻璃方案设计 — WebGL / CSS 双方案 + 主题色系统（待用户审核）

> 基于对 liquid-glass@0.3.2 源码的研读（palette 覆盖机制、组件清单、交互工厂）。
> 结论先行：**WebGL 方案只做「玻璃控件层」，内容主体保持 DOM** —— 混合渲染。

## 1. 架构：混合渲染分层

```
┌─ z=30  DOM 交互层（内容：榜单列表 / 对话流 / 评论区 / 详情）← 常规 DOM
├─ z=20  WebGL 玻璃控件层（liquid-glass canvas，只画控件不画内容）
└─ z=10  页面背景（渐变/壁纸，玻璃折射的采样源）
```

- WebGL 全画内容 = SEO 归零、无障碍归零、长列表性能灾难。**控件玻璃化、内容 DOM 化**。
- canvas 层用 `pointer-events: none` 放行事件，控件命中区由库内 interactions 自己接管（仅控件 bbox 命中）。

## 2. WebGL 方案组件映射表（liquid-glass 库 API）

| 界面 / 情况 | 应用组件 | 参数要点 |
|:---|:---|:---|
| **底部三栏导航**（榜单/对话/我的） | `TabBar` + `makeTabDragInteractions` | 3 tab；支持横向拖拽切换（库原生）；`tabsAccent` = 主题色 |
| **顶栏右侧控制组**（搜索/主题/汉堡） | `HStack` 内 3× `Button`（makeGlassShape 胶囊底） | 玻璃 tintColor，`highlight` 45° 高光，图标走 `Icon` |
| **榜单分类切换**（游戏/工具/文学/二创） | 迷你 `TabBar`（4 tab） | 同一拖拽交互，`tabsContainer` 半透明白/黑 |
| **我的 → 设置面板** | `ControlCenter` | iOS 控制中心形态；`ToggleRow`×（网页通知 / IP 记录）、`SliderRow`×（玻璃折射强度）、方案切换 `Toggle`、主题色三选 `ButtonRow` |
| **确认对话框**（退出登录/删除作品等） | `Dialog` + `Scrim` | `dialogAccent` 主题色；scrim 用库内暗色蒙层 |
| **汉堡侧抽屉** | `GlassPane` + `Scrim` | 面板玻璃折射 + 边缘高光；菜单项用 `ButtonRow`/`Text` |
| **登录页主按钮** | `Button` | `tintColor` = 主题色，`saturation:1.5` 提玻璃感 |
| **游客/未登录提示条** | `GlassPane` 细条 | 低饱和玻璃，不抢内容 |
| **AI 对话输入发送键** | `Button`（圆形） | 纸飞机 `Icon` |
| **榜单列表 / 详情 / 对话消息流 / 评论 / 六维雷达图** | ❌ 不上 WebGL，保持 DOM | 内容层 SEO/无障碍/性能优先；玻璃感由 CSS 方案补 |

**不同情况自适应**：
- 暗色模式：palette 整体切 DARK_PALETTE 覆盖键（库原生支持 `theme:"dark"`）
- WebGL 创建失败 / `!gl`：整站自动落回 CSS 方案（一次性降级，session 内不再尝试）
- `deviceMemory ≤ 4` 或 `hardwareConcurrency ≤ 4`：设置里默认选中 CSS 方案并提示
- `prefers-reduced-motion`：CSS 方案去掉过渡动画；WebGL 方案建议改用 CSS

## 3. CSS 方案映射（backdrop-filter 对照实现）

| WebGL 组件 | CSS 对应 |
|:---|:---|
| TabBar | `backdrop-filter: blur(24px) saturate(1.6)` 胶囊导航 + 主题色 pill 滑块 |
| ControlCenter | 玻璃面板 + 自绘 Toggle/Slider（soul 规则：禁原生控件） |
| Dialog/Scrim | 玻璃卡片 + rgba 蒙层 + scale 过效 |
| GlassPane 抽屉 | 玻璃侧板 + 高光描边（1px inset white） |
| 玻璃按钮 | 同上，`:active` 用 `pressTintColor` 等效的亮度变化 |

内容卡片（榜单列表等）在两种方案下都用 CSS 玻璃——保证一致观感。

## 4. 主题色系统（两方案同步）

三套预设 + 自定义，设置面板存放，`localStorage` 持久化：

| 预设 | 定义 | WebGL palette 键值 | CSS 变量 |
|:---|:---|:---|:---|
| **蓝紫**（默认） | 主色 #7C3AED | accent/dialogAccent/tabsAccent/ccTileAccent = 紫，trackOff 紫灰 | `--lg-accent:#7C3AED` 系 |
| **iOS 彩色** | iOS 控制中心分色 | accent=绿#34C759、dialogAccent=蓝#0089FF、tabsAccent=蓝、ccTileAccent=多彩磁贴逐个分色 | 对应变量组 |
| **自定义** | 设置内自绘 HSL 选色器（禁用原生 color input，soul 规则） | 由所选 HSL 生成整组 palette（主色 + 亮/暗变体自动派生） | 同步生成 CSS 变量 |

**同步机制**：
- WebGL：换主题色 → 重建 `createScene(glass, {theme, palette: overrides})`（palette 是 {...LIGHT/DARK, ...overrides} 合并，只传差异键）
- CSS：`document.body.dataset.accent` 切换预生成变量组；自定义色注入 `<style>` 变量
- 两方案共用一份「主题色令牌」（JS 单一来源），切方案不掉色

## 5. 设置面板项（WebGL 的 ControlCenter / CSS 的玻璃面板，两方案同构）

1. 外观：深色 / 浅色 / 跟随系统
2. 液态玻璃方案：WebGL 增强 / CSS 兼容（WebGL 失败时锁定 CSS）
3. 主题色：蓝紫 / iOS 彩色 / 自定义（HSL 选色器）
4. 玻璃折射强度：Slider（映射 GLASS_PARAMS.refractionAmount / CSS blur 半径）
5. 网页通知：Toggle
6. IP 记录：Toggle

## 6. 代码接入骨架（WebGL 方案）

```html
<canvas id="lg-layer"></canvas>            <!-- 玻璃控件层 -->
<script type="module">
import { LiquidGlass, createScene, TabBar, ControlCenter } from '/assets/vendor/liquid-glass@0.3.2.js';
const glass = new LiquidGlass({ canvas: document.getElementById('lg-layer'), onError: fallbackToCss });
const scene = createScene(glass, { width: innerWidth, theme: 'light', palette: tokens.paletteOverrides() });
scene.setBody(state => TabBar({ tabs: ['榜单','对话','我的'], onSelect: route }));
addEventListener('resize', () => glass.requestRender());
</script>
```

## 7. 兼容边界

- iOS Safari / Chromium 全支持 WebGL1（库内含降级路径与性能监测 perfMonitor）
- Firefox 老版本 backdrop-filter 需 flag → 检测 `CSS.supports('backdrop-filter','blur(1px)')`，不支持则纯磨砂（不透明渐变兜底）
- 两方案切换即时生效，无整页刷新
