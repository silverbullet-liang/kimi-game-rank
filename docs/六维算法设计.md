# 六维自动计算算法 — 设计稿

> 全部特征基于社区 API 可得数据 + 作品 HTML 文件，纯 PHP 7.0 统计实现，无 ML 依赖。
> 所有阈值/权重集中在 `config/scoring.php` 权重表，可调不改码。
>
> **v3.40.0 重构（现行实现）**：六维归为**三支柱**（质量 / 投入 / 认可）；权重 = **AHP 主观判断矩阵**（CR<0.1）× **CRITIC 客观权重**（全站语料，`app/corpus.php`）组合（λ=0.5）；
> 总分由「六维算术求和」改为**支柱加权几何**（下限 0.10，短板乘性压制）；口碑维加**贝叶斯收缩**；评级改为**按全站总分累计名次**（并列同分同档、每档不超配额）。下文逐维公式多数仍适用，**汇总方式以本节为准**。
>
> **v3.41.0**：**媒体数量（图片 / 音频 / 视频）不再参与任何维度计分**（体验的 e3、成本的 c3 已移除，权重归并到其余项）；已上线作品由 `app/relink.php` **自动重新识别跳转链接**。

## 0. 数据记号

| 记号 | 含义 | 来源 |
|---|---|---|
| L / C / F | 点赞数 / 评论数 / 收藏数 | stat.{likeNum,commentNum,collectNum} |
| T / X / B | 标题 / 配文 / 正文 | content.{title,excerpt,text} |
| H | 作品 HTML 文件（可空） | chatShareCard.htmlFile.cdnUrl 抓取 |
| bytes / lines | H 的字节数 / 行数（含作品页引用的非 CDN 脚本） | 抓取统计 |
| age | 作品年龄（小时） | createTime |

通用函数：`clamp01(x)`、`bell(x,a,b)`（[a,b] 内为 1 线性衰减到 0）、`lns(x,base)=ln(1+x)/ln(1+base)`（base 为满分基准）。

**缺数据原则**：某信号组缺失 → 剔除该组并重归一化剩余权重；整维无法计算 → 按可得特征重归一化并打「数据不足」标记（详情页显示灰点），不虚报分数。

## 1. 热度（唯一纯客观维）

```
heat = 200 × min(1, 0.45×lns(L,100) + 0.35×lns(C,50) + 0.20×lns(F,30))
新作品曝光保护：age < 24h → heat × (1 + 0.2×(1−age/24))，clamp 0-200
```
- 满分基准：100 赞 + 50 评 + 30 藏；对数防头部垄断。
- 10 赞/5 评/3 藏 ≈ 95 分，量级合理。

## 2. 创意

```
s1 标题独特性 = 1 − max_2gram_similarity(T, 库内已有标题)   （空库 = 1）
s2 标题信息密度 = bell(len(T), 4, 20)
s3 正文词汇多样性 = 去重词数 / 总词数
s4 形式创新 = 0.15×has(artifactShareId) + 0.10×has(htmlFile)，上限 0.25→归一

creativity = 200 × clamp01( 0.20×s1 + 0.10×s2 + 0.40×s3 + 0.30×s4 )
```

## 3. 体验

```
e1 可运行作品 = has(htmlFile.cdnUrl) 或 has(artifactShareId) → 1.0
e2 交互密度 = min(1, count(button|input|select|textarea|canvas|svg 标签) / 12)
e3 玩法说明覆盖 = 命中词表比例：{操作,点击,选择,输入,按键,拖动,关卡,难度,模式}

experience = 200 × clamp01( 0.40×e1 + 0.40×e2 + 0.20×e3 ) × (可运行 ? 1 : 0.8)
```

## 4. 深度

```
d1 正文规模 = min(1, len(B) / 800)
d2 结构复杂度 = min(1, (段落标记数 + 列表/编号标记数) / 6)
d3 代码深度 = max( min(1, lines/400), min(1, function出现次数/30) )
d4 讨论深度 = clamp01( lns(C,30) )

depth = 200 × clamp01( 0.30×d1 + 0.20×d2 + 0.30×d3 + 0.20×d4 )
```

## 5. 成本（制作投入）

```
c1 体量 = min(1, bytes / 300KB)
c2 代码规模 = min(1, lines / 1200)
c3 文本投入 = min(1, len(B) / 3000)

cost = 200 × clamp01( 0.44×c1 + 0.31×c2 + 0.25×c3 )   （无 H → 剔除 c1/c2，只按文本量计）
```

## 6. 态度

```
基线       = cost / 200
a1 交代用心 = 作者配文/正文用心度（0–1；优先 Jev 判，缺失按配文长度分级）
a2 交付完成 = has(H) 或 has(artifact) → 1，否则 0

attitude = 200 × clamp01( 0.35×基线 + 0.45×a1 + 0.20×a2 )
```

## 7. 总分与评级（v3.40.0 起改为层级聚合）

```
支柱：质量 = 0.45·可玩性 + 0.25·创意 + 0.30·深度
      投入 = 0.55·体量 + 0.45·用心
      认可 = 口碑
总分 = 1200 × Π( (0.10 + 0.90·支柱/200) ^ 支柱权重 )   （支柱权重 0.5396/0.2970/0.1634）
评级按**累计名次**（前2%/10%/25%/50%/75% → SSS/SS/S/A/B，其余 C；并列同分同档、每档不超配额）
```

| 评级 | 名次位置 |
|:---:|---|
| SSS | 前 2% |
| SS  | 前 10% |
| S   | 前 25% |
| A   | 前 50% |
| B   | 前 75% |
| C   | 其余 |

（并列同分同档，每档不超过配额；全站语料不足时退回 `rating.fixed` 固定分数线）

## 8. 重新计算触发点（配合查重逻辑）

- 手动添加已存在作品 → 更新 L/C/F/H 等原始数据 → 六维全部重算
- 自动批量同步遇已存在 ID → 同上，仅覆盖部分字段 + 重算，不重复插入
- 评论数变化后可在后台「刷新作品」手动触发单条重算
- 评分体系版本号变更（`config/scoring.php` 的 `version` +1）→ 上线后由 `app/score_recalc.php` **自动全站重算**（有 `works.feat` 特征快照的走离线重算，无需人工点击）
- 链接重识别（v3.41.0）：已上线作品由 `app/relink.php` 定时抽检，识别出跳转页即换真实地址（并纠正标题）；此步不改评分

## 9. PHP 7.0 实现骨架（示意）

```php
function clamp01($x) { return max(0.0, min(1.0, $x)); }
function lns($x, $base) { return log(1 + max(0, $x)) / log(1 + $base); }
function bell($x, $a, $b) {
    if ($x >= $a && $x <= $b) return 1.0;
    $d = $x < $a ? $a - $x : $x - $b;
    return max(0.0, 1.0 - $d / 10.0);
}
// 每维一个纯函数 computeXxx(array $feat, array $w): float  —— $w 为 config/scoring.php 权重表
// 特征提取 extractFeatures(array $moment, ?string $html): array 独立可测
```
