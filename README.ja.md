# Kimi ゲームランキング · kimi-game-rank

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **日本語** · [한국어](README.ko.md) · [Italiano](README.it.md) · [Français](README.fr.md)

**Kimi コミュニティ**向けの、6 軸による総合スコアランキングサイト。PHP + MySQL、フロントエンドはビルド不要（素の HTML / CSS / JavaScript）。

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](LICENSE)

> 本プロジェクトは **Kimi の公式プロジェクトではありません**。Moonshot AI とは一切関係ありません。

---

## これは何か

コミュニティのゲーム・ツール・文学作品・二次創作を集め、6 つの観点で採点してランキングするサイトです。採点はアルゴリズムが自動で行い、管理者は個別の作品を必要に応じて手動で修正できます。

## 機能一覧

| モジュール | 説明 |
|---|---|
| ランキング | 4 カテゴリ × 4 種（総合 / 投票 / 殿堂 / 穴場）、順位バッジと評価ラベル |
| 作品詳細 | 6 軸レーダーチャート、軸ごとの内訳、紹介とコメント欄（無制限のネスト返信） |
| チャット | ワールドチャット（リアルタイムポーリング）+ AI チャット（ストリーミング出力、Web 検索、サイト内ルールの注入） |
| マイページ | アバター、AI 使用量、IP 情報とアクセス履歴、外観設定 |
| ログイン | パスワードログイン / 新規登録 / ゲストモード |
| 管理パネル | 取り込みと一括更新、データベースのバックアップ、コメント審査、タグ管理、副管理者 |
| スマートリンク解決 | 既定で有効：作品ページが転送ページにすぎない場合、その先の実際のアドレスを使う |
| スキン | 複数のビジュアルスキン。フォントはブラウザが公開 CDN から直接取得するため、サーバーの通信量を消費しない |

## 技術スタックと要件

- **PHP ≥ 7.0**（コードの基準は 7.0。7.1 以降の構文は使いません）
- **MySQL / MariaDB**（InnoDB、`utf8mb4`）
- フロントエンド：ES モジュールのソース → 単一ファイルの成果物。**Node の実行環境は不要**（ビルド時のみ使用）
- Composer 依存なし、フロントエンドフレームワークなし

## デプロイ

```bash
git clone https://github.com/silverbullet-liang/kimi-game-rank.git
cd kimi-game-rank

# 1) メイン設定：テンプレートをコピーしてデータベース接続を記入
cp config/config.sample.php config/config.php
$EDITOR config/config.php

# 2) API キープール：テンプレートをコピーして自分のキーを記入
cp config/api_keys.sample.php config/api_keys.php
$EDITOR config/api_keys.php

# 3) 審査用語リスト：公式リストは非公開のため、サンプルをコピーして自前で整備
cp app/data/moderation_words.sample.txt app/data/moderation_words.txt
cp app/data/moderation_allow.sample.txt app/data/moderation_allow.txt
```

サイトのドキュメントルートを本プロジェクトのルートに合わせ、ブラウザでトップページを開いてください——**初期化は自動で完了します**（データベース・テーブル・キーの生成）。データベースが未準備の場合、ページに明確なメッセージが表示されます。

> 用語リストのファイルが無い場合、審査モジュールは自動的に「何もブロックしない」状態に縮退し、サイトはそのまま動作します。

## 設定ファイル

| ファイル | コミット | 説明 |
|---|---|---|
| `config/config.php` | ❌ **コミット禁止** | データベース接続（メイン + 管理）、サイト情報、AES / cron キー、管理者資格情報 |
| `config/api_keys.php` | ❌ **コミット禁止** | モデル API キープール（Zhipu、OpenRouter） |
| `app/data/moderation_words.txt` | ❌ **コミット禁止** | 審査用語リスト（公式リストは非公開） |
| `config/config.sample.php` | ✅ | メイン設定のテンプレート |
| `config/api_keys.sample.php` | ✅ | キープールのテンプレート |

上記 ❌ の 3 つは `.gitignore` に登録済みです。コミット前に漏洩チェックを実行してください：

```bash
python3 tools/repo_check.py
```

次の 3 点を検査します：禁止ファイルがステージングに混ざっていないか、テキストにキーの指紋が含まれていないか、**データベース接続値が漏洩していないか**。

## ディレクトリ構成

```
├── api/            エンドポイント層（JSON の入口。認証 + CSRF + レート制限）
├── app/            ビジネス層（設定、DB、採点、認証、コンテンツ審査、AI 経路…）
│   └── data/       審査用語リスト（.sample のみ保持）
├── assets/
│   ├── css/        スタイルとスキン
│   ├── docs/       サイト内ドキュメント（公開ページの本文）
│   ├── emoji/      チャット絵文字
│   └── js/
│       ├── src/    フロントエンドのソース（ES モジュール、ページ単位で分割）
│       └── app.js  ビルド成果物（src から生成。直接編集しないこと）
├── config/         設定とキー（.sample のみコミット）
├── docs/           設計・アルゴリズムのドキュメント
├── sql/            テーブル定義
├── standalone/     単体表示ページ（更新履歴 / 転送ページ）
├── storage/        実行時のデータ（キャッシュ、ログ、アップロード、バックアップ）
└── tools/          ビルドと検証のスクリプト
```

フォントはリポジトリに含めず、すべてブラウザが公開 CDN から直接取得します。入手元とライセンスは [FONTS.md](FONTS.md) を参照してください。

## フロントエンドのビルド

`assets/js/src/` 以下のソースを変更したら、必ず再ビルドしてください：

```bash
python3 tools/build.py          # src/* → assets/js/app.js
```

## コミット前のチェック

```bash
python3 tools/phpcheck.py       # PHP の構文と基準チェック
python3 tools/jscheck.py        # フロントエンドの名前衝突チェック
python3 tools/repo_check.py     # 漏洩チェック（キー / 用語リスト / DB 接続）
```
