# 功能说明 — Kimi游戏榜

> 站内「功能说明」正式文案
> 本页逐项说明**每个功能是做什么的、怎么用、有什么规则**。看完这一页，你就能把站点的全部功能用起来。

## 一、功能总览

| 功能 | 面向谁 | 一句话说明 |
|---|---|---|
| 四大榜单 | 所有人 | 按不同口径浏览作品，见第二节 |
| 搜索与作品详情 | 所有人 | 找作品、看六维评分，见第三节 |
| 点赞与评论 | 登录用户 | 为作品和评论点赞、留言，见第四节 |
| 世界对话 | 登录用户 | 全站公开聊天室，见第五节 |
| AI 助手 | 登录用户 | 问答、联网、查天气时间，见第六节 |
| 账号与「我的」 | 登录用户 | 签到、额度、设置、资料，见第七节 |
| 站内表情 | 登录用户 | 聊天与评论使用的表情，见第八节 |
| 反映问题 | 所有人 | 提交反馈、举报与权利主张，见第九节 |
| 控制面板 | 管理员 | 收录、评分、运营维护，见第十节 |

> 未登录时以**游客**身份访问：可浏览全部榜单与作品详情，但**不能**发言、点赞或使用 AI 对话。游客模式随时可在「我的」中升级为账号。

## 二、四大榜单

四个榜型使用**同一批作品、同一套六维评分**，只是排序口径不同：

| 榜型 | 排序依据 | 适合用来 |
|---|---|---|
| **总榜** | 六维总分（满分 1200） | 看综合实力最强的作品 |
| **投票榜** | 站内点赞数 | 看读者最直接喜欢的作品 |
| **诸神榜** | 历史最高总分 | 看「曾经达到的高度」，荣誉性质 |
| **冷门榜** | 热度**最低**优先 | 淘「沧海遗珠」：热度不高但整体不低 |

- 每个榜型都可按分区筛选：**游戏 / 工具 / 文学 / 二创**。
- 总分与排名是**动态**的：作品数据更新后会重算，可能上升也可能因热度衰减而后退。
- 评分的六个维度、公式与评级标准见[《评分标准》](?p=doc&arg=评分标准)；分区判定、收录与移除规则见[《入榜规则》](?p=doc&arg=入榜规则)。

## 三、搜索与作品详情

1. **搜索**：在抽屉菜单点「搜索作品」，可按标题、作者或关键词查找；搜索范围是**已收录**的作品。
2. **AI 总结**：搜索结果页顶部会出现一张 AI 总结卡片，把当次命中的作品整理成摘要——命中了几件、整体成色如何、怎么挑；内容较长时**自动折叠**，点「展开全部」看全文。它只看站内的命中结果，不联网、不编造，**不消耗你的任何额度**；不想要可在「我的 → 搜索」里关闭。
3. **作品详情页**展示：
   - 标题、作者、分区、简介；
   - **六维雷达图**与各维得分（每维 0–200）；
   - 总分与评级（SSS / SS / S / A / B / C）；
   - 互动数据：点赞、评论、收藏；
   - 封面与作品截图；
   - 评论区；
   - **指向社区原作品页的链接**——点开可直达原作。
3. 本站**不存储、不传播作品本体**，只展示公开信息并给出原作链接。

## 四、点赞与评论

1. **点赞**：登录后可对作品与评论点赞。每人对同一个对象**只能点赞一次**；取消后可以再点。
2. **评论**：登录后可对作品发表评论；你可以删除自己的评论（连同其下的回复层级一并移除）。删除后该评论**进入回收站**，页面上不再显示；管理员可在控制面板的「评论回收站」中恢复或彻底清空。
3. **发送前自动审核**：评论与消息在发布前会自动「过三关」——第一关站内词库与句式识别，第二关译成英文后的脏词检测，第三关由分类模型给出 **1–10 的违规档位**（越高越像辱骂攻击）——只有达到拦截档位的才拦下，处在中间档的照常发布、但会在内容旁标注「可能有恶意」（管理员认为标错了可以一键取消）；命中拦截时提示「内容未通过审核」，可修改后重发，认为误判可通过「反映问题」找我们。三关由本站承担，不消耗你的额度。针对 AI 的试探性内容（如「忽略以上指令」这类提示词注入）同样**只作标注、不拦下**。上传图片另有图审：先读图上文字与画面，再交同一分类模型判定。完整判定逻辑已在[《用户协议》](?p=doc&arg=用户协议)第九条公开。
4. **内容规则**：禁止发布违法违规、广告引流、人身攻击、刷屏等内容的评论；管理员可依规则删除、折叠、屏蔽，情节严重者可对账号限权、禁言或封禁。详见[《用户协议》](?p=doc&arg=用户协议)第七条与第九条。

## 五、世界对话

1. 世界对话是**全站公开的聊天室**：登录用户发言，游客只读。
2. 消息会**定时自动刷新**，无需手动刷新页面；你也可以撤回**自己发送**的消息，撤回后不再展示。
3. 支持站内**表情**与**图片**（见第八节）。图片上传前会先做一次内容检查，不符合社区规范的图片会被拒绝并删除；聊天里的图片**点一下即可放大**查看细节。
4. **图片会随消息生命周期自动清理**（省空间）：撤回消息即删图；没人再引用的、以及已经沉到前端展示范围之外的旧消息图片也会一并清掉；图片被清理后显示一张「图片已清理」占位图，不会出现裂图。
4. 对话内容对所有人可见，**请勿在其中发布个人信息**（如手机号、住址、账号密码等）。管理员对违规内容有处置权。
5. **@ 官方 AI**：在消息里输入 `@` 选中「官方AI」，或用输入框旁的 `@` 按钮，即可让官方 AI 回应这条消息。回复以 **AI** 身份出现，通常是 150 字以内的纯文本；其消耗**从发起人的 AI 额度中扣除**（详见《AI 使用说明》第三节）。

## 六、AI 助手

AI 助手是一个**可联网、可查站内数据**的对话式助手：

- **能回答**：知识问答、写作与润色、翻译、代码、思路整理等；
- **能查站内**：搜索作品、查看作品详情与评分、查某作品在榜上的位次、读某作品的评论；
- **能联网**：读取你给出的网页地址，转成正文后阅读并作答；
- **能查实时**：天气（任意城市）与当前时间/日期。

使用要点：

1. 对话前可**选择模型**：默认使用**本站模型**，也可在列表中切换为**免费模型**；
2. 两类模型的**计费方式不同**，额度规则、缓存机制与省额度技巧，见[《AI 使用说明》](?p=doc&arg=AI 使用说明)；
3. AI 回答由算法自动生成，**可能不准确**，不代表本站观点，也不构成任何专业建议。

## 七、账号与「我的」

1. **注册与登录**：使用用户名 + 密码，并需完成一次**人机验证**（点一下即可；验证通道不可用时会自动换一条，不用手动切换）。用户名为昵称，**全站展示且注册后不可更改**（不能包含换行或装饰性特殊字符，并需通过内容审核）；忘记密码请联系管理员。
2. **游客模式**：可不注册直接浏览；登录后可解锁投票、评论与 AI 对话。
3. 「我的」页面包含：
   - **签到**：每日签到可获得 AI 额度加成，连续签到还有额外奖励（具体加成以页面显示为准）；
   - **AI 额度卡片**：显示可选模型数、我的今日次数、全站剩余；
   - **设置**：界面风格（含节日限定主题）、通知开关、访问记录开关、搜索 AI 总结开关等；
   - **节日主题**：国庆、辛亥革命纪念日（10/10）、抗美援朝纪念日（10/25）、万圣夜（10/31）、重阳节（**农历九月初九**，公历日期逐年自动换算）各有**一套独立主题**，到日自动启用、过日自动回退（万圣夜强制暗色）；窗口内手动切走皮肤即不再自动启用；
   - **资料**：头像与个人资料卡；
   - **反馈入口**：直达「反映问题」。
4. **隐私**：你可在设置中**随时关闭访问记录**；已记录的内容也可申请删除。详见[《隐私政策》](?p=doc&arg=隐私政策)。

## 九、反映问题（反馈）

1. **入口**：「我的 → 反映问题」，或抽屉菜单中的「反映问题」。
2. **可提交的内容**：功能异常与报错、内容纠错、举报违规、作品的推荐与移除请求、**版权权利主张**等。
3. 提交时**建议附上**：涉及的作品或页面、问题描述、必要的截图或链接。可选「**仅管理员可见**」。
4. 处理：管理员会在「回复反馈」中答复；一般性问题我们会尽快处理。
5. **涉及个人信息或权利主张**时，请按[《隐私政策》](?p=doc&arg=隐私政策)第十八条、[《用户协议》](?p=doc&arg=用户协议)第八条的要求提供必要材料。

## 十、控制面板（仅管理员）

控制面板是**管理员专用**的运营后台，用于收录与同步作品、重算评分、维护数据、处理反馈与公告、管理用户等。

- 普通用户**不需要**也无法进入；该界面**不接受通过地址参数直达**，必须由站内入口进入并二次验证。
- 统计中，**AI 用量按通道分账**：「本站模型」与「模型网关」分别统计 tokens 与调用次数，并附按账号的用量排行。
- 数据维护上有**一键备份**：把全站数据导出成一个 SQL 文件存在服务器上，可随时**下载**到本地留存，也可删除旧备份。单份上限 1GB。备份含账号与评论数据，**下载需管理员鉴权**，请妥善保管、用完及时删除。
- 数据维护上还有**评分方式开关**：默认「只更新信息」——已收录作品在更新时只改信息（标题、简介、封面、互动数等），**不覆盖评分**，方便按实际情况调分；**新收录的作品仍会自动评分**。需要把老作品按算法重算时，由**总管理员**切到「自动评分」再点一次「全部更新」（**副管理员只能查看，不能切换**）。
- 另有**智能链接识别（默认开启）**：作品页若只是个跳转页（一句提示加一个按钮、一段介绍加一个按钮，或一段加载动画后自动跳转），会自动尝试改用其中的真实作品地址；GitHub Pages 与各 AI 平台的作者子站一律视作真实作品页，不会被替换。
- 这两个开关**副管理员同样可用**（他们负责收录与更新作品）。
- 另有**违纪通报**：站长可在用户列表里对某个用户一键通报 —— 勾选多条理由（可补写）、选择封禁时长（含永久，**支持小数天**如 0.5 天 = 12 小时），并可一并封禁访问来源、删除其全部评论、对话与图片。被通报者可照常打开站点甚至**登录**（方便看清处理结果），但前端会**整体锁定在违纪通知界面**，且除该界面外的一切功能都由**服务端统一拒绝** —— 改地址、换设备都绕不过去。「违纪通报」页则公开列出全部处理记录，讨论集中在列表页下方一处；被通报者看不到讨论区，也无法发言。单次封禁满 7 天才计入累计，累计达 10 次的账号会被永久删除；**账号被永久删除时，针对它的 IP 封禁同时取消并清出名单**。被封来源另有**误伤保护**：同一出口地址（学校、公司、公共网络）常被多人共用，被限制者可在通知界面点「校验我的位置」，先阅读说明再决定是否授权定位；若与限制区域相距较远（容差约 30 公里），判定为不同的人并恢复正常访问。不授权则按原有规则处理。
- 另有**改名**：站长可在用户列表里给任意用户改名（2–64 个字符，须与现存用户名不重复、不占用系统保留名，且不能包含换行或装饰性特殊字符，并通过内容审核）。**改过名的用户，其违纪通报会同时显示「原名 + 现名」**——通报记录的是改名当时的名字，改名不会改写它，一并显示现名是为了让通报还能对上人。
- 因此，你在菜单中看不到它属于**正常现象**。

## 十一、常见问题

1. **为什么我看不到「控制面板」？** 它是管理员专用界面，见第十节。
2. **为什么我点不了赞、发不了言？** 请确认是否已登录（游客只能浏览）。
3. **分数和排名为什么会变？** 评分是动态的，作品数据更新后会重算，详见[《评分标准》](?p=doc&arg=评分标准)。
4. **AI 用不了了，提示次数用完？** 见[《AI 使用说明》](?p=doc&arg=AI 使用说明)第四节，额度按自然日重置。
5. **我的作品没被收录 / 分类不对？** 见[《入榜规则》](?p=doc&arg=入榜规则)，可通过「反映问题」告知我们。
6. **找不到想看的说明？** 欢迎通过「反映问题」提出，我们会补充到文档中。
7. **搜索页没有出现 AI 总结？** 三种正常情况：该关键词没有命中作品；你已在「我的 → 搜索」里关掉了它；或站点当日的总结次数已用尽（次日恢复）。
