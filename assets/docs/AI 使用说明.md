# AI 使用说明 — Kimi游戏榜

> 站内「AI 使用说明」正式文案
> 本页说明 AI 助手**能做什么、额度如何计算、怎样更省额度**，以及相关的数据与免责说明。

## 一、AI 助手能做什么

AI 助手是一个可联网、可查站内数据的对话式助手：

| 能力 | 说明 |
|---|---|
| 知识问答 | 常识、写作与润色、翻译、代码、思路整理等通用问题 |
| 查站内作品 | 搜索作品、查看作品详情与六维评分、查某作品在榜上的位次、读某作品的评论 |
| 联网读网页 | 给出一个网页地址，助手会读取其正文后作答 |
| 查天气 | 任意城市的天气 |
| 查时间 | 当前时间、日期、星期 |

- 同一条提问中，助手**最多可同时调用 3 个查询**，并在失败时自动重试（最多 2 次）后作答。
- 出于安全考虑，部分地址（如内网地址）不会被读取。

除对话式助手外，**搜索结果页顶部**还会出现一张 **AI 总结卡片**：它把当次搜索命中的站内作品整理成一段摘要（命中了几件、整体成色如何、怎么挑），用于快速判断这批结果值不值得点进去。这张卡片与助手是两套独立机制：它**只看站内命中结果**，不联网、不读站外内容、也不接受追问；开销由本站承担，**任何情况下都不消耗你的额度**——见第三节第 3 条。

## 二、两种模型与计费方式

对话前可选择模型，两者**计费方式完全不同**：

| | 本站模型（默认） | 免费模型 |
|---|---|---|
| 来源 | 本站接入的模型 | 由模型网关提供的**免费**模型 |
| 计费方式 | 按 **token（字数）** 计量 | 按 **次数** 计量 |
| 是否消耗次数额度 | 否 | 是 |
| 适合场景 | 长回答、多轮追问 | 想省 token、偶尔使用 |

> 「我的」页面顶部有一张 **AI 额度卡片**，实时显示：可选模型数量、我的今日次数、全站剩余。以该卡片显示的数值为准。

## 三、额度计算规则

### 1. 本站模型：按 token 计量

- **每日基础额度**：100,000 tokens
- **每月基础额度**：3,000,000 tokens
- **签到加成**：
  - 每日签到：**当日**额度 +1,000 tokens；
  - 连续签到满 7 天：**当月**额度 +100,000 tokens。
- 计量方式：按本次对话**实际消耗的 token**（输入 + 输出）累计，逐年逐月累加，用完即止。

### 2. 免费模型：按次数计量（双重限制）

使用免费模型时，必须**同时**满足下面两个条件：

1. **每人每日次数**：默认 **2 次**（超过后提示「今日免费模型次数已用完」）；
2. **全站每日总额度**：由模型服务方**实时返回**，免费档通常为**每天 50 次**；若本站账户额度更高，可选次数也更多（超过后提示「全站今日免费模型额度已用完」）。

**是否会重复扣次数**：不会。提问时先校验、通过后占用一次；若因全站额度不足导致本次未能调用，个人计数会被**退回**。

### 3. 什么情况不消耗额度

- **缓存命中**：若你的问题是**新对话的第一问**、且此前已有人问过并获得答案，系统会**直接沿用**既有答案，**不调用模型、不消耗任何额度**（见第四节）。
- **提问被拒绝或未能开始**：如内容为空、被限流拦下，均不计入额度。
- **搜索结果页的 AI 总结**：这张卡片由本站承担开销，与你的每日次数、个人 token **完全无关**；无论你是否登录、免费次数是否用完，它都照常出现（可在「我的 → 搜索」里关掉）。
- **内容审核**：评论与消息发送前的「过三关」自动审核（第三关为 1–10 档的违规程度分级）以及图片上传审核，同样由本站承担，**不消耗你的任何额度**，也不占用你的免费模型次数；其判定逻辑已在[《用户协议》](?p=doc&arg=用户协议)第九条公开。

### 4. 额度重置时间

额度按**自然日**重置，以国际标准时间（UTC）计，即**北京时间每天上午 8:00** 恢复新的一天额度。本月 token 额度按月重置。

### 5. 其它限制

- **频率限制**：为避免滥用，短时间内连续提问会被限流（约每分钟 6 次），稍等片刻即可继续。
- **管理员**：管理员账号不受上述额度限制。

## 四、缓存机制（省时间、省额度）

1. **什么会被缓存**：只有**不依赖站内数据、不联网查询的纯知识型回答**才会进入缓存——即「新对话的第一问」，且回答过程中**没有调用任何查询工具**。
2. **什么不会被缓存**：涉及实时内容的回答（天气、时间、榜单数据、网页内容等）**不缓存**，以免你拿到过期结果。
3. **命中的好处**：直接从缓存返回，**更快、不花额度**，且同类问题答案保持一致。
4. **如何让缓存更容易命中**：把**独立的知识型问题作为新对话的第一句**提出（例如「什么是六维评分」）；若在已有上下文的对话中提问，系统会按正常流程调用模型。
5. **搜索总结另有一套缓存**：同一个关键词只生成一次，之后所有人（含游客）都直接读缓存，因此不消耗任何额度。缓存以「关键词 + 命中条数」为准——一旦站内作品增删或被改名导致条数变化，旧摘要立即作废并重新生成，不会拿过期的数字糊弄你。

## 五、怎样更省额度

1. **短问题用免费模型**：日常的小问小答走免费模型，把 token 额度留给需要长回答的场景。
2. **优先问新对话的第一问**：纯知识型问题单独开一个对话提出，有机会走缓存、不花额度。
3. **别让助手反复查同一件事**：同一条消息里把需求一次说清，减少工具调用轮次。
4. **按时签到**：签到能实打实地增加当日与当月额度。
5. **不需要联网就明说**：例如直接问「用你自己的知识回答」，可减少联网与查询开销。
6. **清空不需要的历史**：对话历史越短，输入侧消耗越少；「我的」页面可清空对话记录。

## 六、数据、隐私与记录

1. **提问会发送给模型服务方**：为生成回答，你的提问内容会发送至相应的模型服务提供方。相关说明见[《隐私政策》](?p=doc&arg=隐私政策)第八条。
2. **不要在对话中输入敏感信息**：如身份证号、银行卡号、密码、健康信息等。因主动提交敏感信息所致的后果由你自行承担。
3. **记录与清空**：你的对话记录与用量保存在你自己的账号下，可在「我的」页面查看，并可随时清空。
4. **缓存不含个人信息**：缓存以**问题与答案**为对象，不含你的账号信息。

## 八、常见问题

1. **提示「今日免费模型次数已用完」怎么办？** 每人每日免费模型的次数已用尽，可**改用本站模型**（按 token 计），或等次日额度重置后再用。
2. **提示「全站今日免费模型额度已用完」怎么办？** 全站当日的免费额度已被所有用户用完，可改用本站模型，或次日再来。
3. **为什么同一个问题这次没花额度？** 很可能命中了缓存——新对话的第一问、且此前有人问过相同问题，见第四节。
4. **额度为什么重置得和我想的不一样？** 额度按 UTC 自然日重置，即北京时间每天上午 8:00，见第三节第 4 点。
5. **本站模型和免费模型哪个更好？** 两者来源不同、能力侧重不同，也都可能出错。免费模型按次数更省钱，本站模型适合长回答与多轮追问。
6. **管理员也会用完额度吗？** 不会，管理员账号不受额度限制。
