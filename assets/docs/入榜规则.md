# 入榜规则 — Kimi游戏榜

> 站内「入榜规则」正式文案
> 本页说明**什么作品可以入榜、如何入榜、如何查重更新、以及什么情况下会被移除**。

## 一、总则

本站是面向 **[Kimi 社区](https://www.kimi.com)公开作品**的第三方兴趣榜单。作品信息与评分由系统依据公开数据**自动整理与计算**，旨在让好作品被更多人看到，不涉及任何商业合作与利益关联。

## 二、什么作品可以入榜

一件作品需要**同时满足**下列条件：

1. **来源可公开访问**：发布在 [Kimi 社区](https://www.kimi.com)、可通过公开链接访问的作品。
2. **信息完整**：具备可识别的标题与基本介绍。**空壳、占位、测试、无法访问的作品不予收录。**
3. **内容合规**：不含法律法规禁止的内容，不违反社区公序良俗。
4. **未被收录**：该作品在库中尚不存在（同一作品只保留一条，按社区作品 ID 判定）。
5. **具备可评价性**：至少能取到一部分用于评分的信息（标题、文本或作品文件）。

> 本站不要求作者主动申报，也不要求作品"报名"；收录是**系统整理**的结果。

## 三、分区规则

作品按内容类型归入四个榜单。判定**有明确优先级，依次为**：

**二创 ＞ 文学 ＞ 工具 ＞ 游戏**

| 分区 | 面向的作品 |
|:---:|---|
| 💬 二创榜 | 基于已有 IP 或作品的二次创作 |
| 📖 文学榜 | 小说、剧本、设定集等以文字叙事为主体的作品 |
| 🔧 工具榜 | 实用工具、效率类、插件、脚本、生成器等 |
| 🎮 游戏榜 | 可玩的游戏类作品 |

**判定依据**（依据作品标题与简介中的表述）：

- **二创**：出现「改编自 / 原作者是 / 同人 / 二创 / 番外 / 衍生 / 设定集 / 平行世界 / 致敬」等从属或二次创作表述。
- **文学**：出现「小说 / 文学 / 散文 / 诗歌 / 连载 / 短篇 / 章节 / 文集 / 随笔」等以文字叙事为主体的表述。
- **工具 / 游戏**：各自有对应判定词（工具 / 插件 / 脚本 / 助手 / 生成器；游戏 / 玩法 / 关卡 / 对战 / 解谜）。

**兜底规则**：以上三类都不命中时，**一律归入游戏榜**。游戏是本站的主力分区，作为兜底可最大限度避免作品被误分；因此"说不清分类"的作品出现在游戏榜属于**正常结果**，而非错误。

**优先级为何这样排**：「改编自某小说的同人游戏」首先属于二创，而不是游戏。顺序颠倒会把大量二创作品错分到游戏榜。

> 管理员可在控制面板预览「按规则将如何重分」后再执行；**预览与执行使用同一套判定逻辑，所见即所做**。

## 四、如何入榜

收录由**管理员**统一操作，普通用户暂不能直接提交作品：

1. **手动收录**：管理员按作品 ID 从社区拉取作品信息入库。
2. **自动同步**：管理员开启自动模式后，系统按社区信息流批量发现新作品并记录入库。

作品入榜时的标题、简介、封面与六维评分均由系统**自动生成**，无需作者操作。若你希望推荐某件作品，可通过站内「反映问题」告知我们。

## 五、查重与更新

1. **唯一性**：同一作品在库中只保留一条，按**社区作品 ID** 查重。
2. **增量更新**：已入库的作品再次被发现时，只更新**发生变化**的字段（标题、简介、互动数据、封面等），不重复建条。
3. **自动重算**：更新后**重新计算六维分数**。
4. **历史保留**：系统记录作品的**历史最高总分**，作为「诸神榜」的排序依据；历史记录不因单次重算而丢失。
5. **排名动态**：总分变化会实时反映在榜单排名中——作品可以「逆风翻盘」，也可能因热度衰减而后退。

## 六、四个榜型的口径

| 榜型 | 排序依据 | 说明 |
|:---:|---|---|
| 总榜 | 总分（六维之和） | 综合实力排序，主榜 |
| 投票榜 | 站内点赞数 | 体现读者的直接喜爱程度 |
| 诸神榜 | 历史最高总分 | 荣誉榜，记录曾经达到的高度 |
| 冷门榜 | 热度**最低**优先 | 沧海遗珠：热度不高但整体不低，值得被看见 |

每个榜型都可按分区（游戏 / 工具 / 文学 / 二创）筛选。

## 七、作品展示字段

一件作品在站内通常展示：标题、作者、分区、六维雷达图与各维分数、总分与评级、互动数据（点赞 / 评论 / 收藏）、简介、封面与截图、评论区，以及指向原作品的链接。点开链接可直达社区原作品页。

## 八、移除规则

出现下列情形之一的，作品会被移出榜单（下架）：

1. **作品在社区被删除、设为不可见或链接失效**；
2. **涉嫌抄袭、侵权、刷分等违规行为**，经核查属实；
3. **内容违反法律法规或社区公序良俗**；
4. **作者本人向管理员申请移除**；
5. **长期失效**：多次同步均无法获取有效信息的作品；
6. **其它**：管理员基于运营与合规需要，依合理判断下架的作品。

> 说明：多数"移除"为**隐藏（下架）**处理，即不再在榜单展示，而非物理删除数据，以便在误判或申诉后恢复。被删除的内容与数据处置，另见[《用户协议》](?p=doc&arg=用户协议)与[《隐私政策》](?p=doc&arg=隐私政策)。

## 九、纠错与申诉

1. **信息有误**：若收录的标题、简介、作者、封面等信息有误，请通过站内「反映问题」指出，并尽量附上原始链接与正确信息。
2. **作为作者要求修改或移除**：欢迎通过「反映问题」联系我们，建议附上**可证明权属的材料**（如社区作品页截图），我们将在核实后处理。
3. **对分区或评分有异议**：分区依第三节规则自动判定；评分依[《评分标准》](?p=doc&arg=评分标准)算法自动计算。若你认为规则本身存在明显漏洞，欢迎提出，我们会在评估后调整**规则**（而非个案调分）。

## 十、免责声明

1. 本站为**社区兴趣榜单**，评分由算法自动生成，**仅供浏览与交流参考，不代表任何官方评价、背书或推荐**。
2. 收录作品的信息来自公开渠道，**可能存在错漏或滞后**；如发现错误，欢迎通过「反映问题」告知，我们将及时更正。
3. 作品的著作权归原作者或权利人所有；本站仅展示公开信息并提供原作品链接。**如有侵权，请权利人通过「反映问题」联系我们，我们将在核实后依法及时更正、删除或断开链接。**
4. 本规则可能随社区生态与运营需要调整，调整后在本页公示。

## 十一、常见问题

1. **作品没被收录，能自己提交吗？** 收录由管理员统一操作；普通用户可通过站内「反映问题」推荐，我们会视情况处理。
2. **为什么我的作品被分到了游戏榜？** 分区依第三节优先级判定；三类都不命中时**兜底归游戏榜**。若分类明显不当，欢迎反馈。
3. **分数会变吗？** 会。互动数据与作品信息更新后系统会重新计算；诸神榜记录的是历史最高总分。
4. **能买分或刷分吗？** 不能。刷分行为一经查实，作品将被下架，账号亦可能被处理，详见[《评分标准》](?p=doc&arg=评分标准)第十节「防刷分机制」。
5. **作品被移除了，还能恢复吗？** 多数移除为**隐藏处理**，若属误判或申诉成立，可恢复展示。
6. **本站与 Kimi 官方是什么关系？** 无隶属或合作关系。本站为第三方兴趣榜单，作品数据来自 [Kimi 社区](https://www.kimi.com)的公开信息，不代表其官方立场。
