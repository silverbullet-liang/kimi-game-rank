# 隐私政策

本站（「Kimi游戏榜」）尊重并保护每一位访问者的个人信息。本政策依据[《中华人民共和国个人信息保护法》](https://flk.npc.gov.cn/)、[《中华人民共和国网络安全法》](https://flk.npc.gov.cn/)、[《中华人民共和国数据安全法》](https://flk.npc.gov.cn/)等法律法规，说明我们收集哪些信息、为何收集、如何使用与保护，以及你依法享有的权利。

**请在使用本站前仔细阅读本政策。注册、登录或以游客身份访问本站，即表示你已理解并同意本政策。**

## 一、引言与适用范围

1. 本政策适用于你通过网页、移动浏览器等任何方式访问和使用本站服务的过程。
2. 本政策**不适用于**第三方通过本站链接跳转后自行收集信息的行为，该等行为适用相应第三方的隐私政策。
3. 本政策为《用户协议》不可分割的组成部分。本政策与《用户协议》不一致时，就个人信息保护事项以本政策为准。

## 二、个人信息处理者

1. **处理者**：本站由个人开发者独立运营，为个人信息的处理者。
2. **联系方式**：有关个人信息的任何事项，可通过站内「反映问题」（可选择"仅管理员可见"）或联系站长 `admin`。
3. 本站**不设**个人信息保护专职机构；因规模所限，相关请求由运营者直接处理，我们将在合理期限内（通常不超过 15 个工作日）回复。

## 四、我们如何收集信息

1. **你主动提供**：注册、登录、发帖、评论、上传图片、提交反馈、使用 AI 对话时提交的信息。
2. **自动收集**：你访问本站时，服务器自动记录必要的技术信息（如获取访问来源 IP、请求时间）；用于访问归属地解析的 IP 会被发送至第三方查询服务（详见第八条）。
3. **本地存储**：浏览器 Cookie 与 `localStorage` 中保存的登录态与偏好（详见第七条）。
4. 我们**不会**通过第三方统计、广告或社交插件 SDK 被动收集你的行为数据。

## 五、我们处理个人信息的目的与法律依据

我们处理个人信息的法律依据包括：**你的同意**、**履行你作为一方的合同所必需**、**履行法定义务所必需**，以及在合理范围内为**保障服务安全所必需的合法利益**。

具体处理目的如下：

1. 提供、维护与改进服务功能；
2. 完成身份识别、登录校验与权限控制；
3. 保障服务安全：限速、防刷、反垃圾、异常与攻击行为识别；
4. 统计访问与使用情况（以**汇总、去标识化**形式）；
5. 履行法律法规规定的义务，配合监管部门依法开展的调查。

**我们不会**将你的个人信息出售、出租，或用于与本站服务无关的广告画像与自动化推销。

**例外情形**：依照法律法规，在下列情形中我们处理你的个人信息**无需取得你的同意**：为履行法定职责或法定义务所必需；为应对突发公共卫生事件或紧急情况下为保护自然人生命健康、财产安全所必需；在合理范围内处理你自行公开或已合法公开的信息；法律法规规定的其它情形。

## 六、关于敏感个人信息与自动化决策

1. **敏感个人信息**：本站**不以任何功能为目标收集**敏感个人信息（生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹及不满十四周岁未成年人的个人信息等）。若你的某些操作可能导致敏感信息被处理，我们会在处理前以显著方式提示并取得你的**单独同意**。
2. **自动化决策**：本站的榜单排序与评分**基于作品公开数据与固定算法计算，不针对你个人进行自动化决策**；本站**不进行**基于个人信息的个性化推荐、用户画像或差异化定价。
3. 评论区的内容屏蔽为**由你自行配置、仅在本机生效**的功能，不涉及服务端对你个人信息的自动化处理。
4. **内容审核说明**：评论、消息与上传图片的内容审核由系统自动判定（规则见[《用户协议》](?p=doc&arg=用户协议)第九条）。该判定**只针对内容或图片本身**，不分析你的身份、行为或个人信息，不构成对你个人在信用、能力等方面的自动化评价，也不影响你在本站的其它权利；审核结果仅决定该条内容或图片是否发布；处于中间档位的会在内容旁标注提示（该标注不影响发布，管理员可取消）。

## 九、IP 地址的特别说明

1. **采集目的**：仅用于安全防护（登录限速、防刷、异常排查）与访问来源统计。
2. **脱敏存储**：数据库中仅保存 IP 的**前 3 个字符与后 2 个字符**（例如 `114****89`），中间字符以掩码替代，**无法据此还原完整地址**。
3. **登录限速**：限速校验使用 IP 的**不可逆哈希值**，而非 IP 明文。
4. **自主控制**：你可在「我的 → 设置」中随时**关闭访问记录**。关闭后不再记录新的访问条目；已记录的条目你也可申请删除。
5. **归属地解析**：为获得归属地与运营商信息，IP 会发送至第三方归属查询服务（详见第八条），该服务仅接收 IP 本身，不接收你的账号信息。
6. **人机验证**：登录或注册时的人机验证由第三方公共实例提供，验证过程会向其发送你的访问 IP；验证完成后本站仅保存一次性校验结果，不额外保存该服务返回的信息。

3. **跨境合规**：我们会依据适用法律，采取合理措施保障跨境传输中个人信息的同等保护水平；如法律要求履行相应出境程序，我们将依法履行。

## 十一、信息安全措施

1. **密码保护**：用户密码以**不可逆的加密摘要**形式存储（加盐慢哈希），**服务端无法还原明文密码**。
2. **凭证隔离**：管理账号的凭证与普通业务数据**分开保管**，并采用额外的校验与验证措施。
3. **传输与存储安全**：全站强制 HTTPS；数据库采用最小权限账号访问；管理后台的敏感操作需二次验证。
4. **服务端校验**：所有校验、归一化与敏感处理均在服务端完成，前端仅负责展示与数据传递。
5. **权限最小化**：仅有运营者本人因运维需要可接触数据。
6. **风险提示**：我们会采取合理的技术与管理措施保护数据，但**没有任何系统能保证绝对安全**。
7. **安全事件应对**：若发生个人信息泄露、篡改、丢失等安全事件，我们将立即采取补救措施，并按适用法律要求，以站内公告、页面提示等合理方式向你告知事件基本情况、可能影响、已采取的处置措施及你可采取的防范建议；必要时向监管部门报告。
8. **数据备份**：为防止数据丢失，管理员可对站点数据制作整体备份。备份文件存放于**不可通过网址直接访问**的位置，下载须经管理员鉴权；备份仅用于灾备与迁移，不作其它用途。

| 数据库备份 | 由管理员按需创建；删除后即从服务器移除，站点不另行保留副本 |

2. 超过保留期限的，我们将删除或匿名化处理。

## 十三、你的权利

依据《个人信息保护法》等法律，你对自身个人信息享有以下权利：

- **知情与决定**：了解并决定你的个人信息如何被处理，可限制或拒绝特定处理。
- **查阅与复制**：在「我的」页面查看账号信息、AI 用量与访问记录；可申请获取个人信息的副本。
- **更正与补充**：通过「反映问题」申请更正不准确的信息（用户名作为唯一标识一经创建不可更改）。
- **删除**：删除自己的评论与对话消息；在法定情形下（如处理目的已实现、你撤回同意、我们违法处理等）可要求删除个人信息。
- **注销**：申请注销账号；注销后我们将在合理期限内删除或匿名化你的账号及关联数据。
- **撤回同意**：关闭通知、关闭访问记录，或退出登录转为游客身份。撤回同意不影响撤回前基于同意已进行的处理。
- **可携带**：在技术上可行且法律要求的情况下，可申请将你的个人信息转移至你指定的处理者。
- **解释说明**：要求我们说明个人信息处理规则。
- **投诉举报**：向本站投诉、举报，或依法向监管部门反映。

行使上述权利的，请通过本政策联系方式提交，我们将在合理期限内处理并回复。

## 十七、术语说明
