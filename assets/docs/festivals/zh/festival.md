# 国庆

## 简介

10月1日为中华人民共和国国庆日。1949年10月1日下午三时，开国大典在北京天安门广场举行，中华人民共和国中央人民政府宣告成立。1949年12月2日，中央人民政府委员会第四次会议通过《关于中华人民共和国国庆日的决议》，采纳中国人民政治协商会议第一届全国委员会的建议，规定每年10月1日为国庆日。这套皮肤是跨九天的窗口主题，自9月30日至10月8日显示，把烈士纪念日与国庆假期连在同一段里。

## 由来

1949年10月1日下午三时，开国大典开始，毛泽东在天安门城楼上宣读公告，随后按动电钮升起第一面五星红旗，五十四门礼炮齐放二十八响，接着是阅兵与群众游行。1949年至1959年，每年国庆都举行阅兵；此后按「五年一小庆、十年一大庆」安排，1984年、1999年、2009年、2019年举行过阅兵。1999年国务院修订《全国年节及纪念日放假办法》，国庆的法定假日由一天改为三天，经调休连成七天，长假由此成为制度。2020年前后，国庆与中秋有时落在同一段假期里。

## 习俗

1. **升国旗**：天安门广场的升旗按日出时刻进行，国庆当天观礼的人最多。
2. **阅兵与群众游行**：逢大庆之年举行，徒步方队、装备方队与空中梯队依次通过广场。
3. **悬挂国旗**：机关、学校、商铺与住户在门口或窗前挂旗，街道两侧成排。
4. **出行与返乡**：七天长假是全年出行最集中的两段之一，景区、铁路、公路都在高位运行。
5. **广场花坛与夜景**：天安门广场每年布置主题花坛，夜间开放灯光。

## 故事

开国大典留下的细节里，常被提起的有三件：下午三时这个开始的时间，是考虑到防空而定的；升旗用的是电动装置，毛泽东按动电钮，旗沿旗杆升起；五十四门礼炮齐放二十八响，炮声与升旗同时。当天广场上聚集了三十万人，阅兵的战机中有四架是带弹受阅的。这些细节见于当年的报道与后来的口述史料，成为了解那一天的主要入口。

## 主题

这套皮肤是红与金的两色：红色做底，金色做线与边，几何块面在其中排布，像旗帜、灯笼与彩带的抽象。它不指向某一个具体物件，只把庆典的浓度提上来；又因为窗口横跨九天，这套颜色要在国庆前后的日常里连着出现，与前后两套安静的主题相接。
