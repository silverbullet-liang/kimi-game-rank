# 感恩节

## 简介

美国的感恩节在11月第四个星期四；加拿大因收获季更早，定在10月第二个星期一。美国感恩节的假期通常从星期四延续到星期日，次日的购物日被称为「黑色星期五」。核心内容是家庭聚餐与表达感谢，餐桌上的主菜是烤火鸡。

## 由来

1789年，华盛顿曾宣布一个全国性的感恩日；此后很长一段时间里，日期由各州自定。1863年，正值内战期间，林肯宣布11月最后一个星期四为全国性的感恩节。1941年，美国国会通过法案，把日期固定为11月第四个星期四，1942年起实行。加拿大方面，1957年1月31日议会宣布每年10月的第二个星期一为感恩节，主要与丰收相连。

## 习俗

1. **家庭晚餐**：烤火鸡、填料、蔓越莓酱、土豆泥、焗南瓜与南瓜派，菜单在19世纪逐渐定型。
2. **游行**：纽约的梅西感恩节大游行自1924年起举行，巨型气球、花车与乐队依次通过。
3. **橄榄球**：午后开赛，电视直播，是许多家庭的固定背景声。
4. **赦免火鸡**：白宫在节前赦免两只火鸡，20世纪后期起成为惯例。
5. **志愿与捐赠**：食物银行、社区餐会与募捐在这一天前后最集中。

## 故事

通行的叙述是1621年：上一年乘「五月花号」到达的清教徒经历了一个严冬，死者近半；次年他们在当地原住民的帮助下学会种玉米与捕鱼，秋收之后与万帕诺亚格人一同举行了为期三天的庆祝。这一叙述见于后世的地方志与回忆录，具体细节已难确证。万帕诺亚格人的后裔自1970年起，在感恩节当天于普利茅斯举行「全国哀悼日」活动，纪念殖民带来的损失。两种纪念在同一天、同一地点并行，这是这一天在今天的样子。
