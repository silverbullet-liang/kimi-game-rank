# 1024 程序员节

## 简介

10月24日是民间通行的中国程序员节。1024是2的十次方，也是存储换算的基数：1KB=1024字节，1MB=1024KB。日期写作10/24，与1024同形，因此定在这一天。它不是法定假日，由技术社区与从业者约定俗成，各公司各社区自己安排。

## 由来

国际上通行的程序员节出自俄罗斯。2002年，程序员瓦连京·巴尔特征集签名，向俄罗斯联邦政府请愿设立程序员节；2009年9月11日，时任总统梅德韦杰夫签署法案，把每年的第256天定为程序员节——平年为9月13日，闰年为9月12日。256是一个字节能表示的数量，因此这个日期会随闰年移动。中国选择了另一种算法。2010年前后，博客园、CSDN 等技术社区在网上发起「把10月24日定为中国程序员节」的讨论与投票；2015年前后，培训机构与互联网公司陆续跟进，成为行业内的固定日子。2020年起，长沙每年举办「中国1024程序员节」，设论坛与展台。

## 习俗

1. **公司内部活动**：技术分享、内部赛事、发放纪念品，也有公司把这一天当作年度技术开放日。
2. **论坛与开发者大会**：项目集中发布、开源仓库提交量在这一天前后上扬。
3. **不加班的倡议**：部分机构在这一天提出按时下班，这条倡议比节日本身更容易被记住。
4. **用技术动作过节**：写一行代码、提交一次 commit、修一个旧 bug，都是通行的过法。
5. **数字梗**：1024、1G=1024M 与「一级」谐音，互为口采。

## 故事

通常被称为第一位程序员的是阿达·洛芙莱斯。1843年，她为巴贝奇分析机的一篇论文所写的注释里，给出了一组计算伯努利数的步骤，被视为最早的算法描述之一，她也在注释中讨论了机器能否作曲的问题，比机器真的能作曲早了一百多年。她的名字与这一天的联系在于：一个程序员的节日，追到头来会追到一位女士写的注释上。
