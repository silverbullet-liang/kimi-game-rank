# 上巳节

## 简介

农历三月初三，古称上巳，又称重三、三月三、修禊日。先秦以三月上旬的巳日为节，魏晋以后固定在三月初三。旧时这一日人们到水边洗濯、宴饮、踏青，是春季临水祈福的日子。汉族地区今已少见，广西等地仍以三月三为盛大的歌节。

## 由来

上巳出自先秦的水滨祓禊之俗。《周礼》记「女巫掌岁时祓除衅浴」，即以香草和汤洗浴洁身；《论语·先进》载曾皙之志「暮春者，春服既成……浴乎沂，风乎舞雩，咏而归」，可见三月临水沐浴、迎春祈福的风气由来已久。汉代定为节令，《后汉书·礼仪志》称三月上巳「官民皆絜于东流水上，曰洗濯祓除，去宿垢疢，为大絜」。魏晋以后为便于行用，日期改定三月初三；《荆楚岁时记》记「士民并出江渚池沼间，为流杯曲水之饮」，节俗由祓除转向临水宴游。

## 习俗

1. **祓禊**：到河湖之滨以流水洗濯，去垢除秽，古人以为可去疾病不祥。
2. **曲水流觞**：于环曲的水渠旁列坐，上游置酒杯任其顺流而下，杯停在谁面前，谁即取饮并赋诗。
3. **踏青游春**：三月春和，士女出城临水而行，采兰草、佩香草，谓之春禊。
4. **荠菜煮鸡蛋**：湖南、湖北一带旧俗，以开花的老荠菜煮蛋，取祛湿之意。
5. **对歌赶圩**：广西等地三月三歌圩，男女对歌、抛绣球、做五色糯米饭。

## 故事

据《兰亭集序》，东晋永和九年（353）三月初三，王羲之与谢安、孙绰等四十余人在会稽山阴的兰亭修禊。众人临曲水列坐，一觞一咏，得诗若干，王羲之乘兴作序，文中「引以为流觞曲水，列坐其次」一句，成为后世曲水流觞之典。另有一说相传三月三为黄帝诞辰，旧有「三月三，生轩辕」之语，河南新郑等地至今于此日恭祭黄帝。
