# 抗美援朝纪念日

## 简介

10月25日为中国人民志愿军抗美援朝出国作战纪念日。1950年10月19日，中国人民志愿军入朝；10月25日，志愿军第40军第118师在两水洞、丰下洞地区与向北镇方向推进的南朝鲜军第6师一部遭遇，打响入朝后的第一仗，当夜至26日凌晨占领温井。1951年，中共中央决定将10月25日定为抗美援朝纪念日。1953年7月27日，《朝鲜停战协定》在板门店签署；1958年，志愿军全部撤离朝鲜。

## 由来

1950年6月，朝鲜半岛战事爆发，美国随即武装介入，并派第七舰队进入台湾海峡。9月仁川登陆后，联合国军向北推进，10月初越过三八线，战火逼近鸭绿江。10月，中共中央作出出兵决定，组成中国人民志愿军，10月19日渡江入朝。10月25日上午，第118师在两水洞、丰下洞一带的谷地伏击北进之敌，经约一小时战斗，将南朝鲜军第6师第2团一个营及一个炮兵中队歼灭，随后乘胜攻占温井。第一次战役由此展开，战线在当年年底回到三八线附近。1951年，中共中央根据志愿军政治部的建议，把两水洞战斗的日期定为纪念日。

## 习俗

1. **陵园祭扫**：沈阳抗美援朝烈士陵园建于1951年，安葬有黄继光、杨根思、邱少云等烈士，每年这一天前后有祭扫与献花。
2. **迎回遗骸**：自2014年起，在韩中国人民志愿军烈士遗骸分批回国，安葬于沈阳抗美援朝烈士陵园，仪式在每年秋季举行。
3. **纪念大会与纪念章**：逢十周年举行纪念活动；2020年颁发「中国人民志愿军抗美援朝出国作战70周年」纪念章。
4. **两地纪念**：2019年10月25日，中朝两国代表在平壤友谊塔前敬献花圈。
5. **口述史与档案**：近年有老兵口述、战地书信与档案的整理与出版。

## 故事

1951年4月11日，魏巍的报告文学《谁是最可爱的人》在《人民日报》刊出，写的是朝鲜战场上的普通士兵：一次战斗之后的对话、一个防空洞里的分食、一封没写完的家信。文章发表后，「最可爱的人」成为对志愿军士兵的通行称呼，也被沿用到此后许多年。这篇文字与10月25日的关系是间接的：它写的不是首战那一天，但它塑造了后来人们在这一天想起的那张面孔。
