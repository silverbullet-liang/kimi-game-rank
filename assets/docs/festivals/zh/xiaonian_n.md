# 北方小年

## 简介

农历十二月二十三日，又称祭灶节、灶王节、小年。中国北方大部分地区以这一天为小年，南方大部分地区则为腊月二十四日。「小年」的意思不是节小，而是从这一天起进入过年的准备，前面还有一个更盛大的除夕与春节。

## 由来

祭灶是很老的祀典。《礼记·祭法》所列的七祀之中就有「灶」，《论语》里也有「与其媚于奥，宁媚于灶」的话，可见灶神在先秦已受人奉事。至于祭灶为何从腊月二十四提前到二十三，通行的一种解释是：清代宫廷在腊月二十三日祭灶，王公与京官随之效仿，北方民间也逐渐改在这一天，南方则更多保留了旧日。民间原有「官三民四船家五」的说法，讲的就是官家二十三、百姓二十四、水上人家二十五的差别。

## 习俗

1. **祭灶**：在灶台前供糖瓜、关东糖、清水与草料，糖要黏、要甜，图的是灶王「上天言好事」。
2. **扫尘**：扫房顶、擦窗户、洗被褥，把一年积下的灰一次清掉，取除旧布新的意思。
3. **剪贴窗花**：红纸剪成花鸟、人物、福字，贴在擦净的窗格上，是北方冬日里最显眼的一抹红。
4. **沐浴理发**：俗谚说「有钱没钱，剃头过年」，这一天前后大人小孩都要理发洗澡。
5. **备年货与蒸干粮**：买糖、买炮、买对联，蒸馒头、枣糕、粘豆包，冻在院里吃一正月。

## 故事

灶王的传说在民间流传最广。相传灶王爷常年住在灶间，看一家人的饮食起居，也记一家人的善恶；到了腊月二十三夜里，他要上天向玉皇禀报这一年的事。人们怕他说坏话，便供上又黏又甜的糖瓜，黏住他的嘴，或让他的嘴甜些。祭完把旧的神像揭下焚化，除夕再贴新的一张，叫作「送灶」与「接灶」。这一套说法没有确切的典籍源头，却在南北的灶台上讲了几百年。

## 主题

这套皮肤画一扇八角形的剪纸窗，旁边一颗糖瓜。窗格里的刀痕是红线，糖瓜是浅金，两者并排放在深红的底上。剪纸是给人看的，糖瓜是给神吃的——小年这一天，人间的热闹和灶间的供奉摆在一起。
