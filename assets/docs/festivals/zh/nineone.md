# 九一八

## 简介

1931年9月18日夜10时许，日本关东军炸毁沈阳北郊柳条湖附近南满铁路的一段路轨，反诬中国军队所为，随即炮轰东北军驻地北大营、进攻沈阳城。次日凌晨沈阳城陷落，1932年2月东北全境沦陷。中国以1931年至1945年为抗日战争的十四年。9月18日为九一八事变纪念日。

## 由来

事变前的东北，南满铁路由日本经营，沿线驻有关东军。1931年9月18日夜，关东军自行引爆柳条湖段路轨，随即以「中国军队破坏铁路」为由出动，攻北大营、攻沈阳城。当时代理东北军政的张学良与东北当局执行不抵抗方针，东北军大部未作抵抗即行撤出，沈阳一夜之间易手。此后数月，日军沿铁路线推进，至1932年2月占黑龙江，东北全境沦陷。中国方面把1931年起的武装抵抗计入抗日战争，共十四年，这一断限与「十四年抗战」的表述在2017年起被普遍用于教材与纪念活动。

## 习俗

1. **鸣响防空警报**：沈阳自1995年起，每年9月18日9时18分在全城鸣响防空警报三分钟，机动车停驶鸣笛；2006年起辽宁十四个市同时鸣响，此后全国百余座城市在这一天鸣放。
2. **撞钟**：沈阳「九一八」历史博物馆残历碑广场举行撞钟鸣警仪式，警世钟撞十四响，对应十四年。
3. **参观纪念馆**：博物馆于1991年9月18日、事变六十周年之际建立，1999年9月18日新馆落成开馆；馆东墙紧邻当年的北大营，距柳条湖路段约八百米。
4. **寻访旧址**：北大营旧址以陈列馆方式开放，沈阳之外，辽阳白塔公园内另有一处事变策划地纪念馆。
5. **学校与社会的纪念活动**：默哀、献花、讲座、展览，多在这一天前后举行。

## 故事

沈阳「九一八」历史博物馆广场上立着一座残历碑，形如一本摊开的台历：右页日期永久定格在1931年9月18日星期五，左页刻着事变的经过，碑面布满弹痕状的孔洞。据参与设计的鲁迅美术学院教授贺中令说明，碑的底座用了骷髅与骸骨的元素，主体做成一本摊开的日历，取的是把这一页翻不过去的意思。这座碑在1991年随馆落成，后来成为这一天举行仪式的场所，也是许多人到达沈阳后第一个去看的地方。

## 主题

这套皮肤是右上角一块日历格子，一道裂痕自上而下劈过中间那一格，格子里的日期因此断开。裂的不是纸，是日历所要维持的那种连续；一套只为一天准备的皮肤，把它画成了一条断口。
