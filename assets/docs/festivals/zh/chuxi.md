# 除夕

## 简介

农历一年的最后一天，因农历月有大小，或为腊月三十日，或为腊月二十九日，民间统称「大年三十」。这一天与次日春节首尾相接，是一年里仪式最密的一夜：吃年夜饭、贴春联、守岁、发压岁钱，都在这一夜完成。

## 由来

「除夕」之名，通行说法见于西晋周处《风土记》，其中记有除夕「达旦不眠，谓之守岁」，说明至迟在晋代，岁末守夜已是固定习俗。「除」是去除、更替的意思，除夕即旧岁到此夕而除，明日另换一岁。南朝梁宗懔《荆楚岁时记》也记岁末家家备办肴馔、相聚迎新的情形。除夕的许多做法都围绕一个「接」字：把旧年送走，把新年接进门，所以这一夜要亮着灯、要有人醒着、要有剩饭。

## 习俗

1. **年夜饭**：全家围桌，菜要有余，鱼常留头留尾，取「年年有余」；北方包饺子，饺子形似元宝，子时吃。
2. **贴春联与福字**：门框贴对联，门上贴门神、福字，福字常倒贴，取「福到」的谐音。
3. **守岁**：灯火不熄，一家人说话、看节目、打牌到零点，长辈给晚辈压岁钱。
4. **祭祖**：饭前摆供、上香、烧纸，请祖先回家过年，一些地方要留一副空碗筷。
5. **放爆竹**：旧俗以爆竹驱邪迎年；近些年许多城市划定了禁放、限放区域，做法随之改变。

## 故事

关于除夕，流传最广的是「年」的传说。相传远古有一种叫「年」的怪兽，每到岁末夜里出来伤人，怕红色、怕火光、怕响声。人们于是在门上贴红纸、点灯、烧竹竿，整夜不睡守着，直到天亮，「年」没有再出现，众人相贺。这个故事没有可靠的典籍源头，是民间口传；但它把除夕的三样东西——红、火、不睡——解释在了一处，也因此流传得最广。

## 主题

这套皮肤画一枚表盘，指针走到底，旁边一张福字。表盘的刻度是这一年的全部，指针停在最后一格；福字贴在旁边，是给下一格准备的。除夕就是这两件事同时成立的一刻：旧的时间已经用完，新的祝福已经贴上门。
