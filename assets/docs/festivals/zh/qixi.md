# 七夕节

## 简介

农历七月初七是七夕节，又称乞巧节、女儿节、双七节。这一天与牛郎织女的传说相连，是传统节日中与女性、手艺和星象关系最紧的一个。2006 年，七夕节被列入第一批国家级非物质文化遗产名录。日本、朝鲜半岛与越南也有同源的节俗，日期与做法各不相同。

## 由来

七夕源自对星象的观察。牵牛星与织女星分居银河两岸，《诗经·小雅·大东》已有「跂彼织女」「睆彼牵牛」的句子。汉代把七月七日与穿针乞巧连在一起，据《西京杂记》记载，汉时宫女在七月七日于开襟楼穿七孔针。东汉以后，牵牛织女逐渐人格化为夫妻，《古诗十九首》中已有「迢迢牵牛星，皎皎河汉女」的相思之语。晋代以后，七夕成为固定的节令，乞巧、乞子的风俗在唐宋尤盛。

## 习俗

1. **穿针乞巧**：女子在月下用彩线穿七孔针，看谁穿得快，以此「乞巧」。
2. **陈列巧果与花果**：院中摆桌，供上巧果、瓜果、莲藕与鲜花，有的地方称「乞巧桌」。
3. **观星**：入夜后找银河两侧的牵牛星与织女星，长辈给孩子讲传说。
4. **洗发与染指甲**：一些地方用柏叶、桃枝煎水洗头，或以凤仙花染指甲。
5. **当代的过法**：送花、约会、登记结婚，一些城市举办集体婚礼与乞巧市集。

## 故事

相传牛郎是人间的放牛孤儿，织女是天上的织锦仙女。两人结为夫妻，生下一双儿女，男耕女织。王母娘娘得知后把织女带回天上，牛郎披着老牛的皮追去，王母用金簪在他身后一划，划出一道银河，两人隔河相望。喜鹊每年七月初七搭成鹊桥，让他们在桥上相见一次。这个故事的完整形态见于汉代以后的文献与民间说唱，各地说法在细节上并不一致，鹊桥相会是流传最广的一段。

## 主题

这套皮肤用页首一条斜向的星河，两岸各一颗带星芒的亮星。星河从左上斜到右下，两颗星一高一低，与河的距离并不相等。星光是极细的四射，不闪，也不动。七夕的全部情节都落在这段距离里：中间是一条过不去的亮带，两端各有一颗星。
