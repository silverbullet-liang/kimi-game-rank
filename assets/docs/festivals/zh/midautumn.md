# 中秋节

## 简介

农历八月十五。农历八月居秋季之中，称「仲秋」，十五又在仲秋之中，故名中秋。又称月夕、八月半、团圆节。2006年5月20日，中秋节经国务院批准列入第一批国家级非物质文化遗产名录；自2008年起列为法定节假日。

## 由来

「中秋」一词最早见于《周礼·春官·籥章》：「中春昼击土鼓，吹豳诗以逆暑；中秋夜迎寒，亦如之。」这里的「中秋」指八月，是一种迎寒气的时令仪式，还不是节日。唐人诗中已多见八月十五咏月之作，杜甫《八月十五夜月》、王建《十五夜望月》写的都是这一夜。到宋代，中秋才成为各阶层共同参与的节日。孟元老《东京梦华录》卷八记北宋汴京：「中秋夜，贵家结饰台榭，民间争占酒楼玩月。」吴自牧《梦粱录》卷四说得更直白：「八月十五日中秋节，此日三秋恰半，故谓之中秋。」月饼成为节令食品是更晚的事，明田汝成《西湖游览志余》记：「八月十五谓之中秋，民间以月饼相遗，取团圆之意。」明清以后，中秋与春节、清明、端午并列，成为四大传统节日之一。

## 习俗

1. **赏月与祭月**：在月出的方向设案，摆西瓜、石榴、月饼，旧时多由家中妇女主祭。
2. **吃月饼**：饼必圆，按人数切块，人人有份，圆与分指向的是同一件事。
3. **赏桂与饮桂花酒**：桂花正当此时开，江南以桂花入酒、入糖、入糕。
4. **玩花灯**：儿童提兔灯走街，南方水乡放河灯，湖广一带有「树中秋」。
5. **观潮**：浙江钱塘江中秋潮最盛，自唐宋以来观潮成俗。

## 故事

流传最广的是嫦娥奔月。相传后羿从西王母处求得不死之药，其妻嫦娥吞药后飞升入月，居月中不出。西汉《淮南子·览冥训》已有「羿请不死之药于西王母，姮娥窃以奔月」的记载，可见这个故事至少流传了两千年，只是各代讲法不尽相同。后世又添上玉兔捣药、吴刚伐桂——桂树随伐随合，永远伐不倒。这些是想象，不是史事，却是中国人看月亮时最早的一层心思。

## 主题

这套皮肤在页首偏上放一轮满月，月外一圈很淡的晕，一片薄云横着切过月面。云没有遮住月，只是从它前面过，画面就停在这一下：圆的和过去的，聚的和留不住的，同时落在同一天上。
