# 辛亥纪念

## 简介

10月10日为辛亥革命纪念日。1911年10月10日（农历辛亥年八月十九）夜，武昌起义爆发。辛亥革命由此展开，清朝统治结束；1912年1月1日，中华民国临时政府在南京成立，孙中山就任临时大总统。10月10日因此成为纪念日，在台湾地区称为「双十节」。

## 由来

1911年夏，四川保路运动起，清廷将湖北新军部分队伍调入四川，武汉的防守力量随之减弱。湖北的革命团体文学社与共进会在同盟会中部总会推动下联合，9月24日开联席会议，推蒋翊武为临时总司令、孙武为参谋长，定10月6日起义，后因故延期。10月9日，孙武在汉口俄租界宝善里的机关赶制炸弹时发生爆炸，文件被搜走，机关暴露，清方按名册捕人，彭楚藩、刘复基、杨洪胜遇害。10月10日晚，新军工程第八营的革命党人首先发难，夺占中和门附近的楚望台军械库，吴兆麟被推为临时总指挥，经一夜战斗攻下湖广总督署。11日湖北军政府成立，12日武汉三镇光复。中和门因首义之功，1912年改名起义门。

## 习俗

1. **寻访起义门**：武昌中和门旧址，城楼与城墙段保存至今，被视为首义的起点。
2. **参观纪念馆**：鄂军都督府旧址（红楼）为辛亥革命武昌起义纪念馆，1961年列入第一批全国重点文物保护单位；辛亥革命博物馆于2011年、百年之际在首义广场南侧开馆。
3. **纪念大会与研讨**：逢十周年举行纪念活动，学界另有专题研讨与文献整理。
4. **献花与展览**：彭刘杨路一带的烈士祠、起义门城楼，每年这一天前后有献花与图片展。
5. **两岸各自的纪念**：大陆称辛亥革命纪念日，台湾地区以10月10日为「双十节」，各有仪式。

## 故事

关于起义当夜的第一枪由谁打响，记载并不一致，有熊秉坤、程正瀛等不同说法，学界也各有依据。可以确认的是：起事以工程第八营为发端，目标是楚望台军械库，库中枪炮为后续战斗提供了装备；夜间三次进攻总督署，天亮前拿下；一夜间，一座省城换了旗号。起义的领导者多为中下级军官与士兵，原定的领导人或被捕、或出走、或受伤，事后成立的军政府推举黎元洪为都督，这一转折在当时就引起过讨论。
