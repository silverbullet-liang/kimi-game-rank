# 重阳节

## 简介

农历九月初九，又称重九、登高节、茱萸节。古人以「九」为阳数，两九相重，故名重阳。因「九九」与「久久」同音，今又取长久长寿之意，2012 年起农历九月初九被定为中国法定的老年节。

## 由来

「重阳」一词最早见于屈原《远游》，但作为节令习俗成型于汉代：据《西京杂记》记载，汉时九月九日已有佩茱萸、食蓬饵、饮菊花酒的讲究。唐代正式列为节日，宫廷与民间一同登高宴饮、赋诗赏菊，此后历代相沿。因重阳在深秋，天气转凉、草木将凋，古人在这一天既有游乐，也有避疫祈福的用意，节俗因此兼具欢聚与敬畏两面。

## 习俗

1. **登高**：秋高气爽时上山或登塔，取「步步登高」之意，也是古人避疫的一种说法。
2. **赏菊饮菊花酒**：菊在深秋盛开，被视为耐寒延寿之花，重阳前后赏菊、酿菊花酒是旧时风气。
3. **佩茱萸**：茱萸气味辛烈，古人折枝插头或装入绛囊佩于臂，用以驱邪避恶。
4. **吃重阳糕**：「糕」与「高」同音，与登高相应；讲究的做法要做成九层，上插小旗。
5. **敬老探亲**：当代最通行的一项内容，回家看望长辈、陪老人吃饭。

## 故事

相传东汉时汝南人桓景随费长房学道。一日费长房告诉他：九月九日你家将有灾祸，可让家人各做绛色布袋装茱萸系在臂上，登高饮菊花酒，灾祸可免。桓景照办，举家登山。傍晚回家，见鸡犬牛羊尽皆暴死，家人却都平安。此事见于南朝梁吴均《续齐谐记》，后世重阳登高、佩茱萸、饮菊花酒的习俗，常以此传说为源。

## 主题

这套皮肤用的是页首一条斜向的星河，两岸各一颗带星芒的亮星：星河把视野分成两边，正好对应重阳登高望远、隔山隔水思亲的那层意思；星光是极淡的金白，配深蓝的秋夜底色，是全站最安静的几套之一。
