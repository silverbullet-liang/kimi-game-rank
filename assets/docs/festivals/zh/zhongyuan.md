# 中元节

## 简介

农历七月十五是中元节。道教称中元，佛教称盂兰盆节，民间多称七月半。这一天以祭祖和追荐亡者为主要内容，与除夕、清明、重阳同属旧时重要的祭祀日子。日本、朝鲜半岛与越南也有受同一源流影响的节俗，名称与日期各自不同。

## 由来

中元之名出自道教的三官信仰：正月十五为上元，七月十五为中元，十月十五为下元，分别对应天官、地官与水官。道教以为中元之日地官赦罪，故于此日设醮荐亡。佛教一侧的说法源自《盂兰盆经》，经中记目连以盂兰盆供僧，救拔亡母。南北朝的岁时记载里，七月十五已有盂兰盆供与祭墓的内容，梁宗懔《荆楚岁时记》记此日「僧尼道俗悉营盆供诸佛」。唐宋以后，道教、佛教与民间习俗逐渐混融，形成今天所见的样子。

## 习俗

1. **祭祖**：家中设供桌，焚香、上供、烧纸钱，按长幼次序行礼。
2. **放河灯**：以纸或木作灯座，中点蜡烛，放入河湖，任其顺流漂远。
3. **盂兰盆供**：寺院举行法会，诵经、施食，信众以盆盛供物送往寺院。
4. **普度**：一些地方在街巷搭棚，设孤棚、竖灯篙，普施孤魂。
5. **放焰口**：道观与寺院设坛，为无主亡者诵经，夜间持续数小时。

## 故事

《盂兰盆经》所记的一段流传最广：相传佛弟子目连以神通见亡母堕在饿鬼道中，不得饮食，向佛求告救度之法。佛告诉他，七月十五是僧众安居圆满之日，以百味饮食置于盂兰盆中，供养十方僧众，可仗众僧之力使母脱离苦处。目连依教而行，其母得脱。此经在中土流传很广，盂兰盆会的说法多由此而来。道教一侧另有地官赦罪之说，两种说法长期并行，民间往往并不细分，供品与仪节也相互借用。

## 主题

这套皮肤只有一盏河灯：水面上一盏灯，灯下一圈柔光与三道涟漪，全靠光晕，不用描边。灯是画面上唯一亮的地方，光从灯底往外散，越远越淡，涟漪只是三圈更淡的弧，一圈比一圈松。没有岸，没有月，也没有人，页面下端留着一片没有边的暗水。
