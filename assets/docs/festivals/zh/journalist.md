# 记者节

## 简介

11月8日是中国记者节。2000年8月1日，国务院批复中华全国新闻工作者协会《关于确定「记者节」具体日期的请示》，同意将11月8日确定为记者节；同年11月8日为第一个记者节。记者节与护士节、教师节并列，是中国仅有的三个行业性节日之一，按国务院规定不放假。

## 由来

日期取自中国记协的前身。1937年11月8日晚，由范长江等二十四人发起，中国青年新闻记者协会在上海山西南路二百号南京饭店成立；上海沦陷后迁往武汉，1938年3月30日在汉口举行第一次全国代表大会，后改称中国青年新闻记者学会。1957年，中华全国新闻工作者协会成立；1987年，中国记协经论证认定其源头为1937年11月8日。1949年12月23日政务院颁布的《全国年节及纪念日放假办法》已列入记者节，但未定具体日期；1999年9月18日修订的办法再次列入；2000年1月25日中国记协正式向国务院请示，8月1日获批复。此前，1933年至1949年间，新闻界曾在9月1日过记者节，那一起议始于1934年杭州记者公会的通电。

## 习俗

1. **行业表彰**：中国新闻奖、长江韬奋奖在这一天前后公布或颁发。
2. **座谈与研讨**：记协与各新闻单位举行座谈、业务研讨与经验交流。
3. **走基层**：不少媒体把这一天安排在一线采访，而不是在会议室里。
4. **开放日与展览**：报社、电台、电视台开放参观，同期举办新闻摄影展。
5. **自我提醒**：行业刊物多在这一天谈采访伦理、事实核查与报道边界。

## 故事

1937年7月，全面抗战爆发。7月中旬，正在上海代表中共中央领导南方工作的周恩来，向胡愈之、夏衍等人传达了广泛团结爱国新闻工作者、组织统一战线的意见。11月4日，范长江与胡愈之、夏衍、恽逸群等会商，决定成立组织；11月8日晚七时，成立大会在上海南京饭店举行，选出总干事若干人，并决定出版会刊《新闻记者》。此后青记在全国设立分会四十多个，会员最多时两千余人。2010年，成立会址上海南京饭店被确定为文物保护单位。

## 主题

这套皮肤是纸白配铅黑：两侧各三道极淡的报纸栏线，把版面分成栏；右上角一枚手画的朱批圈，笔画走了一圈却不闭合，留着一道口；右下角一枚钢笔尖，锋口朝上。红只有这一点，是批注的颜色，不是庆祝的颜色。
