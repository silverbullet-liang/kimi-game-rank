# 南方小年

## 简介

农历十二月二十四日。中国南方大部分地区以这一天为小年，又称祭灶节、扫尘日。江浙沪一带另有把除夕前一夜称为「小年夜」的说法，与腊月二十四并行；无论叫法如何，这一天开始的都是同一件事——扫房、备年货、把家收拾干净等过年。

## 由来

小年日期南北相差一天，民间原有的解释是「官三民四船家五」：官家在腊月二十三祭灶，百姓在二十四，水上人家在二十五。北方在清代以后多从官府之例改到二十三，南方则大体沿用二十四，于是形成今天南北各过一天的局面。祭灶本身是很古老的祀典，《礼记·祭法》所记七祀中有「灶」，《论语》也留下「与其媚于奥，宁媚于灶」的话。此外，「小年」也是旧时账房封账、伙计结年的日子，讨账与清账都赶在这一天之前。

## 习俗

1. **掸尘**：用竹帚、鸡毛掸子从梁上扫到墙角，拆洗被褥、擦洗门窗，把一年积的灰一次除净。
2. **祭灶**：灶前供糖、糕、酒，送灶神上天；南方一些地方供品里还有豆腐、甘蔗与荸荠。
3. **洗晒与沐浴**：趁着冬日晴好，把被褥衣物晾满院子，人也理发洗澡，取「干干净净过年」。
4. **备年货**：腌腊味、灌香肠、晒鱼干，做年糕、打麻糍、蒸糯米，南方年货里米制品占的分量更重。
5. **写春联贴福字**：请人或自家写对联、剪红纸，门神、福字、年画一并贴上门窗。

## 故事

掸尘的来历，民间讲的是一个谐音。「尘」与「陈」同音，扫尘就是扫陈，把过去一年的旧事、晦气一并扫出门去，所以这一天的清扫要从屋梁开始，一直扫到门口，方向是往外。竹帚在这里有讲究：南方就地取材，砍竹枝扎成一把，柄长而硬，够得到高处的梁与椽，用旧了也不散。这个说法没有典籍可考，但每年这一天，家家门口的竹帚和满院的被子，是它一直活着的样子。

## 主题

这套皮肤把一把竹帚斜靠在画面左侧，旁边四点扬尘慢慢浮起。竹帚是旧的，扫过的痕迹还在，浮尘细而不散。扫尘这个动作本身很轻，也没有声音，正好对上小年的意思：不庆祝，只是把一年清干净，为后面更大的日子腾出地方。
