# 腊八节

## 简介

农历十二月初八，又称腊八。「腊」本是岁末祭祀之名，这一天既是年终祭祖祭神的日子，也是民间公认的「年味」起点——过了腊八，备年货、扫房、写春联就陆续开始了。

## 由来

腊祭是先秦已有的年终大祭，祭祖先与百神，报一年之收。南朝梁宗懔《荆楚岁时记》记「十二月八日为腊日」，说明至迟到南北朝，腊日已固定在腊月初八。此后佛教的佛成道日与腊日合流，寺院在这一天煮粥供佛、施粥给信众。据南宋吴自牧《梦粱录》记载，十二月八日寺院「设五味粥，名曰腊八粥」，可见宋代腊八粥已通行。明清两代，腊八粥从寺院走进家家户户的灶房，配料也随各地物产越加越多。

## 习俗

1. **熬腊八粥**：以米、豆、枣、栗、莲子、花生、桂圆等凑成八样或更多，先祭祖、赠亲友，再全家分食，讲究剩一些，取「年年有余」。
2. **泡腊八蒜**：华北一带把剥净的蒜瓣浸入米醋，封到除夕开坛，蒜色转碧绿，醋带蒜香，配饺子吃。
3. **吃腊八面**：陕西关中一些地方不喝粥而吃面，以豆类与蔬菜做臊子，腊八清晨全家同食。
4. **施粥与祭祖**：寺院、道观与一些商铺在这天舍粥；家中供桌上仍保留祭祖的一副碗筷。
5. **开年事**：从这一天起置办年货、腌肉、写春联，民间有「过了腊八就是年」的说法。

## 故事

腊八粥的来源，流传最广的一说与佛成道日有关。相传释迦牟尼苦修多年，形容枯瘦而未曾得道，后受牧女所献的乳糜，体力恢复，在菩提树下静坐而悟，这一天在中国汉地记为腊月初八。寺院因此在这天煮粥供佛，并以粥施人。另一类说法更近人情：旧时穷苦人家到年底把缸底各种存粮扫出来，凑成一锅杂粮粥，反而成了风味。两条线索一并流传，前者进了寺院的仪轨，后者留在民间的灶上。

## 主题

这套皮肤画一只粗陶碗，碗沿上方悬着七粒谷物，一缕很淡的热气向上散开。陶的粗、谷物的散、热气的轻，都是腊八这一天最实在的东西：一年将尽，把剩下的几样粮凑在一处，煮成一碗热的。
