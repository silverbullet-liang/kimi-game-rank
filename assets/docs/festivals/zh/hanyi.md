# 寒衣节

## 简介

农历十月初一，又称十月朝、祭祖节、授衣节。在民间，这一天与清明、中元并列，是一年中祭奠先人的日子之一。北方多于此时上坟，为逝去的亲人焚送纸衣，称「送寒衣」。农历十月也是入冬之始，此后天渐冷。

## 由来

「授衣」之说很早。《诗经·豳风·七月》有「七月流火，九月授衣」，说的是九月天转凉，该备冬衣了。唐玄宗天宝二年（743年），朝廷下制，令每年九月一日荐衣于陵寝，见《唐大诏令集》卷七十七，把新制的冬衣供献于先人，这一诏令影响到民间拜墓送衣的做法。因十月才入冬，九月嫌早，宋人把这一习俗移到十月朔日。孟元老《东京梦华录》记汴京九月下旬「即卖冥衣、靴鞋、席帽、衣段，以十月朔日烧献故也」，又说十月一日「士庶皆出城飨坟」。周密《武林旧事》记临安「十月朔，都人出郊拜墓，用棉裘楮衣之类」。元代《析津志》中，「送寒衣节」一名已经出现。明《帝京景物略》记得最细：十月一日，纸肆裁五色纸作男女衣，长一尺有余，上写姓名辈分，如寄书信，家家在夜里于门前呼唤而焚之，称送寒衣。

## 习俗

1. **送寒衣**：以五色纸剪成衣裤，装于纸袋或纸包袱，写上亡者名讳与辈分，焚于墓前或门前。
2. **上坟祭扫**：清理坟头、陈设供食、焚化纸钱，与清明相似而更简。
3. **授衣**：为家中长辈备冬衣、添棉被，这一层至今仍通行。
4. **开炉**：旧时在这一天生火取暖，北方称「开炉」，与授衣同属入冬的记号。
5. **荐新**：北方一些地方以新收的黍、或饺子供祖，取秋收先荐之意。

## 故事

与这一天有关、流传最广的是孟姜女的传说。相传她的丈夫被征去修长城，久无音信，她缝好冬衣，千里寻夫；到时人已死，尸骨被筑入城墙，她在城下恸哭，城墙为之崩。这个故事在早期文献里只有「杞梁之妻」的简略记载，后来在戏曲与说唱中不断生长，细节各代不同，来源已难确指。民间把它与十月初一送寒衣连在一起，两边说的是同一件事：天冷了，衣服要送到。
