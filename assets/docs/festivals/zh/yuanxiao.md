# 元宵节

## 简介

农历正月十五，又称上元节、灯节、小正月。这一天是农历一年中第一个月圆之夜，也是春节年俗的收尾：灯挂起来，年就算过完了。道教将正月十五、七月十五、十月十五合称「三元」，正月十五为上元，故有此名。

## 由来

正月十五燃灯的来历，通行的一种说法与佛教有关：相传汉明帝时，为表示对佛的敬意，下令在正月十五夜于宫中和寺院燃灯，此后相沿成俗。这个说法见于后世的记载，具体情形难以确考。可以确认的是，南朝梁宗懔《荆楚岁时记》已记正月十五「作豆糜，加油膏其上」以祠门户，说明南北朝时这一夜已有固定的做法。唐代长安的灯事极盛，苏味道《正月十五夜》留下「火树银花合」的句子；宋代把灯期延长到五夜、六夜，灯上粘谜，猜灯谜由此而来；明清两代，灯市成为城市里的固定场所。

## 习俗

1. **赏灯与灯会**：扎灯、挂灯、观灯，宫灯、走马灯、龙灯各有做法，各地公园与街市办灯会。
2. **猜灯谜**：把谜面写在纸条上贴于灯下，猜中揭下领奖；谜格、谜目自成一套规矩。
3. **吃元宵或汤圆**：北方「滚」元宵，馅在干粉里滚成球；南方「包」汤圆，糯米皮裹馅后搓圆。馅多为芝麻、豆沙、花生。
4. **舞龙舞狮与踩街**：龙灯、狮队、踩高跷、划旱船、扭秧歌上街，是一年里最后一次大规模的街头热闹。
5. **走百病**：北方旧俗，妇女在正月十五、十六夜结伴出门过桥、走城墙，称走百病，取祛病之意。

## 故事

流传较广的一则故事与汉武帝时的大臣东方朔有关。相传宫人元宵因思念家人而欲投井，东方朔为成全她，先在长安街上设摊占卜，散布「正月十五火焚身」的话，再向武帝进言，说火神君爱吃汤圆，可让全城在正月十五挂红灯、放焰火、家家煮汤圆，以灯火之盛代替火灾之祸。武帝准奏，长安城灯火通明，元宵的父母也进城观灯，一家人得以相见。此说见于后世的杂记与民间叙述，不见于正史。

## 主题

这套皮肤画一碗汤圆，上方悬着三盏大小不一的灯。碗是近的、低的、静止的，灯是远的、高的、发亮的；一碗白与三盏暖光之间留着大片空白。元宵节的两样东西就这样摆在同一个画面里：吃的那一碗，和照亮整条街的那几盏。
