# 烈士纪念日

## 简介

2014年8月31日，第十二届全国人民代表大会常务委员会第十次会议通过《关于设立烈士纪念日的决定》，以法律形式将9月30日设立为烈士纪念日，并规定每年9月30日国家举行纪念烈士活动。2014年9月30日为首个烈士纪念日。2018年4月27日，《中华人民共和国英雄烈士保护法》经十三届全国人大常委会第二次会议通过。

## 由来

日期定在9月30日，与人民英雄纪念碑有关。1949年9月30日，中国人民政治协商会议第一届全体会议通过在天安门广场建立人民英雄纪念碑的决议，当天下午举行奠基仪式。在国庆前一天举行纪念活动，既与次日的国庆相接，也与10月1日上午向纪念碑敬献花篮的安排相衔接。据不完全统计，近代以来约有2000万名烈士为民族独立、人民解放和国家富强献出生命；由于战争年代条件所限，其中留下姓名、收入各级《烈士英名录》的只是少数。

## 习俗

1. **向人民英雄敬献花篮**：每年9月30日上午在天安门广场人民英雄纪念碑前举行，党和国家领导人及首都各界代表出席，军乐团奏国歌，全场默哀，礼兵抬花篮缓步上前，缎带上写着「人民英雄永垂不朽」。
2. **瞻仰与默哀**：仪式后绕行纪念碑，各界群众依次献花。
3. **烈士陵园祭扫**：全国各地烈士陵园、烈士墓、纪念堂馆在这一天前后集中祭扫与敬献。
4. **为烈士寻亲**：近年通行的做法，为无名或失联的烈士寻找姓名与家属。
5. **网上祭英烈**：线上献花、留言，中小学多在这一天前后安排主题课程。

## 故事

人民英雄纪念碑1949年9月30日奠基，1952年动工，1958年建成揭幕，通高37.94米，正面碑心石采自青岛浮山。碑文由毛泽东起草、周恩来书写，分三段，从「三年以来」起，经「三十年以来」，到「由此上溯到一千八百四十年」，把不同时期的死者放进同一块石头里。周恩来为写这块碑的字练了多日，这一细节在纪念文章中被反复提及。碑的正面是八个大字，背面是那三段话，中间没有多余的东西。
