# 尾牙

## 简介

农历十二月十六日，流行于福建、台湾等地及闽南移民聚居的东南亚华人社区。「牙」指每月初二、十六的做牙，即商家备牲礼祭土地神的日子；十二月十六是全年最后一次做牙，所以称「尾牙」。

## 由来

做牙之俗起于对土地神的祭祀。旧时商铺、行号每月初二、十六以牲醴、香烛祭福德正神，祭毕把供品分给伙计打牙祭，一年二十四次，头一次叫「头牙」，末一次叫「尾牙」。年关将近，东家要在尾牙这天宴请伙计一年辛劳，同时交代来年的人事与工钱，于是尾牙宴兼有答谢与议事两重性质。后来商业形态改变，祭祀淡了，宴席留下来，成为许多公司年末聚餐的名称。

## 习俗

1. **祭土地神**：在门口或店堂设供桌，摆三牲、酒、糕粿，焚香放炮，谢一年庇佑。
2. **尾牙宴**：老板做东请全体员工，早年是自家院落摆桌，如今多在餐馆，席间抽奖、发红包、表彰资深员工。
3. **吃润饼与刈包**：闽台一带尾牙吃润饼（薄饼卷菜）与刈包（割包），形似钱包，取「包住财富」的意思。
4. **鸡头的讲究**：旧时宴上必有白斩鸡，鸡头朝向谁，席间便知东家的意思；后来为避免尴尬，多把鸡头朝下或撤走。
5. **结清账目**：商家在这一天前后收账、发年终、写来年的计划，旧时欠账不过尾牙。

## 故事

尾牙最常被提起的，是那只鸡的头。相传早年商家不便当面辞退伙计，便在尾牙宴上把白斩鸡的鸡头对准某人，被对准的人自然明白来年不必再来。若东家想留人，就把鸡头转向自己或干脆去掉。这层暗语后来被认为太过生硬，渐渐改为私下告知，鸡头也不再指人。故事的真伪已难查考，但它记下了一件事：一顿饭在旧时的行号里，既是酬劳，也是契约。

## 主题

这套皮肤画的是一席将散的桌面：一盏低垂的灯、一角垂下的桌布、一双搁下的筷子。灯还亮着，桌布已经松了，筷子平放着不再举起。尾牙的那一刻就在这里——一年的事谈完了，人也散了，桌面上只剩下吃过之后的空。
