# 烈士記念日

## 概要

2014年8月31日、第12期全国人民代表大会常務委員会第10回会議が「烈士記念日の設立に関する決定」を採択し、9月30日を烈士記念日とすることを法の形式で定め、毎年この日に国が烈士を記念する行事を行うと規定した。2014年9月30日が最初の烈士記念日である。2018年4月27日には「英雄烈士保護法」が第13期全国人民代表大会常務委員会第2回会議で採択された。

## 由来

日付が9月30日とされたのは、人民英雄紀念碑と関わる。1949年9月30日、中国人民政治協商会議第一回全体会議は天安門広場に人民英雄紀念碑を建てる決議を採択し、同日午後に定礎式が行われた。国慶節の前日に記念行事を置くことで、翌日の国慶節とつながり、10月1日午前に紀念碑へ花輪を捧げる次第とも連続する。不完全な統計によれば、近代以降、民族の独立、人民の解放、国の富强のために命を捧げた烈士は約2000万人にのぼる。戦時下の事情から、氏名が残り、各級の「烈士英名録」に収められた者はその一部にとどまる。

## 習わし

1. **人民英雄への花輪捧呈**：毎年9月30日午前、天安門広場の人民英雄紀念碑前で行われ、党と国家の指導者、首都各界の代表が参列する。軍楽隊が国歌を奏し、全員が黙祷し、衛兵が花輪を運ぶ。リボンには「人民英雄永垂不朽」とある。
2. **瞻仰と黙祷**：式の後、紀念碑を巡り、各界の市民が順に花を供える。
3. **烈士陵園での墓参**：各地の烈士陵園、烈士墓、記念館で、この日の前後に拝礼と献花が集中的に行われる。
4. **烈士の身元調査**：近年広がる取り組みで、無名の烈士や家族と連絡の絶えた烈士の氏名と縁者を探す。
5. **インターネットでの追悼**：オンラインでの献花やメッセージ、小中学校でのテーマ学習。

## 物語

人民英雄紀念碑は1949年9月30日に定礎され、1952年に着工、1958年に完成して除幕された。高さ37.94メートル、正面の碑心石は青島の浮山から切り出された。碑文は毛沢東が起草し、周恩来が書いた。「三年以来」「三十年以来」「ここから一千八百四十年にさかのぼる」という三段からなり、時期の異なる死者を一つの石の内側に並べている。周恩来は書く前に何日も字を練習したと伝えられる。正面には八つの大字、裏面にはその三段の文があり、ほかには何も足されていない。
