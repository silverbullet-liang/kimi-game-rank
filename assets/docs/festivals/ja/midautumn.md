# 中秋節

## 概要

旧暦八月十五日。旧暦の八月は秋の真ん中の月であることから「仲秋」と呼ばれ、その十五日はさらにその中にあるため「中秋」という。月夕、八月節、団円節とも呼ばれる。2006年5月20日、国務院の認可を経て第一次国家級無形文化遺産に登録され、2008年からは法定休日となっている。

## 由来

「中秋」の語は『周礼・春官・籥章』に最も早く見える。「中春の昼は土鼓を撃ち、豳詩を吹きて以て暑を迎う。中秋の夜、寒を迎うること亦た之の如し」とある。ここでの「中秋」は八月を指し、寒気を迎える時令の儀であって、まだ祭日ではない。唐の詩にはすでに八月十五日の月を詠む作が多く、杜甫『八月十五夜月』、王建『十五夜望月』などがこの夜をうたっている。宋に入って、中秋は社会の各層がともに祝う祭日となった。孟元老『東京夢華録』巻八は北宋の汴京を「中秋の夜、貴家は台榭を飾り、民間は争うて酒楼を占めて月を玩ぶ」と記す。呉自牧『夢粱録』巻四はさらに明快で、「八月十五日の中秋節、この日三秋まさに半ばなれば、故にこれを中秋と謂う」とある。月餅が節の食べ物として定まるのはもっと後のことで、明の田汝成『西湖遊覧志余』に「八月十五を中秋と謂い、民間は月餅を以て相遺り、団円の意を取る」とある。明清以降、中秋は春節・清明・端午と並ぶ四大伝統節の一つとなった。

## 習わし

1. **月を観る・月を祭る**：月の出る方角に卓を置き、西瓜・石榴・月餅を供える。旧時は家中の女性が主宰した。
2. **月餅を食べる**：必ず円い形で、人数に合わせて切り分け、一人ずつに行き渡らせる。
3. **木犀を愛で桂花酒を飲む**：木犀はちょうどこの時期に咲き、江南では花を酒・飴・糕に用いる。
4. **花灯を玩ぶ**：子どもは兎の灯籠を提げて町を歩き、南方の水郷では灯籠を川に流す。
5. **潮を観る**：銭塘江の中秋の潮は最も盛んで、唐宋以来、岸辺で観潮する習わしがある。

## 物語

もっとも広く語られるのは嫦娥奔月である。伝えられるところでは、后羿は西王母から不死の薬を得たが、妻の嫦娥がこれを飲んで月へ飛び、そのまま月に住んだという。前漢の『淮南子・覧冥訓』にすでに「羿、不死の薬を西王母に請う。姮娥、窃みて以て月に奔る」とあり、この話が少なくとも二千年伝わってきたことが分かる。ただし細部は時代によって語り方が異なる。後世には玉兎の薬搗きや、呉剛の桂伐りが加わった。桂の木は伐ってもすぐに癒えるので、いつまでも倒れない。いずれも史実ではなく、月を見上げるときの最初の想像力である。

## テーマ

このスキンは画面上方に満月を一つ置き、その外側にごく淡い暈を添え、薄い雲を一枚、月の面を横切らせる。雲は月を隠さない。ただ前を通り過ぎるだけで、画面はそこで止まる。丸いものと過ぎるもの、集うことと留まらないことが、同じ夜の上に並んでいる。
