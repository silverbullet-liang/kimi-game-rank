# メーデー（国際労働者の日）

## 概要

毎年五月一日。中国語では「五一国際労働節」と呼ばれ、五月一日を国際労働者の日とする決議は、一八八九年の第二インターナショナル・パリ大会で採択された。一九四九年十二月、中央人民政府政務院は五月一日を中国の法定労働節と定めた。世界の八十余りの国がこの日に休みを取る。

## 由来

一八八六年五月一日、アメリカのシカゴなどで労働者が八時間労働制を求めてストライキに入り、やがて衝突が起きた。これがヘイマーケット事件である。一八八九年七月、第二インターナショナルはパリで大会を開き、毎年五月一日を国際労働者の日とすることを決め、一八九〇年に初めて実施された。中国の労働者が五月一日を記念する行事は一九一八年にさかのぼり、一九二〇年には北京・上海・広州などでデモと集会が行われた。一九四九年十二月、政務院は五月一日を法定の労働節とした。

## 習わし

1. **休日と集会**：多くの国がこの日を休みとし、労働組合がデモ、集会、音楽会を開く。
2. **労働者の表彰**：中国では一九八九年以降、ほぼ五年ごとに全国労働模範と先進工作者を表彰している。
3. **旅行と帰省**：五日ほどの連休となり、家族旅行や帰省に充てられる。
4. **職場の催し**：労働を主題にした合唱、夕べの会、技能競技会が行われる。

## 物語

一八八六年五月一日、シカゴの数万人の労働者が、労働時間を八時間に短縮するよう求めて街に出た。五月三日に警察がストライキの労働者に発砲し、五月四日の夜、ヘイマーケット広場の集会で爆弾が投げられ、警察が発砲して複数が死亡した。のちに数名の労働運動家が裁判にかけられ処刑された。一八八九年の第二インターナショナルの決議は、こうした出来事を背景としている。経過の記述は労働運動史によって細部が異なるが、五月一日と八時間労働制の結びつきはここから定まった。

## テーマ

濃い赭色の地に、スパナと槌が交差している。線はまっすぐで、飾りも余分な影もない。工場や現場で最も見慣れた二つの道具だが、重なり方は握手のようでもある。一方は締め、一方は打ち込む。どちらも、物を仕上げていく過程を語っている。
