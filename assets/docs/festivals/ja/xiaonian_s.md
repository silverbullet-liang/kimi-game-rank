# 南方の小年

## 概要

旧暦12月24日。中国の南方の大部分ではこの日を小年とし、祭竈節、塵払いの日とも呼ぶ。江蘇・浙江・上海の一帯には、除夕（大晦日）の前夜を「小年夜」と呼ぶ言い方もあり、12月24日と併存している。呼び名はどうであれ、この日から始まるのは同じことである。家を掃き、正月用品をそろえ、住まいを整えて年を迎える準備に入る。

## 由来

小年の日付が南北で一日違うことについては、民間に「官は三、民は四、船家は五」という説明がある。役人は12月23日、庶民は24日、水上生活者は25日に祭竈を行ったというものである。北方は清の時代以降、官府の例に倣って23日に移り、南方はおおむね24日を保ったため、今日のように南北で一日ずつ違う形になった。祭竈そのものは非常に古い祀りで、「礼記」の祭法に記される七祀のなかに「竈」があり、「論語」にも「其れ奥に媚びんよりは、寧ろ竈に媚びよ」ということばが残る。また「小年」は、昔の商家が帳簿を締め、使用人の一年を清算する日でもあり、借金の取り立てと支払いはこの日より前に行われた。

## 習わし

1. **塵払い**：竹箒や羽根はたきで梁の上から隅々まで掃き、寝具を解いて洗い、窓や戸を拭く。一年に積もった埃を一度に落とす。
2. **祭竈**：竈の前に糖、糕、酒を供えて竈神を天へ送る。南方の一部では豆腐、サトウキビ、オオウナギグワイ（くわい）も供える。
3. **洗濯と入浴**：冬の晴れた日に寝具や衣類を庭いっぱいに干し、人も髪を切り風呂に入る。「きれいにして年を迎える」という意である。
4. **正月用品の用意**：塩漬け肉、腸詰め、干し魚を作り、年糕をつき、麻糍（もち米の餅）を搗き、もち米を蒸す。南方の正月用品は米の加工品の比重が大きい。
5. **春聯と福の字**：人に頼むか自分で対聯を書き、赤い紙を切って門神、福の字、年画を戸や窓に貼る。

## 物語

塵払いの由来について、民間では言葉の音が同じことを以て説明する。「塵（ちり）」と「陳（古い）」は同音であるため、塵を掃くことは陳を掃くことになり、過ぎた一年の古い事柄や厄を戸の外へ掃き出すのだという。だからこの日の掃除は屋根の梁から始めて戸口まで、方向は外へ向かう。竹箒にも理由がある。南方ではどこでも竹が手に入るので、竹の枝を切って束ね、柄を長く硬く作る。高い梁や垂木まで届き、使い込んでもばらけない。この話に典籍の裏づけはないが、毎年この日、戸口の竹箒と庭の寝具が、その話が今も生きていることを示している。

## テーマ

このスキンは竹箒を一本、画面の左側に斜めに立てかけ、そのそばに四つの小さな埃がゆっくり浮かぶように描く。箒は使い込まれ、掃いた跡が残り、埃は細かく散らずに寄っている。掃くという動作はそれ自体が軽く、音もない。それが小年の意味に合っている。祝うのではなく、一年をきれいに片づけ、このあとに来る大きな日のために場所を空けるのである。
