# 感謝祭

## 概要

アメリカの感謝祭は11月の第4木曜日、収穫期が早いカナダでは10月の第2月曜日である。アメリカでは休暇が木曜日から日曜日まで続くことが多く、翌日の買い物の日は「ブラックフライデー」と呼ばれる。中心にあるのは家族の食卓と感謝を述べることで、主菜は七面鳥の丸焼きである。

## 由来

1789年、ワシントンは全国的な感謝の日を宣言した。その後長く、日付は各州が定めていた。1863年、南北戦争のさなか、リンカーンは11月の最後の木曜日を全国の感謝祭と宣言した。1941年、アメリカ議会は法案を可決して11月の第4木曜日に固定し、1942年から実施された。カナダでは1957年1月31日の宣言により10月の第2月曜日とされ、主として収穫と結びついている。

## 習わし

1. **家族の夕食**：七面鳥の丸焼き、詰め物、クランベリーソース、マッシュポテト、南瓜の煮込みとパンプキンパイ。献立は19世紀にほぼ固まった。
2. **パレード**：ニューヨークのメイシーズ感謝祭パレードは1924年から続き、巨大な気球、山車、楽隊が順に通る。
3. **フットボール**：午後に試合が始まり中継される。多くの家庭で固定の背景音になっている。
4. **七面鳥の赦免**：ホワイトハウスが直前になって二羽を赦す。20世紀後半から慣例となった。
5. **奉仕と寄付**：フードバンク、地域の炊き出し、募金がこの日の前後に集中する。

## 物語

よく語られるのは1621年のことである。前年にメイフラワー号で着いた入植者たちは厳しい冬を越し、半数近くが死んだ。翌年、先住民に教わって玉蜀黍の栽培と漁を覚え、秋の収穫のあと、ワンパノアグの人々とともに三日間の祝いを行った。この話は後世の地誌や回想録に伝わるもので、細部はもはや確かめられない。ワンパノアグの子孫は1970年から、同じ日にプリマスで「全国哀悼の日」の行事を行い、植民地化がもたらした損失を記している。二つの記念が同じ日、同じ場所で並んで行われる。それが現在のこの日の姿である。

## テーマ

このスキンはクリーム色の紙の地に南瓜の橙を合わせる。画面の中央に南瓜が一つ、輪郭は簡素で、顔は刻まれていない。二枚の楓の葉が上からゆっくり落ち、下端には暖かな光が一か所だけ溜まる。机の下に灯りを残したような光である。図は暖かいが、暖かさは抑えられている。光源は一つだけで、二つ目はない。
