# 尾牙

## 概要

旧暦12月16日。福建省、台湾、および閩南系移民の多い東南アジアの華人社会で行われる。「牙」とは、商家が毎月2日と16日に供え物をして土地神を祀る「做牙」のことで、12月16日は一年で最後の做牙にあたるため「尾牙」と呼ばれる。

## 由来

做牙の習わしは土地神への祭祀に始まる。旧時の商店や同業の店は、毎月2日と16日に獣肉や酒、香をそろえて福德正神（土地公）を祀り、祀り終えた供え物を番頭や小僧に分け与えて腹を満たした。一年に二十四回、最初を「頭牙」、最後を「尾牙」という。年末が近づくと、雇主は尾牙の日に一年の労をねぎらって番頭や使用人を招き、あわせて翌年の人事と賃金を告げた。つまり尾牙の宴は、感謝と相談の二つの性格を持っていた。商業の形が変わるにつれて祭祀は薄れ、宴だけが残り、現在では多くの会社の年末懇親会の名として使われている。

## 習わし

1. **土地神を祀る**：店先や店内に供え卓を設け、三牲（肉・魚・鶏）、酒、糕粿を並べ、香を焚き、爆竹を鳴らして一年の加護に感謝する。
2. **尾牙の宴**：雇主が全員を招く。かつては自宅の中庭に卓を並べたが、今はレストランが多い。席上では抽選会、紅包（お年玉）の配布、長年の勤続者への表彰が行われる。
3. **潤餅と刈包を食べる**：閩台の一帯では尾牙に潤餅（薄い皮で野菜を巻いたもの）と刈包（蒸しパンに豚の角煮を挟んだもの）を食べる。財布に似た形から「財を包み込む」縁起を取る。
4. **鶏の頭の作法**：かつては宴に白斬鶏（ゆでた鶏のぶつ切り）が必ず出され、鶏の頭が誰を向くかで雇主の意向が示された。後に気まずさを避けるため、頭を下に向けるか取り除くようになった。
5. **帳尻を合わせる**：前後に売掛金を回収し、年末手当を支給し、翌年の計画を立てる。昔は「借金は尾牙を越さない」と言われた。

## 物語

尾牙について最もよく語られるのは、あの鶏の頭である。かつては雇主が面と向かって使用人を解雇しにくかったため、尾牙の宴で白斬鶏の頭をある人に向け、向けられた者は翌年は来なくてよいと悟ったという。続けてほしい相手がいる場合は、雇主が自分のほうへ頭を向けるか、いっそ取り除いた。この暗黙の合図はあまりに露骨だとされ、しだいに内々に伝える形へ変わり、鶏の頭も人を指さなくなった。話の真偽はもはや確かめようがないが、一つの事実は伝えている。昔の店にとって、食事は報酬であると同時に契約でもあった。

## テーマ

このスキンが描くのは、宴が終わろうとする食卓である。低く垂れた一灯、垂れ下がったテーブルクロスの一角、そして置かれたままの一双の箸。灯はまだ点いており、クロスは緩み、箸は横たわったまま上げられない。尾牙の瞬間はここにある。一年の話は終わり、人も去り、卓上には食べ終わったあとの空白だけが残っている。
