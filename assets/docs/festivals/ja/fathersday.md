# 父の日

## 概要

六月の第三日曜日は、父の日としてもっとも広く使われている日付である。アメリカ、中国本土、日本などがこの日に贈り物や食事会を行う。法定の休日ではなく、すべての地域が同じ日というわけでもない。台湾では八月八日が用いられる。「八八」が「爸爸」（パパ）と同じ音になるためである。タイは十二月五日、スペインなどは三月十九日としている。

## 由来

近代の父の日はアメリカに始まる。一九〇九年、ワシントン州スポケーンのソノラ・スマート・ドッドは、母の日の礼拝を終えたあと、教会の牧師に、父を記念する日も必要ではないかと尋ねた。彼女の母は六人目の子を産むときに亡くなり、父ウィリアム・スマートは南北戦争の従軍者で、その後は田舎の農場で六人の子をひとりで育てた。一九一〇年六月十九日、スポケーンで最初の父の日の行事が行われた。その後数十年かけてこの考えは広がっていく。一九二四年にクーリッジ大統領が支持を表明し、一九六六年にジョンソン大統領が六月を父の月と宣言し、一九七二年にニクソン大統領が署名して、六月の第三日曜日が全国的な父の日となった。

## 習わし

1. **花を贈る**：父が存命なら赤い薔薇やデンドロビウム、亡くなった父には白い花を。ドッド夫人の頃からの作法である。
2. **贈り物とカード**：子がカードを書き、小さな贈り物を用意する。学校では工作や作文の行事が行われる。
3. **家族の食事**：子が料理をしたり店を予約したりして、父はその日台所に立たない。
4. **遠くからの挨拶**：離れて暮らす父に電話やビデオ通話をする。
5. **地域の催し**：六月には父子マラソン、親子運動会、チャリティ販売などが開かれる都市もある。

## 物語

一九一〇年の春、ドッド夫人は牧師のラスマスとキリスト教女子青年会の協力を得て、最初の父の日の準備を進めた。日付は父の誕生日である六月五日とされたが、準備が間に合わず、その月の第三日曜日、六月十九日に移された。地元紙はその日の礼拝を報じている。以後六十二年間、ドッド夫人は手紙を書き、講演をし、実業界、教会、歴代大統領に働きかけ続け、一九七二年に父の日はアメリカの全国的な行事となった。彼女は一九七八年に亡くなっており、その結果を生前に見ている。

## テーマ

このスキンが描くのは古い上着の肩の線だけである。茶系の色、広い肩、ポケットもボタンもなく、飾りは一切なく、肩の曲線は一筆で通されている。父の姿は、しばしば扉の裏に掛けられた一着の衣服に圧縮される。形を支えているのは肩であって、顔ではない。画面に人物はなく、残るのはひとつの幅だけである。
