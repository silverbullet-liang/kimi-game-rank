# 朝鮮戦争 記念日

## 概要

10月25日は、中国で中国人民志願軍の朝鮮戦争参戦を記念する日とされている。1950年10月19日に中国人民志願軍が朝鮮へ渡り、10月25日、第40軍第118師が両水洞・豊下洞地区で北鎮方面へ進む南朝鮮軍第6師の一部と遭遇して入朝後最初の戦闘を行い、同日深夜から26日未明にかけて温井を占領した。1951年、中国共産党中央は10月25日を記念日と定めた。朝鮮休戦協定は1953年7月27日に板門店で署名され、志願軍は1958年に朝鮮から全面撤収した。

## 由来

1950年6月、朝鮮半島で戦闘が始まり、アメリカはただちに武力で介入し、第七艦隊を台湾海峡へ派遣した。9月の仁川上陸ののち国連軍は北へ進み、10月初めに38度線を越えて鴨緑江に迫った。10月、中国共産党中央は出兵を決定して中国人民志願軍を組織し、10月19日に川を渡った。10月25日午前、第118師は両水洞・豊下洞一带の谷で北進する敵を待ち伏せし、約1時間の戦闘で南朝鮮軍第6師第2連隊の1個大隊と砲兵中隊を壊滅させ、続いて温井を攻め取った。第一次戦役はここから始まり、同年末に戦線は38度線付近まで戻った。1951年、志願軍政治部の建議により、党中央はこの最初の戦闘の日を記念日とした。

## 習わし

1. **陵園での墓参**：瀋陽抗米援朝烈士陵園は1951年に設けられ、黄継光、楊根思、邱少雲らが眠る。この日の前後に献花と墓参が行われる。
2. **遺骨の帰還**：2014年から、韓国で見つかった志願軍烈士の遺骨が分けて本国へ戻り、瀋陽の陵園に埋葬される。儀式は毎年秋に行われる。
3. **記念式典と記念章**：十周年ごとに式典が行われ、2020年には「中国人民志願軍抗米援朝出国作戦70周年」記念章が交付された。
4. **二つの国での記念**：2019年10月25日、中朝両国の代表が平壌の友誼塔に花輪を捧げた。
5. **聞き書きと資料**：近年、老兵の聞き書き、戦地の手紙、公文書の整理と出版が進んでいる。

## 物語

1951年4月11日、魏巍のルポルタージュ「誰が最も可愛い人か」が『人民日報』に載った。書かれたのは朝鮮戦線の普通の兵士たちである。戦闘のあとの会話、防空壕のなかで分け合った食事、書きかけの家書。発表後、「最も可愛い人」は志願軍の兵士を指す通りの言い方となり、その後も長く使われた。この文章と10月25日との関係は間接的である。最初の戦闘を描いたものではないが、のちに人々がこの日を思うときに浮かべる顔をつくった。

## テーマ

このスキンは赭紅と土黄の二色を用い、幾何学的な面を同じ斜めの方向へ押し出すように重ねる。縁はそろわず、押されたような形になる。色は土と古い軍服から取り、明るい色はない。画面の方向はただ一つ、前へであり、それはこの日が記録する前進の方向と重なる。
