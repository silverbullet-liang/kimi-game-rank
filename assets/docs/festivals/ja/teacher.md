# 教師節

## 概要

九月十日は中国の教師節であり、一九八五年に設けられた。法定の休日ではなく、学校はこの日に表彰、花の贈呈、各種の行事を行う。これに対して台湾では九月二十八日、孔子の誕生日を教師節としており、ユネスコは一九九四年から十月五日を世界教師デーとしている。

## 由来

中国には古くから師を尊ぶ伝統があり、旧暦の孔子の誕生日は釈奠の日とされ、書院や私塾は入学のときと年末に礼を行った。近代の教師節の日付は何度か変わっている。一九三一年、邰爽秋、程其保らが六月六日を教師節とすることを提唱し、教師の待遇改善、職の保障、修養の向上の三点を掲げる宣言を発表した。一九三九年、当時の政府は孔子の誕生日に改めた。一九四九年以降、一九五一年には五月一日の国際労働節を教師節とすることが告げられた。一九八五年一月二十一日、第六期全国人民代表大会常務委員会第九回会議は教師節の設置に関する決定を採択し、国務院の議案に同意して、毎年九月十日を教師節と定めた。

## 習わし

1. **表彰と慰問**：学校と教育当局が節の前に優秀な教師を選び、退職した教師や農村の教師を訪ねる。
2. **花とカード**：児童・生徒がカードを作り、礼状を書き、授業の前にそろって起立して挨拶する。
3. **学級活動と職徳教育**：師を尊ぶことを主題にした学級活動が行われ、新任の教師はこの日に宣誓する。
4. **公開授業と研究協議**：この日を公開授業の日とし、保護者や同僚に授業を見せる学校もある。
5. **社会への発信**：報道機関が教師の物語を集中的に伝え、観光地によっては教師の入場を無料とする。

## 物語

伝えるところによれば孔子の弟子は三千人あり、『史記』仲尼弟子列伝は「業を受け身に通ずる者七十有七人」と記す。旧時の私塾が孔子の像の前に礼をするのは、入学と節句の折りの定まった作法であった。一九八四年十二月、北京師範大学の教授数名が連名で教師節の設置を提案し、翌年一月二十一日に全国人民代表大会常務委員会が決定を採択した。九月十日が選ばれた理由のひとつは時期にある。新学年が始まったばかりで学校が行事を組みやすく、九月には国の記念日が少ないため、広報が重ならない。一九八五年九月十日が最初の教師節である。
