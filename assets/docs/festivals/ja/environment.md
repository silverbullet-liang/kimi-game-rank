# 世界環境デー

## 概要

毎年六月五日。国際連合が定めた日である。一九七二年六月五日から十六日まで、国連人間環境会議がスウェーデンのストックホルムで開かれ、同年十月、第二十七回国連総会は会議の開幕日である六月五日を世界環境デーとする決議を採択した。国連環境計画は毎年テーマを発表し、記念の行事を開いている。

## 由来

一九七二年のストックホルム会議は、環境問題を地球規模で論じた最初の国連の会議であった。会議は「ただ一つの地球」という合言葉を掲げ、『国連人間環境宣言』と、百九項目の勧告を含む行動計画を採択した。同年十月、第二十七回国連総会は六月五日を世界環境デーと定め、一九七三年一月には国連環境計画の設立を決めた。同計画が毎年のテーマを定めている。中国でも一九八〇年代から六月五日に広報行事が行われ、二〇一五年に施行された環境保護法はこの日を環境の日と定めている。

## 習わし

1. **テーマの発表**：国連環境計画が毎年テーマと主催都市を発表し、各国がそれに沿って行事を組む。
2. **植樹と清掃**：河岸のごみ拾い、植樹、ごみ分別の広報。
3. **企業の取り組み**：排出削減の約束、環境に配慮した調達、清掃工程の公開。
4. **環境教育**：自然教室、不用品を使った工作、低炭素の記録。
5. **展示と映画**：水、大気、生物多様性を題材にした写真展と記録映画の上映。

## 物語

一九七二年六月五日、ストックホルム会議が開幕し、百十三か国から千三百人余りの代表が参加した。準備の段階で、事務局長のモーリス・ストロングは数十か国の専門家に依頼し、『ただ一つの地球』と題する非公式の報告書を作らせた。これが討議の土台となった。会議は七つの共通の視点と二十六の原則からなる『人間環境宣言』を採択し、百九項目の勧告を含む行動計画を添えた。開幕日を世界環境デーとすることが提案され、同年十月の第二十七回国連総会で承認された。

## テーマ

葉が一枚、葉脈が細い線で描き込まれ、主脈から両側へ枝分かれして縁まで届いている。葉の外には枝も背景もなく、緑は線の上にだけ残る。葉脈は木の縮図である。水と養分は一本の線から細い線へと分かれ、葉はその分布によって生きている。
