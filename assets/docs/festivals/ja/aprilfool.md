# エイプリルフール

## 概要

4月1日。英語で April Fools' Day、別名を万愚節ともいう。どの国の法定休日でもなく、統括する主催者も、決まった儀礼もない。通用している決まりはただ一つである。この日に冗談を言い、人を傷つけない小さな嘘をつく。だまされた人は「四月の愚か者」と呼ばれる。

## 由来

起源には定説がなく、いくつかの説が併存している。もっとも広く語られるのは16世紀フランスの暦の改革に関わる説である。新年はかつて3月末から4月初めに数えられていたが、のちに1月1日へ移された。それでも旧暦どおり4月初めに新年を祝い贈り物をする人が笑いものにされ、「四月の愚か者」と呼ばれ、贈り物も冗談の品にすり替えられたという。別の説は、ローマのヒラリア祭や中世の「愚者の祭」に遡らせ、4月の初めは秩序を逆転させてよい時期だったと考える。いずれも決定的な証拠を欠き、学界では今も議論が続いている。

## 習わし

1. **午前中の冗談**：イギリスやフランスの古い言い方では、冗談は正午までで、午後まで続ける者はかえって愚か者とされた。現在これを守る人は少ない。
2. **メディアの作り話**：新聞、ラジオ、テレビ、ウェブサイトがこの日に架空の記事を載せ、読者は途中まで読んでから気づく。この伝統はすでに百年以上続いている。
3. **偽の贈り物と偽の知らせ**：贈り物の包装をした空箱、緊急連絡の体裁をした紙片、同僚に送る偽のメールなど、いずれも手間のかからない種類である。
4. **企業による「偽発表」**：この二十年ほど、多くの企業がこの日に存在しない製品を発表し、発想の面白さを示す。
5. **節度**：共通の線引きは、人を傷つけない、金銭を絡めない、本当の不安を起こさない、というものである。この線を越えた冗談は祭りではなく事故として扱われる。

## 物語

1957年4月1日、英国放送協会（BBC）の報道番組「パノラマ」は、およそ3分の報告を放送した。スイスのティチーノ州で今年は「スパゲッティの木」が豊作で、農家が木からスパゲッティの束を摘み取っているという内容で、映像には女性が枝から麺を外して籠に入れる様子が映っていた。当時スパゲッティはイギリスではまだ珍しい食べ物で、多くの視聴者が本気にし、家庭でスパゲッティの木を育てる方法を尋ねる電話を局にかけた。番組側の答えは、麺を一本トマトソースの缶に挿して「幸運を祈る」というものだった。この報告はその後くり返し引用され、この日にもっとも有名な冗談となっている。

## テーマ

このスキンは、上下を逆さにした疑問符を一つと、破線を一本だけ描き、色を極端に抑えている。疑問符は問いの形であり、逆さにすると理屈の通らない形になる。破線は、つながっているはずの線が途中で断たれたものである。エイプリルフールに赤も金も要らない。必要なのは、ほんの少しねじられた記号だけである。
