# 中国人民抗日戦争勝利記念日

## 概要

九月三日は中国人民抗日戦争勝利記念日である。一九四五年九月二日、日本は東京湾の戦艦ミズーリ号の上で降伏文書に調印し、九月三日が勝利の記念日とされた。二〇一四年二月二十七日、第十二期全国人民代表大会常務委員会第七回会議は、立法の形で九月三日を中国人民抗日戦争勝利記念日と定め、毎年この日に国の記念行事を行うことを決めた。

## 由来

一九四五年八月十五日、日本はポツダム宣言の受諾を表明し、九月二日に降伏文書に調印した。当時の中国政府は九月三日を勝利記念日とし、一九四六年から記念行事を行った。一九五一年八月十三日、中央人民政府政務院は通告を出し、九月三日を抗日戦争勝利記念日と定める。二〇一四年二月二十七日、全国人民代表大会常務委員会は決定を採択し、立法の形で九月三日を中国人民抗日戦争勝利記念日とし、毎年この日に国の記念行事を行うことを規定した。

## 習わし

1. **国の記念行事**：九月三日、中国人民抗日戦争記念館などで式典が行われ、抗日の犠牲者に花が供えられる。
2. **黙祷とサイレン**：式典で黙祷が行われ、一部の都市では防空警報が鳴らされる。
3. **展示と史料公開**：戦争を主題とする展示、公文書の公開、聞き取り調査の成果は秋にまとめて発表されることが多い。
4. **学校の活動**：記念館の見学、映画鑑賞、史料の読解、学級での学習。
5. **民間の追悼**：団体が烈士の墓地や戦跡を訪れ、花を供え、木を植える。

## 物語

一九四五年九月二日の午前、東京湾の戦艦ミズーリ号の甲板で、外相重光葵が天皇と日本政府を代表し、参謀総長梅津美治郎が日本軍の大本営を代表して降伏文書に署名した。連合国側の代表であるマッカーサー、ニミッツ、そして中国の代表徐永昌らが続いて署名する。式の後、その報は中国に伝えられ、重慶や延安などで祝賀の行事が行われた。以後、九月三日が中国側の勝利記念日となる。一九五一年の政務院の通告はこの日付をそのまま用い、二〇一四年の立法による決定もこれを引き継いだ。
