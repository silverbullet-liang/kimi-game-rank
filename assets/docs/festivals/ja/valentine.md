# バレンタインデー

## 概要

2月14日。聖バレンタインデーとも呼ばれる。多くの国で行われ、恋人や伴侶をめぐる日とされている。どの国の法定休日でもなく、統括する主催者も存在しない。その作法は、主として商業と民俗のなかから自然に形づくられてきた。

## 由来

この日はキリスト教の聖人ウァレンティヌス（Valentine）の名と結びついている。ただしその聖人が誰であり、どのような事績があったのかについては複数の伝えがあり、実証できる部分は限られている。そのため通常は、名のつながりだけが語られる。2月14日と恋愛とを結びつけた起源は、一般に14世紀のイングランドに求められる。チョーサーの詩『鳥の議会』は、この日を鳥がつがいを選ぶ日として描いたもっとも早い英語作品の一つとされ、その後「恋人の日」という考えがヨーロッパに定着した。19世紀半ば以降、印刷されたカードが広まると、この日は民俗から買えるものへと変わり、バラ、チョコレート、カード、ディナーの組み合わせは、それ以降に層をなして加えられていったものである。

## 習わし

1. **バラを贈る**：赤いバラがもっとも一般的である。本数や色に込められた意味の多くは後世の付会である。花屋の売り上げはこの日、平日のそれを大きく上回る。
2. **チョコレートと菓子**：日本では独自の習慣が発達し、恋人に贈るもの、同僚に配るもの、自分ためのものなどに分けられ、それぞれ名称も意味も異なる。
3. **カードとメッセージ**：名前を書いてもよく、書かなくてもよい。差出人不明のカードは、初期のイングランドで広く行われた遊びであった。
4. **ディナーとプロポーズ**：レストランは二人用のコースを用意し、この日に求婚したり婚姻の届けを出したりする人も多い。
5. **公開の表明と装飾**：街頭、商店、学校にハートや赤い飾りが現れ、SNS には愛情の表明が集中する。

## 物語

ウァレンティヌスについて比較的広く流布しているのは次のような話である。ローマ皇帝が兵士の結婚を禁じたところ、ウァレンティヌスという名の聖職者が若い男女のために内密に結婚を執り行い、そのために処刑された。処刑の前に彼は、獄中で知り合った盲目の娘に手紙を書き、末尾に「あなたのウァレンティヌスより」と署名した。この話には細部の異なる複数の版があり、年代も人物も確認できない。伝説に属する語りである。確かなのは、この署名の仕方が残り、英語で名前を伏せた恋文の結び方になったことである。

## テーマ

このスキンは白い地に、一本の線だけで描いたバラを置き、花びらには色を塗っていない。赤もなく、ぼかしもなく、ただ一本の線が行き来して一輪の花を完成させる。バレンタインデーはふつう塗りつぶすように描かれるが、このスキンはその逆を行き、花を彩色する前の段階に留めている。描きたいのは熱の部分ではなく、まだ口に出していない時間のほうだからである。
