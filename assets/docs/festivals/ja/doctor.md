# 中国医師節

## 概要

八月十九日は中国医師節である。二〇一七年十一月三日、国務院は、二〇一八年から毎年八月十九日を「中国医師節」とすることに同意した。実施は旧国家衛生計画出産委員会（現在の国家衛生健康委員会）が関係部門と協議して進める。二〇一八年八月十九日が最初の中国医師節である。法定の休日ではなく、病院や衛生機関がこの前後に表彰、無料診療、施設の公開などを行う。

## 由来

日付の選択は二〇一六年八月十九日に関わる。この日、全国衛生・健康会議が北京で開かれた。医師の日を設ける提案は、それ以前から業界団体、全国人民代表大会の代表、政治協商会議の委員によって長く出されていた。中国医師節は、看護師の日、教師の日、記者の日に次ぐ、中国で四番目の職能別の記念日である。

## 習わし

1. **表彰**：各級の衛生健康部門と病院が優秀な医師とチームを選び、節の前に表彰式を行う。
2. **無料診療と啓発**：病院が専門医を地域や農村へ派遣して診療にあたり、健康講座や救急講習も開く。
3. **施設の公開**：手術室、検査部門、教育施設を公開し、診療の流れを一般に見せる病院もある。
4. **訪問と慰問**：退職した医師、農村の医師、海外や新疆・チベットへ派遣された医療隊の家族を訪ねる。
5. **宣誓**：新しく着任した医師が医師の宣誓を読み上げ、経験の長い医師がこの日にこれを復唱する。

## 物語

二〇一六年八月十九日、全国衛生・健康会議が北京で開かれた。それから一年あまり後の二〇一七年十一月三日、国務院は旧国家衛生計画出産委員会の申請を認め、二〇一八年から毎年八月十九日を「中国医師節」とすることを決めた。二〇一八年八月十九日、最初の中国医師節の日、各地の病院では短い式が行われ、いくつかの診療科はいつもどおりの勤務を続けた。この日付は、あの会議の日に応じている。これに対して看護師の日は五月十二日、ナイチンゲールの誕生日をそのまま用いており、二つの職能別記念日の由来は同じではない。
