# 辛亥革命

## 概要

10月10日は辛亥革命の記念日である。1911年10月10日（旧暦辛亥年八月十九日）の夜、武昌蜂起が起こった。辛亥革命はここから広がり、清朝の支配は終わった。1912年1月1日には中華民国臨時政府が南京に成立し、孫文が臨時大総統に就任した。10月10日は以来記念され、台湾地区では「双十節」と呼ばれる。

## 由来

1911年の夏、四川で保路運動が起こると、清廷は湖北の新軍の一部を四川へ移し、武漢の守備は手薄になった。湖北の革命団体である文学社と共進会は、同盟会中部総会の働きかけで合同し、9月24日の会議で蒋翊武を臨時総司令、孫武を参謀長に推し、10月6日の挙兵を決めたが、のちに延期された。10月9日、孫武が漢口のロシア租界宝善里の拠点で爆弾を製造中に爆発し、文書が押収されて拠点が露見、名簿に基づく逮捕が始まり、彭楚藩、劉復基、楊洪勝が殺された。10月10日の夜、新軍の工程第八営の革命党がまず行動を起こし、中和門に近い楚望台の兵器庫を占拠、呉兆麟が臨時総指揮に推され、一夜の戦闘で湖広総督署を攻め落とした。11日に湖北軍政府が成立し、12日には武漢三鎮が革命軍の手に落ちた。中和門は首義の功により1912年に起義門と改名された。

## 習わし

1. **起義門を訪ねる**：武昌の中和門の旧址で、城楼と城壁の一部が残り、蜂起の出発点とされる。
2. **記念館の見学**：鄂軍都督府の旧址（紅楼）は辛亥革命武昌起義記念館となり、1961年に第一批全国重点文物保護単位に指定された。辛亥革命博物館は100周年にあたる2011年、首義広場の南側に開館した。
3. **記念式典と研究集会**：十周年ごとに式典が行われ、学界では研究集会や資料の整理も行われる。
4. **献花と展示**：彭劉楊路一帯の烈士祠や起義門の城楼では、この日の前後に献花と写真展が行われる。
5. **二つの記念**：大陸では辛亥革命記念日、台湾地区では10月10日を「双十節」と呼び、それぞれに儀式がある。

## 物語

蜂起の夜、最初の一発を誰が撃ったかについては記録が一致しない。熊秉坤、程正瀛などの名が挙げられ、研究者の根拠も分かれる。確かなのは、工程第八営が発端となり、目標が楚望台の兵器庫であり、そこにあった銃砲がその後の戦いを支えたこと、総督署へ夜のうちに三度攻撃をかけて夜明け前に落としたこと、一夜で一つの省城が支配者を変えたことである。指導した者の多くは中下級の将校と兵士であり、本来の指導者は逮捕され、逃亡し、あるいは負傷していた。事後に成立した軍政府は黎元洪を都督に推したが、この転換は当時から議論の対象であった。

## テーマ

このスキンは暗い赤と鉄の灰色の二色を用い、幾何学的な面を横に重ねる。縁は硬く真っ直ぐで、弧はない。赤は祝祭の赤ではなく、錆と鉄の色に近い。面のあいだに残された隙間のため、画面全体が一歩押し出されたように見える。首義は夜に起こり、この図も夜にとどまっている。
