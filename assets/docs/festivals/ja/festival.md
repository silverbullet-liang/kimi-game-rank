# 国慶節

## 概要

10月1日は中華人民共和国の国慶節である。1949年10月1日午後3時、建国の式典が北京の天安門広場で行われ、中華人民共和国中央人民政府の成立が宣言された。1949年12月2日、中央人民政府委員会第4回会議は「中華人民共和国国慶日に関する決議」を採択し、中国人民政治協商会議第一届全国委員会の建議を入れて、毎年10月1日を国慶日と定めた。このスキンは9日間にわたる窓のテーマで、9月30日から10月8日まで表示され、烈士記念日と国慶節の休暇を一続きのうちに収める。

## 由来

1949年10月1日午後3時、式典が始まり、毛沢東が天安門の楼上で公告を読み上げ、次いで電源のボタンを押して最初の五星紅旗を掲げた。54門の礼砲が28発を斉射し、そのあとに閲兵と群衆の行進が続いた。1949年から1959年までは毎年閲兵が行われ、その後は「五年ごとに小慶、十年ごとに大慶」の方針で、1984年、1999年、2009年、2019年に閲兵が行われた。1999年、国務院は「全国年節及び記念日休暇弁法」を改正し、国慶節の法定休日を1日から3日に増やし、振替休日を合わせて7日間の連休とした。長期休暇はここから制度になった。2020年前後には、国慶節と中秋節が同じ連休に入る年もある。

## 習わし

1. **国旗掲揚**：天安門広場の掲揚は日の出の時刻に合わせて行われ、国慶節の日は見学者が最も多い。
2. **閲兵と群衆行進**：大慶の年に行われ、徒歩の隊列、装備の隊列、空中の梯団が順に広場を通る。
3. **国旗を掲げる**：役所、学校、商店、住居が入口や窓に旗を掲げ、通りの両側が赤の列になる。
4. **旅行と帰省**：7日間の連休は一年で最も移動が集中する二つの時期の一つで、鉄道、道路、観光地が高い稼働となる。
5. **広場の花壇と夜景**：天安門広場には毎年テーマのある花壇が設えられ、夜間はライトアップされる。

## 物語

建国の式典についてよく語られる細部は三つある。午後3時という開始時刻は防空を考慮して決められた。国旗は電動装置で掲げられ、毛沢東がボタンを押すと旗が旗竿を上った。54門の礼砲が28発を撃ち、砲声と掲揚が同時であった。その日、広場には30万人が集まり、空中を通過した航空機のうち4機は実弾を搭載していた。これらの細部は当時の報道と後世の聞き書きに見えるもので、あの午後を知る主要な入口となっている。

## テーマ

このスキンは赤と金の二色でできている。赤を地に、金を線と縁に用い、幾何学的な面をその上に配する。旗、灯籠、飾り紐を抽象した形だが、特定の物を指しはしない。祝祭の濃度だけを上げている。窓が9日間に及ぶため、この色は前後の日常の中に長く居続け、静かな二つのテーマのあいだをつなぐ。
