# 母の日

## 概要

毎年五月の第二日曜日が、多くの国で行われる母の日である。花やカード、家族での食事などを通じて母に感謝を伝える日とされる。中国では法定の休日ではなく、カーネーションやワスレグサ（萱草）を贈る習慣が一般に広がっている。

## 由来

現代の母の日はアメリカに始まる。一九〇六年五月、フィラデルフィアのアンナ・ジャービスが母を亡くしたことを機に、母を記念する日を設ける運動を始めた。一九〇八年五月十日、故郷で最初の母の日の行事が開かれ、一九一四年にはアメリカ議会が五月の第二日曜日を母の日とする決議を可決した。さらに古い由来が二つある。古代ギリシアでは春に神々の母に供物を捧げ、十七世紀のイギリスでは四旬節の第四日曜日を「母を訪ねる日」とし、奉公に出た子女が母のもとへ帰ることを許された。

## 習わし

1. **カーネーション**：赤や桃色は在世の母に、白は亡くなった母を思って贈る。この習慣はアンナ・ジャービスに由来する。
2. **ワスレグサ**：中国では古くから萱草が母の住まいを指す言葉とされ、母の花として贈られることがある。
3. **カードと手作り**：子どもが手書きのカードを書き、工作の贈り物を作る。学校でも行事が組まれる。
4. **家族の食事**：子が帰って料理をしたり店を予約したりして、家事を代わる。
5. **電話と訪問**：離れて暮らす母に電話やビデオ通話をし、贈り物を送る。

## 物語

一九〇六年五月九日、フィラデルフィアでアンナ・ジャービスの母が亡くなった。翌年の命日に彼女は親しい人を集めて追思を行い、ウェストバージニア州グラフトンの教会に手紙を送り、母のために特別な礼拝をしてほしいと願い出た。母はその教会の日曜学校で二十年余り教えていた。一九〇八年五月十日、教会は彼女の母をしのぶ礼拝を開き、あわせてすべての母を記念した。これが現代の母の日の最初の行事とされる。彼女はその後も手紙と講演を重ね、国としての母の日を求めた。

## テーマ

三枚の花びらを持つカーネーションが一本、柔らかい桃色に生成りの白を合わせ、茎は細くまっすぐで、葉は二筆だけ添えられている。花びらは塗り残され、花の芯には少し空白がある。切り取ってすぐ瓶に挿した一枝のようである。色はごく淡く、声を張らない桃色になっている。
