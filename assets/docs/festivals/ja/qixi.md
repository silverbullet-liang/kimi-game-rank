# 七夕

## 概要

旧暦七月七日の七夕は、乞巧節、女子節、双七節とも呼ばれる。牽牛と織女の伝説に結びつき、伝統的な節句のなかで女性、手仕事、星にもっとも深く関わる日である。二〇〇六年、七夕は第一次国家級無形文化遺産リストに登録された。日本、朝鮮半島、ベトナムにも同じ起源の習わしがあり、日付も作法もそれぞれに異なる。

## 由来

七夕は星の観察に始まる。牽牛星と織女星は天の川の両岸にあり、『詩経』小雅・大東にはすでに織女と牽牛を詠んだ句がある。漢代には七月七日と針に糸を通す技くらべが結びつき、『西京雑記』によれば、宮中の女たちは七月七日に開襟楼で七孔針に糸を通した。後漢以降、牽牛と織女はしだいに夫婦の姿を与えられ、『古詩十九首』にはすでに遠い牽牛星と明るい河漢の女をうたう恋慕の句がある。晋代以降、七夕は定まった節句となり、巧を乞い子を乞う風習は唐宋に盛んになった。

## 習わし

1. **針に糸を通して巧を乞う**：月の下で色糸を七孔針に通し、速さを競う。うまく通せた者に巧みが宿るとされた。
2. **巧果と花果を供える**：庭に机を出し、型菓子、瓜や果物、蓮根、花を供える。乞巧桌と呼ぶ地方もある。
3. **星を眺める**：日が落ちてから天の川の両側の二星を探し、年長者が子に伝説を語る。
4. **髪を洗い爪を染める**：柏の葉や桃の枝を煎じた湯で髪を洗い、ホウセンカで爪を染める地方がある。
5. **現在の過ごし方**：花を贈り、会い、婚姻の届けを出す。集団結婚式や手仕事の市を開く都市もある。

## 物語

伝えるところによれば、牽牛は人の世の牛飼いの孤児、織女は天上で錦を織る仙女であった。二人は夫婦になり一男一女をもうけ、男は耕し女は織った。西王母がこれを知って織女を天へ連れ戻すと、牽牛は老牛の皮をまとって追い、西王母は金の簪で彼の後ろを一劃し、天の川を引いた。二人は川を隔てて向かい合う。鵲は毎年七月七日の夜に橋を架け、二人はそこで年に一度会う。この話が整った形をとるのは漢代以降の文献と語り物においてであり、細部は土地ごとに違いがある。鵲の橋での再会がもっとも広く語られる一節である。

## テーマ

このスキンは、ページの上部に斜めに走る星河を置き、両岸にそれぞれ光芒のある明るい星を一つずつ配する。星河は左上から右下へ傾き、二つの星は高さも、川からの距離も等しくない。光芒はごく細い四方向の筋で、またたかず、動かない。七夕の筋書きはこの距離のなかにある。渡れない光の帯を挟んで、両端に星が一つずつ。
