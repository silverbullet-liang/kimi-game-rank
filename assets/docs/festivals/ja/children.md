# 国際こどもの日

## 概要

毎年六月一日。中国語では「国際児童節」「六一国際児童節」と呼ばれる。一九四九年十一月、国際民主婦人連盟がモスクワで理事会を開き、毎年六月一日を国際こどもの日とすることを決めた。同年十二月二十三日、中央人民政府政務院は中国の児童節をこの日付に統一すると規定した。

## 由来

この日の設立は一九四二年のリディツェ事件と関わる。一九四二年六月十日、ナチス・ドイツの部隊がチェコスロバキアのリディツェ村を襲い、成年の男子を殺害し、女性と子どもを強制収容所へ送った。一九四九年十一月、国際民主婦人連盟はモスクワで理事会を開き、リディツェ村と戦争で命を落とした子どもたちを悼み、子どもの殺害と毒害に反対するために、毎年六月一日を国際こどもの日とすることを決めた。その趣旨には、生存権、保健の権利、教育を受ける権利の保障が含まれている。

## 習わし

1. **芸能の発表**：学校や幼稚園が発表会を開き、子どもが歌い、踊り、劇をする。
2. **入隊式**：小学校では六月一日の前後に少年先鋒隊の入隊式が行われる。
3. **贈り物と遊園会**：親は本や文房具、玩具を贈り、公園には遊園会やゲームの屋台が並ぶ。
4. **入場の無料・割引**：図書館、科学館、動物園がこの日の子どもの入場を無料または割引にする。
5. **支援の行事**：児童養護施設を訪ね、困難を抱える子どもに学用品を届ける。

## 物語

一九四二年五月、ナチス・ドイツのベーメン・メーレン保護領長官ハイドリヒが暗殺された。六月十日、ドイツ軍はプラハ郊外のリディツェ村を包囲し、十五歳以上の男子を集めて銃殺し、女性と子どもを強制収容所へ送り、村を焼いた。戦後の調査では、村の子どもの多くは生き延びられなかった。一九四九年十一月、国際民主婦人連盟はモスクワの理事会で、この記憶を子どもの生存権、保健の権利、教育を受ける権利につなげ、国際こどもの日を設けることを決めた。同じ月、中国の政務院もこれに対応する規定を定めた。

## テーマ

色の異なる三つの積み木がずれて積まれ、右上では紙飛行機が斜め上へ飛んでいる。積み木は組んでは崩すもの、紙飛行機は折っては飛ばすもの。どちらも画面のなかにあり、手元にあるものでまず遊ぶ、という同じことを語っている。
