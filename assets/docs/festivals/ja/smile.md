# 世界スマイルデー

## 概要

毎年五月八日。中国語で「世界微笑日」と呼ばれるこの日は、国際赤十字運動の創始者アンリ・デュナンの誕生日を記念する「世界赤十字・赤新月の日」と同じ日である。この日は笑顔の図柄、街頭の催し、心の健康についての講座などを通じて、感情や人と人との関係に目を向ける機会とされる。

## 由来

五月八日はアンリ・デュナンの誕生日（一八二八年）である。一九四八年、赤十字協会の理事会はこの日を世界赤十字の日と定め、のちに世界赤十字・赤新月の日と呼ばれるようになった。中国語の資料では、同じ年に世界精神衛生機構が五月八日を「世界微笑日」とした、という説明が広く流布している。笑顔を通じて心身の健康を促し、人と人との間に善意を伝える趣旨とされる。

同じ英語名の日がもう一つある。一九六三年に商業美術家ハービー・ボールが黄色い笑顔の絵を描き、のちにその図柄が商品に使われすぎることを案じて、一九九九年に「世界スマイルデー」を提唱した。初回は彼の故郷で開かれ、現在は毎年十月の第一金曜日と定められている。二つの日は期日が異なり、中国語で「世界微笑日」と言えば通常は五月八日を指す。

## 習わし

1. **笑顔の図柄**：顔を描く、シールを配る、風船や紙の扇に描く。
2. **街頭の催し**：ボランティアが笑顔のカードを渡し、記念写真を撮る。
3. **心の健康の講座**：気分の整え方、ストレス管理、睡眠と人づきあい。
4. **学校の行事**：学級会、笑顔の壁、級友への励ましの言葉。
5. **訪問**：高齢者施設、病院、児童施設を訪ねる。

## 物語

一九六三年、マサチューセッツ州ウースターの商業美術家ハービー・ボールは保険会社の依頼を受け、十分ほどで黄色い円に二つの点と一本の曲線を描いた。報酬は四十五ドルだった。多くの記述によれば、この顔はバッジ、Tシャツ、切手に刷られ、一つの時代の表情になった。ボールはのちに図柄が商品として使われていくあり方に不安を覚え、善意について語る日を設けることを主張し、一九九九年に故郷で最初の世界スマイルデーが開かれた。

## テーマ

画面にあるのは一本の弧と二つの点だけである。弧は上に反り、点はその上に対称に置かれ、ほかには何もない。輪郭も影も文字もない。顔をここまで削り、残ったわずかな情報で足りるということが、微笑が認識される仕方そのものである。
