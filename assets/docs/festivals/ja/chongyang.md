# 重陽節

## 概要

旧暦九月九日。重九、登高節、茱萸節とも呼ばれる。中国古代の数の観念では「九」は陽の数であり、九が二つ重なることから「重陽」という名が生まれた。「九九」が「久久（久しく続く）」と同じ音であることから長寿の意味も込められ、2012 年以降、旧暦九月九日は中国の法定「老年節（敬老の日）」とされている。

## 由来

「重陽」という語はすでに屈原の『遠遊』に見えるが、季節の習わしとして形が整ったのは漢代である。『西京雑記』には、九月九日に茱萸を身につけ、餅を食べ、菊の酒を飲む習慣があったことが記されている。唐代には正式な節日となり、宮廷でも民間でも高い所に登り、宴を開き、詩を詠み、菊を愛でるようになり、以後の時代にも受け継がれた。重陽は晩秋にあたり、空気が冷え草木が色あせていく時期であるため、この日には遊興だけでなく、疫病を避け福を願う意味も重なっていた。習わしにこの二つの側面があるのはそのためである。

## 習わし

1. **登高**：秋晴れの日に山や塔に登る。一歩ずつ高くなるという縁起をとるもので、古い記録では疫病を避ける行いともされた。
2. **菊を愛で、菊の酒を飲む**：菊は晩秋に咲き、寒さに耐えて寿命を延ばす花とされた。この時期に菊を見物し、菊の酒を醸すのは古くからの風習である。
3. **茱萸をつける**：茱萸は香りが強く辛い。古くは枝を髪に挿すか、赤い小さな袋に入れて腕につけ、邪気を払った。
4. **重陽糕を食べる**：「糕（ケーキ）」は「高（高い）」と同じ音で、登高と呼応する。手の込んだものは九層に作り、上に小さな旗を挿した。
5. **敬老と帰省**：今日もっとも広く行われているもので、実家に戻って年長者に会い、食事をともにすることが多い。

## 物語

後漢の汝南の人、桓景が道士の費長房に師事していたときのこと。師は、九月九日に家に災いが起こるから、家族それぞれに赤い袋を作って茱萸を入れ腕につけさせ、高い所に登って菊の酒を飲ませるよう告げた。桓景はそのとおりに家族を連れて山へ登った。夕方に戻ると、鶏も犬も牛も羊も皆死んでいたが、家族は誰も無事だったという。この話は南朝梁の呉均『続斉諧記』に見え、のちの重陽の登高、茱萸、菊の酒の習わしはしばしばこの説話に由来するとされる。

## テーマ

このテーマは、ページ上部に斜めに流れる星河と、両岸にひとつずつ輝く星を描いている。星河が視界を二つに分けるさまは、高い所に登って遠くを望み、山と水を隔てて家族を思う重陽の心持ちに対応する。星の光はきわめて淡い金白色で、深い秋の夜の青を下地にしており、サイトでもとりわけ静かなテーマのひとつである。
