# 臘八節

## 概要

旧暦12月8日。別名を臘八（ラーバー）という。「臘」はもともと年末の祭祀の名で、この日は一年の終わりの祖先祭祀と神々への供えの日であると同時に、民間で「正月の気分」が始まる日とされる。臘八を過ぎれば、正月用品の買い出し、部屋の掃除、春聯（対聯）書きが順に始まる。

## 由来

年末の「臘祭」は先秦の時代から行われ、祖先とさまざまな神に一年の収穫を報告した。南朝梁の宗懍『荊楚歳時記』に「十二月八日を臘日と為す」とあり、少なくとも南北朝のころには臘日が12月8日に定まっていたことが分かる。その後、仏教の成道会（釈迦が悟りを開いた日）と結びつき、寺院はこの日に粥を炊いて仏に供え、人々に施すようになった。南宋の呉自牧『夢粱録』には、12月8日に寺院が「五味粥を設け、名づけて臘八粥と曰う」と記され、宋代にはすでに臘八粥が広まっていたことがうかがえる。明・清の時代になると、臘八粥は寺院の厨房から各家庭の竈へと移り、材料も各地の産物に応じて増えていった。

## 習わし

1. **臘八粥を炊く**：米、豆、棗、栗、蓮の実、落花生、桂円などを八種類あるいはそれ以上そろえ、まず祖先に供え、親類や隣人に配り、それから一家で食べる。少しだけ残すのは「年年有余」の縁起を取るためである。
2. **臘八蒜を漬ける**：華北では皮をむいた蒜を米酢に漬けて封をし、大晦日に開ける。蒜は碧色に変わり、酢には蒜の香りが移る。餃子と一緒に食べる。
3. **臘八面を食べる**：陝西省関中の一部では粥ではなく麺を食べる。豆と野菜のあんをかけ、臘八の早朝に家族そろって食べる。
4. **施粥と祖先祭祀**：寺院や道観、一部の商店がこの日に粥を施す。家庭の供え卓には祖先のための茶碗と箸が一組置かれる。
5. **正月支度の開始**：この日から正月用品を買い、肉を塩漬けにし、春聯を書く。「臘八を過ぎればもう正月」ということわざがある。

## 物語

臘八粥の由来として最も広く流布しているのは、仏の成道日に関わる説である。釈迦は長年の苦行で痩せ細りながらも悟りに至らず、牛飼いの娘がささげた乳糜（乳がゆ）によって体力を取り戻し、菩提樹の下で瞑想して悟りを開いたと伝えられる。中国漢地の暦ではその日が12月8日にあたるため、寺院はこの日に粥を炊いて仏に供えるようになった。これとは別に、より生活に近い説もある。貧しい家が年末に甕の底に残ったさまざまな穀物をかき集めて一鍋の雑穀粥にしたところ、かえって美味だったというものである。前者は寺院の儀礼に入り、後者は民間の竈の上に残った。

## テーマ

このスキンは粗い陶の器を描き、器の縁の上に七粒の穀物を浮かべ、ごく淡い湯気が一筋立ちのぼるようにしている。陶の粗さ、穀物の散らばり、湯気の軽さは、この日にもっとも実在するものごとである。一年が尽きようとするとき、残った数種の穀物を一つにまとめ、熱い一椀に炊き上げる。
