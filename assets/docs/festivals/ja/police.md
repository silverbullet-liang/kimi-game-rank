# 中国人民警察節

## 概要

毎年1月10日。正式名称は「中国人民警察節」で、国家のレベルで人民警察の隊伍のために設けられた記念日である。日付は110番（警察の緊急通報電話）の番号に由来する。2020年に中国共産党中央の承認と国務院の批复（認可回答）を経て設けられ、2021年から実施されている。

## 由来

1986年1月10日、広東省広州市公安局が中国で最初の110番報警サービス台を開設した。1996年、公安部は福建省漳州で全国都市110番サービス台建設の現場会議を開き、「漳州110」の経験を全国に広めた。以後110番は公安隊伍を代表する番号となった。2020年7月、国務院は「中国人民警察節の設立に同意する批复」（国函〔2020〕98号）を出し、2021年から毎年1月10日を「中国人民警察節」とすること、具体的な実施は公安部が関係部門と協議して行うことを認めた。

## 習わし

1. **警旗と宣誓**：各地の公安機関はこの日前後に、警察旗の掲揚や入警の誓いの読み直しなどの儀式を行う。
2. **警営の公開**：一部の警察署や交番、交通警察の施設がこの日に一般公開され、装備の展示や通報受理の流れの説明が行われる。
3. **110番の広報**：1月10日という番号の語呂に合わせ、110番の正しい使い方と、緊急回線を私用で使わないよう呼びかける活動が行われる。
4. **表彰**：一定年数の勤務を満たした警察官への記念章の授与、先進的な集団と個人の表彰が行われる。
5. **訪問と慰問**：公務で殉職した警察官の遺族、公務で負傷した警察官、退職した古参の警察官を訪ねる。

## 物語

この日の由来は制度の歴史である。1980年代半ば、沿海部の都市では治安事案と救助要請が増え、従来の通報手段では対応しきれなくなった。広州の公安は1986年1月10日、中国で最初の110番サービス台を開設し、盗難、強盗、そして一般の救助要請を一つの三桁番号に集めた。1996年の漳州での会議の後、110番は全国の都市に広がり、「通報」から「救助」へと受け付ける範囲を広げた。三十年余りの後、この番号が記念日の日付に選ばれた理由はごく単純である。番号が始まった日であり、最も広く知られている番号だからである。

## テーマ

このスキンは深い青を地に、銀灰色を線に使う。右上には八角の徽章が輪郭だけで置かれ、左側には斜めに走る規制線が二本、画面を横切る。八角形は警察の徽章の外側の形を取り、規制線は現場に張られる境界線を取っている。人物も装備も描かず、「標識」と「境界線」の二つだけを残している。そこにこの日の二つの意味がある。一つの隊伍の身分と、それが保つ秩序である。
