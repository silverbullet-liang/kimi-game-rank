# 除夕

## 概要

旧暦の一年の最後の日。旧暦の月には大の月と小の月があるため、12月30日のこともあれば29日のこともあり、民間ではまとめて「大年三十」と呼ぶ。翌朝に始まる春節と端と端でつながり、一年でもっとも儀礼の密集した一夜である。年夜飯（除夕の団らんの食事）、春聯貼り、守歳（夜更かしして年を越すこと）、圧歳銭（子どもへのお年玉）は、いずれもこの夜に行われる。

## 由来

「除夕」という名は、西晋の周処『風土記』に見えるのが通説で、除夕に「旦まで眠らず、これを守歳と謂う」と記されている。少なくとも晋の時代には、年末に夜を明かす習わしが定着していたことになる。「除」は取り除く、入れ替わるという意味で、除夕とは旧年がこの夜で除かれ、明日にはまた新しい一年に替わることを指す。南朝梁の宗懍『荊楚歳時記』にも、年末に家ごとに料理を用意し、集まって新年を迎えた様子が記されている。除夕の作法の多くは「迎える」という一点をめぐっている。旧年を送り出し、新年を戸口から招き入れる。だからこの夜は灯りを消さず、誰かが起きていなければならず、食べ物を残しておくのである。

## 習わし

1. **年夜飯**：一家が一つの卓を囲み、料理は余るほど用意する。魚は頭と尾を残すことが多く、「年年有余」の縁起を取る。北方では餃子を包み、その形が元宝（銀塊）に似ることから、子の刻（零時前後）に食べる。
2. **春聯と福の字**：門の枠に対聯を貼り、扉には門神と「福」の字を貼る。「福」の字は逆さまに貼ることが多く、「倒れる（到）」と「至る」の音が通じることから「福到」の意を取る。
3. **守歳**：灯りを絶やさず、一家で話をし、番組を見、トランプなどをして零時まで起きている。年長者は子どもに圧歳銭を渡す。
4. **祖先祭祀**：食事の前に供え物を並べ、線香を立て、紙銭を焼いて祖先を家に招く。空の茶碗と箸を一組置く地方もある。
5. **爆竹**：古くは邪気を払い新年を迎えるために鳴らした。近年は多くの都市が禁止区域や時間制限を設け、作法もそれに合わせて変わってきた。

## 物語

除夕について最も広く語られるのは「年」という獣の伝説である。むかし「年」という名の怪物が、年の最後の夜に現れて人を害したが、赤い色、火の光、大きな音を恐れたという。そこで人々は戸に赤い紙を貼り、灯りをともし、竹を焼いて音を立て、一晩中眠らずに見張った。夜が明けても「年」は現れず、人々は互いに祝い合った。この話に確かな典籍の出典はなく、口承によるものである。しかし除夕の三つの要素、すなわち赤、火、眠らないことを一つの筋で説明してしまうため、最も広く伝わった。

## テーマ

このスキンは文字盤を一つ描き、針を目盛りの終わりまで進め、その横に「福」の字を一枚置く。文字盤の刻みはこの一年のすべてであり、針は最後の一区画で止まっている。福の字はその横に貼られ、次の一区画のために用意されている。除夕とは、その二つが同時に成り立つ一瞬である。古い時間は使い切られ、新しい祝福はもう戸口に貼られている。
