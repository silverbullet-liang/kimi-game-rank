# 中元節

## 概要

旧暦七月十五日は中元節である。道教では中元、仏教では盂蘭盆会（うらぼんえ）、民間では七月半とも呼ぶ。祖先を祭り、亡者を追悼することを主な内容とし、旧暦の大晦日、清明、重陽とならぶ祭祀の日である。日本、朝鮮半島、ベトナムにも同じ源流の習わしがあり、名称も日付もそれぞれに異なる。日本では同じ語が、お盆の時期を指し、また贈答の習慣である「お中元」を指す。

## 由来

中元の名は道教の三官の信仰に由来する。一月十五日を上元、七月十五日を中元、十月十五日を下元とし、それぞれ天官、地官、水官に対応させる。道教では中元の日に地官が罪を赦すとされ、この日に斎醮を設けて亡者を弔った。仏教側の説は『盂蘭盆経』による。経のなかで目連は、盂蘭盆に僧へ供養して亡母を救ったとされる。南北朝の歳時記にはすでに七月十五日の盂蘭盆供と墓参が記され、梁の宗懍『荊楚歳時記』はこの日「僧尼道俗、悉く盆を営みて諸仏に供す」と記す。唐宋以降、道教、仏教、民間の習俗が混じり合い、現在の姿になった。

## 習わし

1. **祖先の祭祀**：家に供え物の机を設け、香を焚き、紙銭を焼き、長幼の順に礼をする。
2. **灯籠流し**：紙や木の台に蝋燭を立て、川や湖に浮かべて流れに任せる。
3. **盂蘭盆の供養**：寺で法会が開かれ、読経と施食が行われる。参拝者は盆に供物を入れて寺へ運ぶ。
4. **普度**：街路に小屋を掛け、孤魂のための棚や高い灯篭を立てて施しを行う地方がある。
5. **施餓鬼**：道観や寺に壇を設け、縁のない亡者のために夜まで読経する。

## 物語

もっとも広く伝わるのは『盂蘭盆経』の一節である。伝えるところによれば、釈迦の弟子目連は神通力によって、亡母が餓鬼の道に落ちて飲食を得られないのを見、救う方法を仏に尋ねた。仏は、七月十五日は僧たちの安居が終わる日であるから、百味の飲食を盂蘭盆に入れて十方の僧に供養すれば、その力によって母は苦しみを離れられると告げた。目連は教えのとおりに行い、母は救われた。この経は中国に広く流布し、盂蘭盆会の由来はここに求められることが多い。道教側には地官が罪を赦すという説があり、二つの説は長く並び立ってきた。民間では細かく区別されず、供物も儀礼も互いに借り合っている。

## テーマ

このスキンにあるのは河灯が一つだけである。水面の灯、その下の柔らかな光の輪、三筋の波紋。すべて光の暈で作り、描線は使わない。灯は画面で唯一明るい場所であり、光は灯の底から外へ広がって遠いほど淡くなる。波紋はさらに淡い三本の弧で、外へ行くほど緩んでいる。岸も月も人もなく、ページの下端には縁のない暗い水が残る。
