# 元旦

## 概要

1月1日。グレゴリオ暦の年の最初の日で、多くの国で祝日とされている。中国では1月1日の「元旦」と、旧暦1月1日の「春節」は別の祝日として扱われる。中国の法定休日であり、1日が休みとなる。日本語の「元旦」は本来、元日の朝を指す語で、中国語の「元旦」が一日全体を指すのとは少しずれる。

## 由来

古典中国語の「元旦」は旧暦1月1日を指した。「元」は始まり、「旦」は日の出を表し、一年の最初の朝という意味になる。1912年、中華民国はグレゴリオ暦を採用し、1月1日を「新年」と呼んだ。1949年9月27日、中国人民政治協商会議第一回全体会議は、中華人民共和国が西暦すなわちグレゴリオ暦を用いることを決め、1月1日を「元旦」と正式に定め、旧暦1月1日は「春節」と呼ぶことになった。以来、「元旦」は太陽暦の新年を指す語となり、旧暦の新年は春節という名で呼ばれている。

## 習わし

1. **カウントダウン**：12月31日の夜から零時まで起きていて、鐘の音や花火を待ち、最後の数秒を数えて新年を迎える。
2. **暦を新しくする**：壁掛け暦、卓上暦、手帳をこの時期に新調し、最初のページにその年の予定を書き込む人も多い。
3. **家族で食事**：北方の一部では餃子、南方の一部では年糕（もち米の蒸し菓子）や湯円を食べ、「年年高」「団円」の縁起を取る。
4. **挨拶とカード**：親戚や友人に年始の挨拶を送る。この十余年で、携帯のメッセージや短い動画が紙の年賀状の多くを置き換えた。
5. **公共の催し**：多くの都市でマラソン、登高、国旗掲揚、コンサートなどが開かれ、休みは近距離の旅行と組み合わされることも多い。

## 物語

1月1日そのものに中国の伝説はなく、この日をめぐるのは暦そのものの物語である。グレゴリオ暦の前身はローマ暦で、英語などの January は、門と通路、そしてすべての始まりをつかさどるローマの神ヤヌス（Janus）に由来する。ヤヌスは前後二つの顔を持ち、一方で過去を振り返り、他方で未来を見る姿で描かれる。ローマの人々は年の初めにヤヌスへ供え物をし、新しい年の無事を願った。この二つの顔は、後に「新年」という時間の性格を表す西欧のイメージとなった。

## テーマ

このスキンは、地平線に沿って走る一本の細い線と、その上に数本の短い目盛りを置き、線の向こうからごく淡い朝の光がにじみ出るように描いている。画面には名のつくものが何もない。それこそがこの日の意味である。古い年はちょうど終わり、新しい年はまだ起きていない。ただ時間だけが、もう一度測り直されたところである。
