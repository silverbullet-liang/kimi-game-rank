# 記者節

## 概要

11月8日は中国の記者節である。2000年8月1日、国務院は中華全国新聞工作者協会の「『記者節』の具体的な日付の確定に関する請示」を承認し、11月8日を記者節とすることが決まった。同年11月8日が最初の記者節である。記者節は看護師の日、教師の日と並び、中国でただ三つしかない業種の記念日であり、国務院の定めにより休日ではない。

## 由来

日付は中国記協の前身に由来する。1937年11月8日の夜、范長江ら24人の呼びかけで中国青年新聞記者協会が上海の山西南路200号、南京飯店で成立した。上海陥落後に武漢へ移り、1938年3月30日に漢口で第1回全国代表大会を開き、のちに中国青年新聞記者学会と改称した。1957年に中華全国新聞工作者協会が成立し、1987年、中国記協はその源流が1937年11月8日にさかのぼるとの結論を出した。1949年12月23日に政務院が公布した「全国年節及び記念日休暇弁法」にはすでに記者節が挙げられていたが、日付は定まっていなかった。1999年9月18日改正の弁法に再び挙げられ、2000年1月25日に中国記協が国務院へ請示を提出し、8月1日に承認された。それ以前、1933年から1949年まで、新聞界は9月1日を記者節としていた。1934年の杭州記者公会の通電によるものである。

## 習わし

1. **業界の表彰**：中国新聞賞、長江韜奮賞がこの日の前後に発表または授与される。
2. **座談と研究**：記協と各報道機関が座談会、業務研究会、経験交流を行う。
3. **現場へ出る**：多くの媒体がこの日を会議室ではなく取材の現場に充てる。
4. **公開日と展示**：新聞社、放送局、テレビ局が一般公開され、同じ時期に報道写真展が開かれる。
5. **自己点検**：業界誌はこの日に取材倫理、事実確認、報道の限界について論じることが多い。

## 物語

1937年7月、日中戦争が全面化した。同月中旬、上海で中国共産党中央を代表して南方の活動を指導していた周恩来が、胡愈之や夏衍らに、愛国の新聞工作者を広く結集し統一戦線の組織をつくる考えを伝えた。11月4日、范長江が胡愈之、夏衍、惲逸群らと会し、組織の設立を決めた。11月8日午後7時、成立大会が上海の南京飯店で開かれ、幹事数名が選ばれ、機関誌『新聞記者』の発行が決まった。以後、同会は全国に40余りの分会を置き、会員は最盛期に2000人を超えた。2010年、成立の場所である上海南京飯店は文物保護単位に指定された。

## テーマ

このスキンは紙の白に鉛の黒を合わせる。両側にごく淡い段組みの罫線が三本ずつ走り、紙面を段に分ける。右上には手描きの朱の丸があり、一周するが閉じず、切れ目を残す。右下にはペンの先が一つ、切っ先を上に向けている。赤はそこにしかなく、それは朱批の色であって祝いの色ではない。
