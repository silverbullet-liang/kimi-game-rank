# 清明節

## 概要

清明節はグレゴリオ暦の4月4日から6日のあいだに訪れ、2026年は4月5日である。二十四節気の一つであると同時に伝統的な祭日でもあり、その二つが同じ日に重なる。二十四節気のうち、清明だけが祭日でもある。2006年5月20日、国務院の認可を経て第一次国家級無形文化遺産に登録され、2008年からは国家の法定休日となっている。

## 由来

節気としては、清明は太陽が黄経15度に達する時刻にあたり、通常は4月4日から6日のあいだに現れるため、年ごとに日付と時刻がわずかに異なる。『月令七十二候集解』はその名を「物、此の時に至りて、皆な以て潔斉にして清明なり」と説く。祭日としては、現在の清明節は清明節気、寒食節、上巳節の三つが融合した結果である。寒食は漢の時代すでに火を禁じて冷たいものを食べる習わしがあり、唐の時代に祖先の墓を掃く風習が形づくられた。寒食と清明は一、二日しか離れていないため、唐代宗の大暦十二年（777年）に「今より以後、寒食は清明と同じ」との詔が出され、二つの節の統合が公式文書で確認された。宋の時代に上巳は姿を消し、三つの節が一つになった。

## 習わし

1. **墓参りと祖先祭祀**：墓の手入れをし、草を除いて土を盛り、供え物を並べて線香を立て、紙銭を焼くか花を供える。家族そろって出かける、この日のもっとも主要な行事である。
2. **春の散策**：清明の前後は草木がいちばん勢いよく伸びる。墓参りのあと、そのまま郊外を歩き、花を見、凧を上げる。哀しみと楽しみが同じ日に並び立つ。
3. **柳を挿し柳を戴く**：柳の枝を折って門の鴨居に挿し、あるいは編んで頭に戴く。「清明に柳を戴かねば、紅顔も皓首となる」ということわざがある。
4. **青団を食べる**：江南一带ではヨモギや草の汁を餅米粉に練り込み、小豆餡を包んで蒸す。色は青く、香りはさわやかである。山西の一部では小麦粉で燕の形の「子推燕」を作る。
5. **凧上げとぶらんこ**：古い習わしでは凧に病の名を書き、高く上げてから糸を切って飛ばし、厄を手放す意を取った。

## 物語

寒食の火禁の由来として最も広く流布するのは、介子推にまつわる話である。春秋時代、晋の公子重耳は十九年間国外を流浪し、従った介子推は自分の腿の肉を切り取って彼の飢えをしのいだという。重耳が帰国して晋の文公となったのち、介子推は褒賞を求めず、母を連れて綿山に隠れた。文公は山に火を放って彼を出そうとしたが、介子推は木を抱いたまま死んだ。悔いた文公はその日に火を禁じ、冷たいものだけを食べるよう命じ、寒食の習わしが始まったとされる。この話は後世の記述に見えるもので、時代も遠く、具体的な事情は確かめにくい。しかし火を禁じ、冷食し、墓に参るという三つが清明の前後に一つになったことは確かである。

## テーマ

このスキンは灰緑を地にし、右上に一株の枝垂れ柳を置き、斜めの細雨がゆっくり降る。柳は垂れ、雨は斜めで、どちらも上を見ない。だから画面は静かに見える。清明が語る二つのことは、ここにそろっている。育つ部分（柳はもう葉を出している）と、失われる部分（雨は降りやまない）が、同じ季節のなかにある。
