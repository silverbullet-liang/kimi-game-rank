# 北方の小年

## 概要

旧暦12月23日。祭竈節、竈王節、あるいは単に「小年」ともいう。中国の北方の大部分はこの日を小年とし、南方の大部分は12月24日を小年とする。「小」は祭りが小さいという意味ではなく、この日から正月の準備に入るという意味である。その先に、はるかに大きな除夕（大晦日）と春節が控えている。

## 由来

竈（かまど）の神を祀る習わしは非常に古い。「礼記」の祭法に記される七祀のなかに「竈」があり、「論語」にも「其れ奥に媚びんよりは、寧ろ竈に媚びよ」ということばがある。竈の神は先秦の時代すでに祀られていたことになる。祭竈が12月24日から23日へ早まった理由については、次のような説明が広く行われている。清の宮廷が12月23日に祭竈を行い、王公や京官がこれに倣い、北方の民間もまたこの日に移ったというもので、南方は旧来の日を残した。民間にはもともと「官は三、民は四、船家は五」ということばがあり、役人は23日、庶民は24日、水上生活者は25日という違いを語っている。

## 習わし

1. **祭竈**：竈の前に糖瓜（麦芽糖の菓子）、関東糖、清水と飼い葉を供える。糖は粘っこく甘いものが選ばれ、竈王が「天に上りて好事を言う」ことを願う。
2. **塵払い**：天井を掃き、窓を拭き、寝具を洗う。一年に積もった埃を一度に落とし、旧を除き新を迎える意を取る。
3. **切り紙の窓花を貼る**：赤い紙を鳥や花、人物、「福」の字に切り抜き、拭き清めた窓の格子に貼る。北方の冬でもっとも目を引く赤である。
4. **入浴と理髪**：「金があってもなくても、髪を切って年を越す」ということわざがあり、この日前後には大人も子どもも髪を切り、風呂に入る。
5. **正月用品と蒸し菓子の用意**：飴、爆竹、対聯を買い、饅頭、棗糕、粘豆包を蒸して庭で凍らせ、正月の一か月分とする。

## 物語

竈王の伝説は民間で最も広く語られる。竈王は一年中かまどのそばに住み、その家の飲食と暮らしを見、善悪を書き留めているという。12月23日の夜になると、彼は天に上って玉皇大帝に一年のことを報告する。人々は悪く言われるのを恐れ、粘っこく甘い糖瓜を供えて口を塞ぎ、あるいは口を甘くしようとする。祀り終えると古い神像を剥がして焼き、除夕に新しい像を貼る。これを「送竈」「接竈」という。この話には特定の典籍の出典がないが、南北の竈の前で幾百年も語り継がれてきた。

## テーマ

このスキンは八角形の切り紙の窓を一つと、その横に糖瓜を一つ描く。格子の中の切り込みは赤い線で、糖瓜は淡い金色、二つが並んで深紅の地の上に置かれている。切り紙は人に見せるためのもので、糖瓜は神に食べてもらうためのものだ。小年の日には、人の世の賑わいと竈の供え物が同じ画面に並ぶ。
