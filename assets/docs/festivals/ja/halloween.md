# ハロウィン

## 概要

10月31日の夜、諸聖人の日（11月1日）の前夜にあたる。英語の Halloween は All Hallows' Eve の短縮形で、hallow は聖人を意味する。この夜はアメリカ、ブリテン諸島、カナダ、オーストラリア、ニュージーランドなどで広く行われている。このスキンは表示期間のあいだ、暗色に固定される。

## 由来

起源は一般にケルト人のサウィン祭（Samhain）に遡る。ケルト人は11月1日を一年の始まりとし、その前夜は生者と死者の境が薄くなるとされた。人々は焚き火をたき、獣の皮や仮面を身につけて、さまよう霊を遠ざけようとした。8世紀、教会が諸聖人の日を11月1日に定めたことで、その前夜は「諸聖人の前夜」となり、名もそこから生まれた。中世のブリテンとアイルランドには「ソウリング」と呼ばれる習わしがあり、家々を訪ねて「魂の菓子」をもらい、死者のための祈りを返した。仮面をつけて家々を回り芸をする「ガイジング」もあった。19世紀、とくに1840年代のアイルランド大飢饉ののち、多くのアイルランド移民がこの夜を北米へ運び、そこでは地域ぐるみの祭りへと変わっていった。1930年代には「トリック・オア・トリート」という言い方がアメリカで定着している。

## 習わし

1. **仮装**：幽霊やキャラクターに扮する。玄関には菓子の入った器が置かれる。
2. **菓子をもらい歩く**：子どもが戸を叩いて「トリック・オア・トリート」と言い、家の者が菓子を渡す。双方が同じ言葉に従う。
3. **ジャック・オー・ランタン**：南瓜をくり抜いて顔を刻み、中に灯を入れて戸口に置く。
4. **アップル・ボビング**：水盆に浮かべた林檎を手を使わずに取る。古い占い遊びの名残である。
5. **お化け屋敷と怪談**：仮設のお化け屋敷、仮装舞踏会、夜更けまでの怪奇映画。

## 物語

南瓜の灯の由来は、アイルランドの「けちんぼのジャック」と呼ばれた男の話に関わる。伝えられるところでは、彼は二度にわたって悪魔をだましたため、死後は天国にも地獄にも入れず、くり抜いた蕪に炭火を入れて持ち、世をさまようことになったという。人々はこれを Jack of the Lantern と呼んだ。アイルランドでは初め蕪やビートを刻んで灯を作り、北米へ渡った移民がより多く、刻みやすい南瓜に変えた。この話はアイルランドの口承に伝わるもので、成立の年代はもはや定めがたい。しかし灯と、どちらにも受け入れられない者とを結びつけている。

## テーマ

このスキンは暗い地の上に橙と紫を対置する。橙は一か所に集まり、紫は隅へ散る。蝙蝠、枯れ枝、アーチといった影絵の飾りは、形だけを見せて細部を描かない。表示期間のあいだは暗色に固定されるため、昼に開いても画面は同じ低い明るさに抑えられている。
