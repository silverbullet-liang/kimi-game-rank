# 寒衣節

## 概要

旧暦十月一日。十月朝、祭祖節、授衣節とも呼ばれる。民間ではこの日は清明・中元と並び、一年のうち先祖を祭る日の一つとされる。北方ではこの時期に墓参りをし、亡くなった縁者に紙の衣を焼いて贈る。これを「寒衣を送る」という。旧暦十月は冬の始まりでもあり、以後は寒さが増していく。

## 由来

「授衣」の考えは古い。『詩経・豳風・七月』に「七月流火、九月授衣」とあり、九月になって暑さが去り、冬支度をすべき時であることを述べている。唐の玄宗、天宝二年（743年）、朝廷は制を下し、毎年九月一日に陵寝へ衣を薦めることを命じた。これは『唐大詔令集』巻七十七に見え、新調の冬衣を先祖に供えるもので、民間が墓に衣を捧げる習わしにも影響した。十月になって初めて冬に入るため九月では早すぎ、宋の時代にこの習わしは十月朔日へ移された。孟元老『東京夢華録』は汴京の九月下旬について「すなわち冥衣、靴鞋、席帽、衣段を売る。十月朔日に焼献するが故なり」と記し、十月一日には「士庶みな城を出でて墳に饗す」とある。周密『武林旧事』は臨安について「十月朔、都人は郊に出でて墓を拝し、綿裘楮衣の類を用う」と記す。元の『析津志』には「送寒衣節」の名がすでに見える。明の『帝京景物略』はもっとも詳しく、十月一日、紙屋が五色の紙を裁って男女の衣を作り、長さ一尺余り、姓名と輩行を記して書状のようにし、家ごとに夜、門前で呼びかけて焼いたと記す。

## 習わし

1. **寒衣を送る**：五色の紙を衣の形に切り、紙袋に納めて亡者の名を書き、墓前または門前で焼く。
2. **墓参り**：墳を整え、供え物を並べ、紙銭を焼く。清明に似て、より簡素である。
3. **衣を授ける**：家の年長者に冬衣や布団を用意する。この層は今も行われている。
4. **炉を開く**：旧時はこの日に火を入れて暖を取った。北方では「開炉」と呼び、冬入りの印とした。
5. **新穀を供える**：北方の一部では新収の黍や餃子を先祖に供え、秋の実りを先に薦める意を表す。

## 物語

この日にもっとも広く結びつくのは孟姜女の伝説である。伝えられるところでは、夫は長城の普請に徴発されて音信が絶え、彼女は冬衣を縫って千里を尋ねたが、着いたときには夫はすでに死に、遺骨は城壁に築き込まれていた。彼女が城の下で声を上げて泣くと、城壁が崩れたという。この話は早い文献では「杞梁の妻」の簡略な記事としてしか見えず、のちに戯曲や語り物のなかで育ち、細部は時代ごとに異なる。起源はもはや定めがたい。民間はこれを十月一日の寒衣送りと結びつけたが、双方の言わんとするところは同じである。寒くなったので、衣を届けなければならない。

## テーマ

このスキンは霜の色でできている。冷たい月が一つ、霜の粒が六つ、ごくゆっくり落ちる。右下には畳まれた寒衣の影が一つ、四角く整っている。画面に暖色はなく、祝祭的な動きもない。動きは落ちるという一つだけである。
