# 国際博物館の日

## 概要

毎年五月十八日。一九七七年に国際博物館会議（ICOM）が定めた。この日、世界各地の博物館が年度のテーマに沿って展覧会、無料開放、講演、市民向けの催しを行い、博物館の仕事をより多くの人に知ってもらう機会としている。

## 由来

一九四六年、ICOM はパリで設立された。一九七七年、モスクワで開かれた第十一回大会で、五月十八日を第一回国際博物館の日と宣言し、毎年テーマを定めることが決められた。中国博物館協会は一九八三年に ICOM に加入し、以後毎年関連の行事を行っている。近年のテーマは博物館の社会的な役割に関わるものが多い。

## 習わし

1. **無料開放**：多くの博物館がこの日を無料にし、開館時間を延ばす。
2. **テーマ展示**：ICOM が発表する年度テーマに沿って特別展が組まれる。
3. **夜間開館**：博物館の夜として、照明、ガイドツアー、上演が同時に行われる。
4. **講演とワークショップ**：修復の実演、拓本、陶芸、親子向けの解説ツアー。
5. **学校との連携**：学校が団体で見学し、学芸員が学校に出向いて授業を行う。

## 物語

一九四六年十一月、ICOM はパリで設立され、定款は博物館を「社会とその発展に奉仕する非営利の常設機関」と定め、人間とその環境の証となるものを収集し、保存し、研究し、伝達し、展示することを役割とした。この定義は数度にわたり改められながら、各国の博物館に共通する仕事の範囲となっている。一九七七年のモスクワ大会で、博物館と市民の距離を少し縮めるために国際的な日を設けることが決まり、五月十八日が選ばれた。

## テーマ

ガラスの展示ケースが一つ、前面に斜めの反射が走り、中には文様のない素焼きの壺が置かれている。反射がケースを二つに分け、半分は透明で、半分はただの光である。壺はその光の帯の下にあり、輪郭ははっきりしているが、細部はガラスに遮られている。展示を見るときの経験もこれに近い。まず自分の姿が見え、そのあとに器物が見えてくる。
