# 元宵節

## 概要

旧暦1月15日。上元節、灯節、小正月とも呼ばれる。旧暦の一年で最初の満月の夜であり、春節の習わしの締めくくりでもある。灯籠が掛かれば、正月は終わりである。道教は1月15日、7月15日、10月15日を合わせて「三元」と呼び、1月15日を上元とした。上元節という別名はそこから来ている。

## 由来

1月15日に灯をともす由来については、仏教に関わる説が広く行われている。漢の明帝が仏への敬意を示すため、1月15日の夜に宮中と寺院で灯をともすよう命じ、以後それが習わしになったという。この話は後世の記録に見えるもので、具体的な事情は確かめにくい。確認できるのは、南朝梁の宗懍『荊楚歳時記』がすでに1月15日に「豆糜を作り、油膏を其上に加え」て戸口を祀ったと記していることである。南北朝のころには、この夜に定まった作法があったことになる。唐の長安では灯の催しが盛んで、蘇味道の「正月十五夜」に「火樹銀花合す」の句が残る。宋の時代には灯を掲げる期間が五夜、六夜と延び、灯に謎を貼るようになり、これが灯謎の始まりとなった。明・清には灯市が都市のなかの定まった場所となった。

## 習わし

1. **灯籠を鑑賞する**：灯籠を作り、掛け、眺める。宮灯、走馬灯、龍灯にはそれぞれ作り方があり、各地の公園や街路で灯会が開かれる。
2. **灯謎を当てる**：謎を紙片に書いて灯の下に貼り、当てた人がそれを剥がして景品を受け取る。謎の形式や分類には独自の決まりがある。
3. **元宵あるいは湯円を食べる**：北方では餡を乾いた粉の中で転がして丸める「元宵」、南方ではもち米の皮で餡を包んで丸める「湯円」。餡は胡麻、小豆、落花生が多い。
4. **龍舞・獅子舞と街の練り歩き**：龍灯、獅子隊、竹馬、旱船（陸上の船の踊り）、秧歌が街に出る。一年で最後の大規模な街の賑わいである。
5. **百病を歩き払う**：北方の旧習で、女性たちが1月15日と16日の夜に連れ立って外に出て橋を渡り、城壁を歩き、病を払うというもの。

## 物語

比較的広く語られる話に、漢の武帝の臣、東方朔にまつわるものがある。宮中の女官、元宵が家族を恋しがって井戸に身を投げようとしたとき、東方朔は彼女を助けようと考えた。まず長安の街に占いの店を出して「1月15日に火が身を焼く」という予言を広め、次に武帝に、火の神は湯円を好むので、その夜は町中に赤い灯を掛け、花火を上げ、家ごとに湯円を煮れば、灯の明るさが火災に代わると進言した。武帝はこれを許し、長安は灯で明るく照らされ、元宵の両親も灯を見に町へ入り、一家は再会することができた。この話は後世の雑記と民間の語りに見えるもので、正史には見えない。

## テーマ

このスキンは湯円の一碗を描き、その上に大きさの異なる三盏の灯籠を浮かべる。椀は近く、低く、静止している。灯は遠く、高く、光っている。白い一碗と三つの暖かな光のあいだには大きな空白が残されている。元宵節の二つのものが、こうして同じ画面に並ぶ。食べるための一碗と、街全体を照らす幾盏かの灯である。
