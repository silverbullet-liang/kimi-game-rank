# 1024 プログラマの日

## 概要

10月24日は中国で広く用いられるプログラマの日である。1024は2の10乗であり、記憶容量の換算の基数でもある。1KBは1024バイト、1MBは1024KB。日付を10/24と書けば1024と同じ形になるため、この日が選ばれた。法定の休日ではなく、技術コミュニティと従事者のあいだで自然に定まったもので、会社ごと、コミュニティごとに独自に企画される。

## 由来

国際的に定着しているプログラマの日はロシアに由来する。2002年、プログラマのヴァレンティン・バルトが署名を集めて政府に請願し、2009年9月11日に当時のメドベージェフ大統領が法案に署名して、年の256日目をプログラマの日とした。平年は9月13日、閏年は9月12日である。256は1バイトが表せる数であるため、この日付は閏年に動く。中国は別の算法を選んだ。2010年前後、ブログ園やCSDNなどの技術コミュニティが「10月24日を中国のプログラマの日とする」討論と投票をネット上で行い、2015年前後には研修機関やインターネット企業が追随して、業界の定まった日となった。2020年からは長沙で毎年「中国1024プログラマの日」が開かれ、フォーラムや展示が行われる。

## 習わし

1. **社内イベント**：技術分享、社内コンテスト、記念品の配布。年に一度の技術開放日とする企業もある。
2. **フォーラムと開発者会議**：リリースがこの日前後に集中し、オープンソース倉庫へのコミットも増える。
3. **残業しないという提言**：一部の組織はこの日に定時退社を呼びかける。この提言のほうが祭日そのものより記憶されやすい。
4. **技術的な動作で祝う**：一行書く、コミットを一回する、古いバグを一つ潰す。
5. **数字の洒落**：1024、そして1G=1024Mを「一流」の音に掛ける言い方。

## 物語

一般に最初のプログラマと呼ばれるのはエイダ・ラヴレスである。1843年、彼女がバベッジの解析機関に関する論文に付した注記のなかで、ベルヌーイ数を計算する手順が示され、これは最古の算法の記述の一つとされる。同じ注記のなかで彼女は、機械が作曲できるかという問いも立てている。機械が実際に曲を作るより百年以上前のことである。この日とのつながりは、プログラマの祭日を辿っていくと、ついに作られることのなかった機械について書いた一人の女性の注記に行き着くという点にある。
