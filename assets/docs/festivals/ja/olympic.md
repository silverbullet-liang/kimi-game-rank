# 国際オリンピックデー

## 概要

六月二十三日は国際オリンピックデー、別名オリンピックデー、スポーツの日である。国際オリンピック委員会（IOC）が一九四八年にこの日を定め、近代オリンピックの出発点を記念するとともに、性別、年齢、競技水準を問わず多くの人がスポーツに親しむことを呼びかけてきた。各国の国内オリンピック委員会の行事は、六月十七日から二十四日のあいだに置かれることが多い。

## 由来

一八九四年六月二十三日、十二か国の代表がパリのソルボンヌに集まり、クーベルタンによるオリンピック復興の提案を満場一致で可決した。国際オリンピック委員会は同じ日に設立され、近代オリンピックはここから始まる。一九四七年、チェコスロバキア出身のIOC委員ヨセフ・グルスがストックホルムでの第四十一回総会で世界オリンピックデーの構想を提出し、一九四八年一月のサンモリッツでの第四十二回総会がこれを採択した。同年六月二十三日に最初のオリンピックデーが行われ、ポルトガル、ギリシャ、オーストリア、カナダ、スイス、イギリス、ウルグアイ、ベネズエラ、ベルギーが参加した。

## 習わし

1. **長距離走**：もっとも一般的な形。一九八七年からIOCが回次を重ねてオリンピックデー・ランを主催し、中国オリンピック委員会も一九八七年以降、毎年六月二十三日の前後にこれを開いている。
2. **公開練習と体験教室**：各地の競技団体が一般向けの教室を開き、普段は触れない種目を試せるようにする。
3. **スポーツと文化の展示**：オリンピックの歴史展示、写真展、講演、教育セミナー。
4. **選手との合同練習**：現役や引退した選手が集団運動を指導する。近年はオンラインと併用されることが多い。
5. **学校と地域の催し**：学校の運動会、ウォーキング、サイクリング、球技大会など。

## 物語

最初のオリンピックデーである一九四八年六月二十三日、参加した国内委員会は九つだった。その後四十年あまり、この日は各国の裁量に委ねられていた。一九八七年、IOCは回次を定めてオリンピックデー・ランを推進し始め、第一回には四十五の国内委員会が加わった。中国オリンピック委員会も同年に参加し、このランをオリンピック運動の普及の場としてきた。二〇一三年の第二十七回には、中国の二十三都市が同じ日に一斉にスタートしている。二〇一五年に北京と張家口が二〇二二年冬季大会の開催権を得てからは、冬季種目の比重が年々高まっている。

## テーマ

このスキンは五つの輪を輪郭だけで描く。塗りはなく、互いに組み合っている。青、黄、黒、緑、赤を細い線で表し、交わるところは抜いたままにして、どの輪も他の輪を覆わない。塗れば順序と主従が生まれるが、線だけなら五つは同じ重さで並ぶ。この日の「誰でも参加できる」という趣旨はそこにある。背景は低く沈め、線だけを浮かせている。
