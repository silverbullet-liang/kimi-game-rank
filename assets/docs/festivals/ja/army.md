# 建軍節

## 概要

八月一日は中国人民解放軍の建軍記念日である。一九二七年八月一日に南昌蜂起が起こり、のちにこの日が中国人民解放軍の建軍記念日とされた。法定の休日ではなく、部隊はこの日に旗を掲げ、宣誓を行い、営区を開放し、軍史の教育を行う。地方も同じ時期に、軍人家族や退役軍人への支援活動を進める。

## 由来

一九二七年八月一日、中国共産党は江西省南昌で武装蜂起を起こし、部隊はその後南下した。一九三三年七月十一日、中華ソビエト共和国臨時中央政府は八月一日を中国工農紅軍の成立記念日とすることを決定する。一九四九年以降、八月一日は中国人民解放軍建軍節として広く呼ばれるようになった。同じ年、中国人民革命軍事委員会は、軍旗と軍章の標章に「八一」の二文字を用いるよう命じ、日付と標章がここで結びついた。

## 習わし

1. **国旗と軍旗の掲揚**：八月一日、営区で掲揚式が行われ、将兵は軍人の誓いを復唱する。
2. **観閲と営区公開**：観閲式が行われる年もある。通常は営区の公開日や装備の展示で一般を受け入れる。
3. **軍人家族への支援**：節の前に、地方が在役軍人の家族、戦没者の遺族、退役軍人を訪ね、優遇措置を実行する。
4. **軍史教育**：軍史館や革命の旧址を見学し、伝統に関する講義を受ける。
5. **慰問と公演**：軍と地方の文芸団体が営区で公演し、慰問品が送られる。

## 物語

一九二七年八月一日の未明、南昌城内の銃声は予定より早く鳴った。蜂起は周恩来が前敵委員会の書記となり、賀龍、葉挺、朱德、劉伯承らが部隊を率いて参加した。二万余の兵力は数時間の戦闘で南昌城を掌握する。部隊はその後広東へ南下し、転戦のすえ、その一部は一九二八年に井岡山で毛沢東の率いる部隊と合流した。一九三三年の夏、中央は八月一日を紅軍成立の記念日と定め、同年八月一日に最初の記念行事が行われた。当日の夜の経過については複数の回想と文書があり、細部の記述には多少の違いがある。
