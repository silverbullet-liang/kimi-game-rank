# 端午節（たんごせつ）

## 概要

旧暦五月五日。端陽節、重午節、五月節、竜舟節、浴蘭節とも呼ばれる。端午は春節、清明、中秋と並ぶ中国の四大伝統節句の一つである。二〇〇六年五月、国務院が第一次国家級無形文化遺産リストに加え、二〇〇八年からは法定の祝日となり、二〇〇九年九月にはユネスコが中国の端午節を無形文化遺産代表一覧表に登録した。

## 由来

「端午」の語は西晋の周処『風土記』に見える。南朝梁の宗懍『荊楚歳時記』によれば、五月は仲夏で、その最初の午の日を端陽と呼ぶため、五月五日を端陽節ともいう。起源については三つの説が通っている。一つは長江下流域の古い越人の竜トーテム祭祀と竜舟競漕、二つは五月を「悪月」とみなし、薬草を採り、蘭湯に浴し、艾を門に挿して病を避けたこと、三つは汨羅江に身を投じた屈原を記念する説で、民間で最も広く語られる。長い伝承のなかで三つは混ざり合い、現在の習わしになった。

## 習わし

1. **竜舟の競漕**：太鼓に合わせて櫂をそろえ、川や湖で速さを競う。
2. **粽を作る**：葦の葉で餅米を包み、棗や餡、塩漬けの肉を入れ、四角や三角錐に縛って煮る。
3. **艾と菖蒲**：戸口に挿し、香袋を身につけ、雄黄酒を飲む。
4. **五色の糸**：子どもの手首に結ぶ。古くは魔除けとされた。
5. **蘭湯と薬草採り**：蘭や艾を煮た湯で身を洗い、正午の前後に薬草を採る。

## 物語

『史記』屈原賈生列伝によれば、屈原は楚の大夫で、斉と結んで秦に対抗することを主張したが、讒言によって追放された。紀元前二七八年、秦軍が楚の都郢を陥れると、屈原は汨羅江に身を投げた。南朝梁の呉均『続斉諧記』には、楚の人々がこれを哀しみ、毎年この日に竹筒に米を入れて水に投げて祭ったところ、のちに屈原が姿を現し、供え物はしばしば蛟竜に奪われるので、楝の葉で口を塞ぎ五色の糸で縛れば蛟竜はこれを恐れると告げた、とある。葉で米を包み糸で縛る粽はここから生まれた。竜舟の競漕も、屈原を救おうと船を漕ぎ出したことに始まると伝える。

## テーマ

角の鋭い三角錐の粽が一つ、紐で縛られ、その下に三本の水紋が走る。葉の折り目は直線で、水紋は曲線である。硬いものと柔らかいものが向かい合い、この日の二つの半分をなしている。包んで縛る手仕事と、舟を押し流す川の水である。
