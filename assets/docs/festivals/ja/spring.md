# 春節

## 概要

旧暦1月1日。中国でもっとも重要な伝統的な祭りであり、東アジアおよび世界各地の華人社会でも行われる。このスキンの春節は1月1日から九日間続く。5日は「破五」、7日は「人日」、9日は閩台（福建・台湾）一帯で天公生（玉皇大帝の誕生日）とされる。2024年12月4日、「春節——中国人が伝統的な新年を祝う社会実践」はユネスコの無形文化遺産代表一覧表に登録された。その前年の2023年12月、第78回国連総会は旧暦の新年を国連の休日と決めている。

## 由来

旧暦の新年の源は、上古の歳首に行われた祭祀と豊作の祈りにある。漢の武帝のときに頒布された「太初暦」が1月を歳首と定め、以後二千年余りほぼそのまま受け継がれた。民国の初めにグレゴリオ暦へ改められると、1月1日は「元旦」と呼ばれ、旧暦1月1日が「春節」となった。春節は一日ではなく、ひと続きの期間である。12月の正月支度に始まり、除夕の守歳を経て、1月15日の元宵節で終わる。前後およそ一か月で、ユネスコへの申請もこの一連の社会実践を対象としていた。

## 習わし

1. **春聯・福の字・年画を貼る**：門の枠に赤い紙の対聯を貼り、扉に門神と福の字を貼り、室内の年画を新しくする。家の一面が赤くなる。
2. **年夜飯と正月の食べ物**：北方は餃子、南方は年糕、湯円、八宝飯。魚は頭と尾を残し、卓には必ず食べ残しが出る。
3. **年始の挨拶と圧歳銭**：元日の朝早く年長者に挨拶をし、年長者は子どもに圧歳銭を渡す。その後数日は親類や友人を訪ねる。
4. **廟会と龍獅舞**：城隍廟や公園で廟会が開かれ、龍舞、獅子舞、竹馬、灯謎が行われる。正月でもっとも賑やかな場所である。
5. **5日と7日**：5日の「破五」には爆竹を鳴らし、貧を送り、財神を迎える。7日の「人日」には七種類の菜の羹を食べる。9日は閩台一帯で天公を祀る。

## 物語

戸に赤い紙を貼る習わしの源の一つは桃符である。『荊楚歳時記』によれば、1月1日には戸に鶏の絵を貼り、葦の縄をかけ、そのそばに桃符を挿して百鬼を避けた。『山海経』の系統の伝説では、度朔山の大きな桃の木の下に神荼と鬱塁の二神がいて鬼どもを統率したとされ、桃の木は凶を防ぐものと考えられた。後世、桃の板は赤い紙に、神の名は対句の吉祥のことばに置き換えられ、桃符は春聯になった。春聯は今では文学に見えるが、はじめは戸口の守りだった。

## テーマ

このスキンは、かすかに揺れる二盏の灯籠、八角形の窓花一枚、そしてゆっくり落ちる四片の金色の屑を使っている。灯籠は動き、窓花は静止し、屑はその間を落ちていく。春節の色はほとんど赤一つだが、赤が輝くには金がいる。このスキンが描くのはその金である。灯籠の光、紙の縁、宙で止まった屑。
