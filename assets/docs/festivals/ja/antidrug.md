# 国際麻薬乱用・不正取引防止デー

## 概要

六月二十六日は国際麻薬乱用・不正取引防止デー、通称・世界麻薬デーである。国連総会が設けた国際日で、薬物の乱用と不正取引に対する行動と協力を促すことを目的とする。毎年、国連薬物犯罪事務所（UNODC）がテーマを掲げ、各国政府、地域社会、学校がこの前後に啓発活動を行う。

## 由来

一九八七年六月十二日から二十六日まで、国連はウィーンで麻薬乱用・不正取引に関する国際会議を開き、百三十八か国から代表が参加した。会議は国際デーの設置を勧告する。同年十二月七日、国連総会は決議四二／一一二を採択し、六月二十六日を「麻薬乱用・不正取引防止国際デー」と定めた。この日付はウィーン会議の閉幕日と重なる。一九九二年以降、毎年の活動にはテーマが添えられている。麻薬に関する最初の国際会議は一九〇九年に上海で開かれ、その後一九六一年、一九七一年、一九八八年に三つの薬物統制条約が採択された。

## 習わし

1. **テーマ広報**：UNODCが毎年テーマと『世界薬物報告』を公表し、各地の行事はこれを軸に組まれる。
2. **学校での教育**：講演、展示、学級活動で薬物乱用の健康被害を伝える。
3. **相談と治療の窓口**：治療施設が相談日を設け、治療、回復、家族支援への経路を案内する。
4. **押収品の公開と統計**：この日に押収量を公表したり、押収した薬物をまとめて廃棄したりする国もある。
5. **中国での啓発**：六月二十六日の前後、各級政府が新聞、放送、テレビ、ネットを通じて集中的に広報を行う。『中華人民共和国禁毒法』は二〇〇七年十二月に採択され、二〇〇八年六月一日に施行された。

## 物語

この日に関わる背景の一節。一九八七年、ウィーンの会場で議論されていたのは、越境取引の経路、前駆化学物質の流れ、依存者の治療が足りていない領域であった。会議は十五日間にわたり、まとめられた報告は、年に一日をこの問題の説明のために空けておくよう各国に求めた。半年後、決議はニューヨークで可決される。以後三十年あまり、この時期に公表される『世界薬物報告』は、世界の使用量、押収量、新たに現れた精神活性物質の数を毎年記録してきた。記念日のやり方は単純である。数字の束を公衆の前に置く、それだけのことだ。

## テーマ

このスキンが描くのは切れた鎖である。濃紺に銀、三つの完整な環のあとに、四つ目の環がずれて外れる。前三つはまだ繋がっており、最後の一つはほんの少し位置を違えただけで抜け、切れ目には余白が残る。火花も、砕けた欠片もない。鎖は束縛を意味し、同時に連続も意味する。外れた環は、この鎖が止まれる唯一の場所である。
