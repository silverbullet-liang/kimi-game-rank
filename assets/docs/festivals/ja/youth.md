# 青年節（五四青年節）

## 概要

毎年五月四日。中国の青年の日である。一九三九年、陝甘寧辺区西北青年救国連合会が五月四日を中国青年節と定め、一九四九年十二月二十三日、中央人民政府政務院がこれを正式に宣布した。現行の休日規定では、十四歳以上の青年はこの日に半日の休みとなる。

## 由来

この日は一九一九年の五四運動に始まる。同年一月にパリ講和会議が開かれ、中国側が山東の権益返還を求めたが受け入れられず、四月末に会議はドイツの山東における権益を日本に移すことを決めた。この報が国内に伝わると、五月四日に北京の学生が集会とデモを行い、各地で学生の同盟休校、商人の休業、労働者のストライキが続いて運動は全国に広がった。一九三九年、陝甘寧辺区西北青年救国連合会がこの伝統を受け継ぐために五月四日を青年節と定め、一九四九年十二月に政務院が正式に宣布した。

## 習わし

1. **入団式と成人式**：学校では新しい団員の宣誓や、十八歳を迎える成人の儀式が行われる。
2. **表彰と座談会**：五四青年賞章や優秀団員の選考、青年代表による座談会。
3. **ボランティア**：地域サービス、へき地の学校での教育支援、環境保護、科学普及の活動が集中して行われる。
4. **文化・体育の行事**：合唱、演説、長距離走、球技大会など、青春を題にした催しが多い。
5. **記念地の見学**：北京大学の紅楼や五四運動ゆかりの記念館を訪ねる。

## 物語

一九一九年五月四日の午後、北京の十余校の学生三千余人が天安門前に集まり、パリ講和会議の山東問題の処理に抗議して東交民巷方面へデモ行進した。行進の途中で趙家楼にある曹汝霖の邸宅が焼かれ、数十名の学生が逮捕された。報が伝わると天津、上海、広州などの学生が次々に同盟休校に入り、六月からは上海の労働者がストライキをし、商人が店を閉じた。北洋政府は六月に逮捕された学生を解放し、中国の代表は最終的にパリ講和条約への調印を拒んだ。この経過は当時の新聞と学生の回想に数多く記録されている。
