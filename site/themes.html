01 / 三分钟做一套

最少只改三个地方

下载仓库里的任意一套节日主题当底稿，用记事本改三行，再交上去——不用写代码，不用装工具。

  1. STEP 1

    改 id

    给主题起一个英文短名，例如 my-theme。同一个 id 只能出现一次，撞了就换一个。

  2. STEP 2

    改名字

    界面上显示的名字，中文就行，想起什么起什么："我的主题"。

  3. STEP 3

    改主色

    一个 # 开头的颜色值，例如 #7C3AED。保存，上传，收工。

{
  "schema": "theme/1",
  "id": "my-theme",
  "name": "我的主题",
  "colour": "#7C3AED"
}

03 / 想玩多大

能改的地方，比想象中多

颜色是最小的一档。往下还有这些——全都只改「看起来怎样」，不动「能做什么」。

75 处图标

  • 每个动作按钮：点赞、回复、删除、分享
  • 输入框工具条、视频播放控件
  • 底部三个标签、菜单按钮、明暗切换
  • 所有空状态与错误提示

22 处边框

  • 卡片、按钮、输入框、标签栏
  • 顶栏、分段控件、开关
  • 轻提示、抽屉、工具卡、空状态
  • 圆角与阴影一起定

点击效果

  • 形状、颜色、扩散方式由主题决定
  • 点哪儿，在哪儿出现
  • 动画节奏也可以自己写

对话框与背景

  • 背景、文字、描边、遮罩都可定
  • 能单独准备深色一套，切换时自动换
  • 背景可叠多层：图片、SVG、纯 CSS
  • 各自定位、透明度、缓慢动画
04 / 三阶荣誉

名字旁边会多一枚徽标

样式与管理员的身份标识一致，出现在评论、世界对话、榜单、作品详情与主题目录里。

勇于参与

一阶 · 全站唯一

全站第一个提交主题的人。管理员与副管理员不参与这一枚。授予即永久，只此一枚，先到先得。

积微成著

二阶 · 数量

累计 2 套主题通过审核。按当前通过的套数实时计算，撤回或被删后自然回落。

匠心独运

三阶 · 数量 + 认可

累计 3 套通过审核，且其中至少 1 套被标为推荐。做得最好的那一套，会被推荐到目录最前面。

05 / 规矩

几条线，先说清楚

规则少，但每条都要守。守住这一条，主题就永远只改外观，不会动到功能。

额度与流程

  • 每人默认 1 个投稿名额，管理员可提到 2 或 3
  • 额度按「在审」与「已通过」计算，被拒不占
  • 撤回会把名额还回来
  • 审核通过即出现在目录里，全站可见
  • 被拒会写明原因，改完可以重提

安全底线

  • 主题只能提供样式，不能提供代码
  • 含脚本的 SVG、外部图片地址一律拒收
  • 不能提供选择器，不能改变位置与穿透
  • 不会出现盖住按钮、吃掉点击的透明层
  • 入选官方主题库也不放宽这条

评审看四点

  • 整体协调：颜色别打架
  • 对比度：文字在背景上看得清，这是硬指标
  • 手机端：390 宽的屏幕上不能挤成一团
  • 深色一套：别把浅色直接反色了事
